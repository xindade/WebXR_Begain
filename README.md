# WebXR 肉鸽打气球

纯前端 ES Module + 本地 Three.js r168，无需构建。支持桌面键鼠及 WebXR，包含 18 关、抽卡强化、激光机制和 Boss；已有 GLB 模型、天空图、视频及语音资源。

## 本地运行

在项目目录执行：

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

打开 http://127.0.0.1:8123/，直接点击“开始游戏”。不能通过 file:// 直接打开。头显通过局域网访问时需使用受信任的 HTTPS 服务；本机 localhost 的安全上下文特例不适用于头显访问电脑的局域网 IP。

## 操作与设置

| 操作 | 桌面 | VR |
|---|---|---|
| 移动 | WASD / 方向键 | 右摇杆 |
| 瞄准、射击 | 鼠标、左键 | 惯用手朝向、扳机 |
| 技能 | F | 握柄 |
| 暂停 | P / Esc / 页面按钮 | 右手 A 或 B |
| 暂停后继续 | P / 继续游戏 | 右手 A |
| 暂停后退出 | 返回菜单按钮 | 右手 B |

点击画面锁定鼠标。失焦、切到后台或 XR 可见性改变会暂停；回到页面后需明确继续。恢复时需先松开扳机，避免意外连射。

“设置”可保存移动速度、坐姿高度补偿、惯用射击手、音量、左摇杆转向（关闭、30°分段、平滑）及天空质量。设置保存在当前浏览器；天空质量刷新后生效。沉浸式内提供暂停提示面板，详细设置需在进入 VR 前完成。

## 本次改进

- 攻击强化不会降低死亡补偿后的攻击；满级属性不再进入候选池，全属性满级时提供补给；卡牌展示实际变化。
- 选卡检测覆盖子弹整段运动轨迹；模型加载失败保留可见外观，失败请求可重试。
- 天空缓存最多保留三张，并释放淘汰纹理；切关和返回菜单使旧请求失效；共用 GLTF/Draco 加载器。
- 无需联网激活，直接显示开始入口；首关天空、传送门、开场模型在后台预热，不阻挡开局。
- 深度立绘优先使用预生成图集，缺失时回退运行时捕获。已生成 9 套、18 张 PNG，约 18.3 MiB。
- 暂停同步处理玩法、输入和音视频；退出关卡清理语音；异步龙关加载不会在退出后生成旧部件。
- 页面默认收起日志；显示 FPS、帧间隔 P95、draw calls 和纹理数，可导出性能 JSON（最多保留 600 个采样点）。更新/渲染耗时为 CPU 测量，不代表 GPU 耗时。

2K 天空选项缩小解码后的 GPU 上传尺寸，仍下载原始 4K 文件；共享 GLB 与立绘缓存仍跨关复用，三张上限仅针对天空。

## 开发与验证

Node.js >=22.15，无需 npm install：

```powershell
npm test
```

测试覆盖玩法、资源竞态、暂停、设置、输入及音视频。验证范围及真机检查表见 [docs/verification.md](docs/verification.md)。

修改立绘模型后重新生成图集：

```powershell
python tools/bake-server.py
```

打开 http://127.0.0.1:8124/tools/bake-depth-sprites.html 并点击生成按钮，等待显示完成。此工具将 PNG 和 manifest 写入 assets/depth-sprites；完成后停止服务。普通游玩只需只读静态服务器。

## 代码入口

| 文件/目录 | 职责 |
|---|---|
| src/main.js | 启动、会话、暂停、设置与帧循环 |
| src/game/game.js | 游戏状态和关卡编排 |
| src/content/levels.js、cards.js、enemies.js | 实际关卡、强化和敌人配置 |
| src/core/constants.js、userConfig.js | 默认常量及项目覆盖配置 |
| src/core/world.js | 渲染、坐标与天空资源 |
| src/game/glbCache.js、glbCapture.js | 共享模型与立绘图集 |
| src/vr/input.js、audio.js | 输入、音效与媒体生命周期 |
| src/core/pause.js、settings.js、performance.js | 暂停、设置及诊断 |
| tests/ | Node 回归测试 |

src/content/levelConfig.js 是未接入运行时的历史方案，不作为当前数值来源。项目保留关卡快捷入口用于原型调试；正式发布前应决定是否隐藏。

目前未完成 PICO/Quest 真机验收，桌面结果不能代替双目渲染、手柄映射、眩晕舒适度与移动 GPU 性能验证。
