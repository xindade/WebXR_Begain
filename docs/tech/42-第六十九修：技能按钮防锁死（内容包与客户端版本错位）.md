# 第六十九修 · 技能按钮“永久失效”：内容包与客户端版本错位

> 现场：商店里选完「黑洞」后，左右手 grip 都没反应。
>
> 这一修不是在改黑洞本身 —— 黑洞的释放、吸附、冷却在桌面/头显里都能跑通。
> 真正的问题是：**技能卡来自 content 包（服务器/EXE 可覆盖），客户端代码来自 APK**。
> 两者版本一旦错位，商店会卖出一张客户端根本不认识的技能卡。

---

## 1. 失效链路

1. 服务器把新 `src/content/cards.js` 下发给 APK（EXE `/api/config/dump` → APK 配置覆盖层）；
2. 商店按新卡表摆出 `blackhole`；
3. 玩家打爆气球 → `_applySkillCard('blackhole')` → `selectedSkill = 'blackhole'`；
4. 旧 APK 的 `_triggerSelectedSkill()` 里没有 `case 'blackhole'`：
   - `switch` 直接走完，**什么都没放**；
   - 仍然执行 `_skillCasts++` 与 `skillCooldown = _skillCdTotal()`；
   - 旧口径的 `_skillCdTotal()` 在未知 id 上可能返回 `undefined` / `NaN`；
5. 下一帧 `skillCooldown <= 0` 对 `NaN` 恒为 `false` ⇒ **左右手从此永久无效**。

即使旧包返回 0（本项目 HEAD 里的写法），也会表现为「按了没反应」，
因为 `switch` 没有匹配分支 —— 玩家在头显上看不到任何提示。

## 2. 本修的四道保险

| 保险 | 位置 | 行为 |
|---|---|---|
| 技能 id 白名单 | `game.js` 模块级 `SKILL_IDS` / `supportsSkill()` | 只有客户端真正实现过的 id 才能装备 |
| 未知 id 不落库 | `_applySkillCard()` | 保留当前可用技能；当前也无效才回落 `scatter` |
| 未知 id 有兜底 | `_triggerSelectedSkill()` 的 `default` | 回落默认能量散射，绝不「空放却进冷却」 |
| 冷却永远有限 | `_skillCdTotal()` + 每帧自愈 | 任何 id / 任何脏 `skillCdDown` 都返回有限正数；`NaN/undefined` 下一帧自动归 0 |
| 商店过滤 | `shop.js` `_frontEntries()` | 客户端没实现的技能卡**不摆上架**，避免买到假卡 |

另外两处顺手收口：

- 释放失败（能量不足 / 未解锁）现在 `return false`，**不进入冷却、不计技能次数**；
- 商店关 / 激光关也会推进黑洞时间轴（此前在商店里放洞会停在原地不消失）。

## 3. 留痕

每次按 grip：

- 被拒：`[技能] 未就绪：开场提示未结束` / `[技能] 冷却中 3.2s`
- 未知 id：`[技能] 未知技能 id=xxx（客户端未实现，需更新 APK）：保留 scatter`
- 成功：沿用各技能自己的 `黑洞！` / `如来神掌！` 等日志

这样现场只要导出页面留痕，就能一眼区分「没按到」「在冷却」「开场锁」「客户端不认这张卡」。

## 4. 现场必须做的事

代码修的是「以后不再被新内容卡死」，但**已经装在头显上的旧 APK 不会自己变新**：

1. 重新安装本轮的 APK（`tools/cast-apk/dist/WeirdTurning-1.5.4.apk`）；
2. 若安装器提示「应用未安装 / 版本相同」，先卸载旧包再装（包名与版本号本轮未改）；
3. 装完后进第 3 关商店，确认三张技能卡都在，买黑洞后到第 4 关等「快使用技能」横幅结束，再按 grip。

## 5. 验证

- `tests/skill-guard.test.mjs`：8 项
  - 未知 id 的冷却仍是有限正数；
  - `skillCdDown = NaN` 不产生 NaN 冷却；
  - 未知 id 不覆盖当前技能；
  - 当前技能也未知 → 回落 `scatter`；
  - 未知 id 释放时回落散射并正常进冷却；
  - 释放失败不进冷却、不记次数；
  - 商店过滤未知技能卡（0 张）与正常上架（3 张）。
- 浏览器实测（无头 Chrome + 真 WebGL）：
  - 买黑洞 → 第 4 关解锁 → grip：`_bhActive=true`、冷却 12s、扣 500 能量；
  - `selectedSkill='futureSkill'` → grip：回落 `scatter`、正常扣能量；
  - `skillCooldown=NaN` → 下一帧自愈并成功释放。
- 全量：**462 / 462 通过**。
