# 02 · 调试日志（布局与实现）

> 源码：`src/ui/pagelog.js`（页面面板）、`src/vr/wrist-ui.js`（头显内腕表面板）、`src/game/game.js` 的 `log()`
> 样式：`index.html` 的 `.pagelog*` 规则｜参数：`constants.js` 的 `WRIST_UI`
> 复现难度：★★（实现简单，但「为什么这样布局」全是踩坑结论）

---

## 1. 为什么要两套日志

VR 项目调试比普通 Web 难一个量级，原因是**两个「看不见」**：

| 问题 | 后果 |
|---|---|
| 头显里**看不到控制台** | 只能靠现象猜；PC 端 Chromium DevTools 也连不进头显浏览器 |
| ES Module 加载失败时**整站白屏** | 若日志也写在 module 里，日志会跟着一起挂掉，什么都看不到 |
| 进入 immersive VR 后 **DOM 全部不可见** | 浏览器页面上的日志面板在头显里看不到，只能看「黑屏」 |

因此需要两套：

- **`pagelog.js`** —— 浏览器页面上的日志面板。用**经典脚本**实现，即使 `three` / `main.js` 加载失败也能跑，
  专门用来抓「白屏类致命错误」。
- **`WristUI`** —— 左手柄上的日志面板。用 CanvasTexture 画到 3D 平面上，
  解决「沉浸态 DOM 不可见」的问题。

## 2. 页面日志面板 `pagelog.js`

### 2.1 必须用经典脚本（最关键的约束）

`index.html` 中的引入顺序：

```html
<!-- 最高优先级页面日志：经典脚本优先加载，不依赖 three，可捕获黑屏类致命错误 -->
<script src="./src/ui/pagelog.js"></script>
<script type="module" src="./src/main.js"></script>
```

- **无 `type="module"`**：module 是延迟执行（defer 语义）且受 CORS/依赖图影响；
  经典脚本会**立即同步执行**，因此能在 `main.js` 及其依赖（three、所有 `src/**`）开始加载**之前**就装好钩子。
- **不 import 任何东西**：不依赖 `importmap`、不依赖 three。三条依赖全部断掉时它依然活着。
- 用 IIFE 包裹 + `window.__pageLogReady` 幂等守卫，避免重复注入。

### 2.2 布局（值直接取 `index.html`）

```css
/* ── 最高优先级页面日志：浏览器最左侧，占 1/4 面积 ── */
.pagelog {
  position: fixed; left: 0; top: 0; width: 25vw; height: 100vh;
  z-index: 10000; display: flex; flex-direction: column;
  background: rgba(0, 0, 0, .84); color: #d8d8d8;
  font: 12px/1.5 ui-monospace, Menlo, Consolas, monospace;
  border-right: 1px solid rgba(255,255,255,.12);
}
.pagelog-head {
  flex: 0 0 auto; display: flex; align-items: center; justify-content: space-between;
  padding: 6px 10px; background: rgba(108, 92, 231, .9); color: #fff; font-weight: 700;
}
.pagelog-body {
  flex: 1 1 auto; overflow-y: auto; padding: 6px 10px; white-space: pre-wrap; word-break: break-word;
}
.pagelog-line.lvl-info  { color: #cfd8e3; }
.pagelog-line.lvl-warn  { color: #ffd43b; }
.pagelog-line.lvl-error { color: #ff7675; font-weight: 700; }
```

设计要点：

| 设计 | 原因 |
|---|---|
| `left:0; width:25vw; height:100vh` | 固定占最左 1/4，**不遮挡**游戏画面主体（其余 3/4 可玩） |
| `z-index: 10000` | 高于加载遮罩 `#loading-overlay`（9999），加载期报错也看得到 |
| `flex column` + body `overflow-y:auto` | 头部固定、正文滚动 |
| `white-space: pre-wrap` + `word-break: break-word` | 保留堆栈换行，长 URL 不撑破面板 |

### 2.3 行为：会话结束自动暂停滚动

```js
var MAX_LINES = 600;
var paused = false;

function append(msg, level) {
  ensureDom();
  var line = document.createElement('div');
  line.className = 'pagelog-line lvl-' + (level || 'info');
  line.textContent = '[' + ts() + '] ' + msg;
  body.appendChild(line);
  while (body.childElementCount > MAX_LINES) body.removeChild(body.firstChild);  // 环形裁剪
  if (!paused) scrollToBottom();
}
```

- **`MAX_LINES = 600` 环形裁剪**：防止长时间运行把 DOM 撑爆（VR 跑几十分钟，日志可以几万条）。
- **`paused` 机制**：`window.__pageLog.pauseScroll()` 会让面板停止自动滚到底。
  游戏在**退出 VR 回到预览界面**时会调用它——否则最后几条「退出瞬间的报错」会被后续日志顶走而丢失。
  面板顶部徽标「⏸ 已暂停滚动（点此继续）」可手动恢复。

### 2.4 捕获范围

```js
// ── 捕获 console.* ──
['log', 'info', 'warn', 'error', 'debug'].forEach(function (fn) {
  var orig = console[fn] ? console[fn].bind(console) : function () {};
  console[fn] = function () {
    var args = Array.prototype.slice.call(arguments);
    try { orig.apply(null, args); } catch (e) {}          // 原方法出错不能拖垮日志
    var level = fn === 'error' ? 'error' : fn === 'warn' ? 'warn' : 'info';
    append(args.map(fmt).join(' '), level);
  };
});

// ── 捕获未处理异常 / Promise 拒绝（含模块加载失败、语法错误）──
window.addEventListener('error', function (e) {
  var loc = e.filename ? ' @ ' + e.filename + ':' + e.lineno + ':' + e.colno : '';
  append('❌ ' + (e.message || '未知错误') + loc, 'error');
});
window.addEventListener('unhandledrejection', function (e) {
  var r = e.reason;
  append('❌ Promise 拒绝: ' + (r && r.message ? r.message : fmt(r)), 'error');
});
```

`fmt()` 处理三种入参：字符串原样、`Error` 打 `message + stack`、其它走 `JSON.stringify`（失败则 `String()`）。

### 2.5 对外接口

```js
window.__pageLog = {
  log/info/warn/error(m),          // 手动打一条
  pauseScroll() / resumeScroll() / togglePause() / isPaused(),
};
```

`main.js` 把它作为 `pageLog` 注入 `game.setSystems(...)`，成为业务日志的出口之一。

## 3. 头显内腕表面板 `WristUI`

### 3.1 结构

| 面板 | 挂载点 | 内容 | 边框色 |
|---|---|---|---|
| 右手 | 右手柄 **grip** | 关卡 / 剩余敌人 / 船血 / 分数（Boss 关换成龙血量条） | 青 |
| 左手 | 左手柄 **grip** | 实时日志（最近 6 条） | 橙 |

挂 `grip`（握把）而不是 `targetRay`（射线原点），因为 grip 更贴合手背，低头看手腕的姿势最自然。

### 3.2 画布 → 贴图 → 平面

```js
_make(cfg) {
  const cv = document.createElement('canvas');
  cv.width = cfg.CANVAS.w; cv.height = cfg.CANVAS.h;
  const ctx = cv.getContext('2d');
  const tex = new THREE.CanvasTexture(cv);
  // 1px ≈ 1mm：512px → 0.5m，再乘 SCALE 得到最终物理尺寸
  const geo = new THREE.PlaneGeometry((cfg.CANVAS.w / 1024) * cfg.SCALE, (cfg.CANVAS.h / 1024) * cfg.SCALE);
  const mat = new THREE.MeshBasicMaterial({
    map: tex, transparent: true, depthTest: false, depthWrite: false, side: THREE.DoubleSide,
  });
  const mesh = new THREE.Mesh(geo, mat);
  mesh.renderOrder = 999;                     // 始终画在最前，不被手柄模型/场景遮挡
  mesh.position.set(cfg.POSITION.x, cfg.POSITION.y, cfg.POSITION.z);
  mesh.rotation.set(D2R(cfg.ROTATION.x), D2R(cfg.ROTATION.y), D2R(cfg.ROTATION.z));
  return { cv, ctx, tex, mesh, w: cfg.CANVAS.w, h: cfg.CANVAS.h, border: cfg.BORDER };
}
```

关键设计：

| 设计 | 原因 |
|---|---|
| `depthTest:false` + `depthWrite:false` + `renderOrder=999` | 面板永远可见，不会被手柄实体或场景几何挡住 |
| **画布分辨率与物理尺寸解耦** | `CANVAS.w/h` 只决定清晰度，`SCALE` 决定物理大小；缩小物理尺寸不会让文字变糊 |
| `DoubleSide` | 手腕从任意角度都能看到 |
| 挂载幂等 `_attached` | 控制器连上时机不定，`update()` 里反复调用 `attach()` 也不重复添加 |

### 3.3 刷新节流与日志环形缓冲

```js
update(dt, game, input) {
  this.attach(input);
  this._frame++;
  if (this._frame % 6 !== 0) return;   // ~15fps 刷新（72fps / 6），省算力
  this._drawRight(game);
  this._drawLeft();
}

log(msg) {
  const t = new Date().toLocaleTimeString('zh-CN', { hour12: false });
  this._log.push(`[${t}] ${msg}`);
  if (this._log.length > 60) this._log.shift();   // 环形缓冲
}

// 绘制时只取最后 6 条
this._log.slice(-6).forEach((t, i) => c.fillText(t, 24, 92 + i * 30));
```

> **每帧重绘 CanvasTexture 会把 CPU 和纹理上传打满**。降到 1/6 频率即可，肉眼完全够用。

## 4. 数据流：`Game.log()` 扇出

```js
// src/game/game.js
setSystems(audio, input, wristUI = null, pageLog = null) {
  this.audio = audio; this.input = input; this.wristUI = wristUI; this.pageLog = pageLog;
}

log(msg) {
  this.wristUI?.log(msg);    // 头显内左手腕
  this.pageLog?.log(msg);    // 浏览器左侧面板（window.__pageLog）
}
```

`main.js` 启动时：

```js
const wrist = new WristUI();
const pageLog = window.__pageLog;          // pagelog.js 已注入
game.setSystems(audio, input, wrist, pageLog);
```

于是业务代码统一写 `this.log('波次清空，选择强化')`，**一次调用，两端可见**；
桌面调试看浏览器面板，头显调试看左手腕。

### 日志内容约定（便于排障）

用**固定前缀**区分模块，方便在长日志里 grep：

| 前缀 | 来源 | 例子 |
|---|---|---|
| （无前缀） | 游戏流程 | `第 3 关 · 激光驱赶：等待→驱赶→保持原地10秒→走格子` |
| `[glbCapture]` | 离屏捕获 | `sheet 超过纹理上限(4096)，每帧分辨率降至 256` |
| `[GLBCache]` | GLB 加载 | `加载失败: <url>` |
| `[waitingRoom]` | 影片 | `镜像取帧 frames=120 readyState=4 canvas=640x360 mode=raw` |
| `[cast]` | 直播 | `已切换到游戏画面（replaceTrack，链路未中断）` |
| `离屏渲染均耗时 xx ms/帧` | 直播性能 | 判据：稳定 > 7ms 会触发 `_autoScale()` 降档 |

## 5. 参数表

### `constants.js` → `WRIST_UI`

```js
WRIST_UI: {
  RIGHT: {
    SCALE:    …,                     // 物理尺寸缩放（Canvas 像素 ≈ 1mm，再乘本值）
    POSITION: { x, y, z },           // 相对 grip 的位置（米）——独立微调，不随尺寸联动
    ROTATION: { x, y, z },           // 相对 grip 的旋转（度），x 向下倾斜便于低头看
    CANVAS:   { w, h },              // 画布分辨率（像素）——只影响清晰度
    BORDER:   '…',                   // 边框色（青）
  },
  LEFT: { … /* 边框色橙 */ },
}
```

### 硬编码常量

| 常量 | 位置 | 值 | 含义 |
|---|---|---|---|
| `MAX_LINES` | pagelog.js | 600 | 页面面板最大行数（环形裁剪） |
| 日志环形缓冲 | wrist-ui.js | 60 | 手腕日志缓存条数 |
| 显示条数 | wrist-ui.js | 6 | 手腕面板一次显示行数 |
| 刷新间隔 | wrist-ui.js | 6 帧 | ≈15fps |
| 面板宽度 | index.html | 25vw | 浏览器左侧占比 |
| `z-index` | index.html | 10000 | 高于加载遮罩 9999 |

## 6. 踩坑清单

| 现象 | 真因 | 结论 |
|---|---|---|
| 白屏时日志面板也没有 | 日志脚本用 ES Module 写，跟着一起加载失败 | 必须用**经典脚本**，且不 import 任何东西 |
| 加载遮罩把日志盖住 | 遮罩 z-index 9999 ≥ 日志 | 日志用 **10000** |
| 退出 VR 后关键报错找不到 | 后续日志把最后几行顶走 | 会话结束 `pauseScroll()`，徽标可恢复 |
| 长跑后页面卡顿 / 内存涨 | DOM 无上限增长 | `MAX_LINES=600` 环形裁剪 |
| 头显里看得到画面但看不到日志 | immersive 下 DOM 不可见 | 用 `WristUI` 把日志画进 3D 场景 |
| 手腕面板被手柄模型挡住 / 时隐时现 | 参与深度测试 | `depthTest:false` + `renderOrder=999` |
| 面板文字糊 | 物理尺寸缩小同时把画布也缩小了 | 画布分辨率与 `SCALE` 解耦 |
| 面板重复添加（重影/双重开销） | 控制器重连后再次 `attach()` | `_attached` 幂等守卫 |
| 帧率被日志拖垮 | 每帧重绘 CanvasTexture | 每 6 帧刷新一次 |

## 7. 验证方法

- [ ] 故意在 `main.js` 顶部写一句语法错误并刷新：面板仍出现，且显示 `❌ … @ ./src/main.js:行:列`（**证明经典脚本能兜住白屏**）
