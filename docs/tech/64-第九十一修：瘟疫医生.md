# 第九十一修：瘟疫医生（第四角色）

## 目标

在疾风 / 蜂群 / 爆炮手之外新增第四角色「瘟疫医生」，用低爆发、持续毒素和死亡传染形成独立手感：

- 初始攻击 50，射速 2 发/秒；
- 攻击力选项卡卡面仍写 `+100`，但瘟疫医生实际只加 50；
- 子弹命中叠 1 层毒，默认最多 5 层；
- 每层毒素每秒造成「当前攻击力 ×25%」伤害；
- 教学关专属卡「感染」：敌人死亡时，把自身层数的一半传给最近敌人；
- 商店专属道具「加大剂量」：Lv.1 提到 8 层，之后每级 +2（Lv.2=10、Lv.3=12……）。

## 数值口径

| 项目 | 数值 |
|---|---|
| 初始攻击 | 50（基础 100 × `atkMul 0.5`） |
| 射速 | 2 发/秒 |
| 攻击力卡 | 卡面 `+100`，实际 `+50`（`atkGainMul 0.5`） |
| 毒素每层 | 当前攻击力 ×25% / 秒 |
| 默认层数上限 | 5 |
| 加大剂量 Lv.1 | 8 层 |
| 加大剂量 Lv.2 | 10 层 |
| 加大剂量 Lv.3+ | 每级继续 +2（12、14……） |
| 感染转移 | `floor(死亡时自身层数 × 50%)`，不超过目标当前上限 |

毒素按「所有目标同一秒拍」统一结算，不逐怪维护计时器，避免每帧遍历和大量定时器。命中时只叠层，跳伤才真正扣血；跳伤击杀仍走统一 `_onKilled`，因此积分、商店币、精英反馈与 Boss 结算保持原链路。

## 边界

- 致命的那一枪不再叠层：只剩 1 层毒的小怪被最后一枪打死时仍按 1 层结算，不触发「感染」；
- 毒素不对龙 Boss 部件叠层/跳伤，避免多节部件异常放大收益；
- 聚宝盆等无敌目标不叠毒；
- 毒素跳伤不触发「连杀加速」与「吸血/打狗」等只认子弹击杀的商店效果；
- 教学关拿「感染」卡前不传染；非教学关按角色核心手感直接生效；
- 毒素数字固定绿色，精英的金色数字规则不会覆盖它。
