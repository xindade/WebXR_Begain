# 第六十八修 · 黑洞成长闪烁、环形吸附、切关与末尾精英卡顿

> 现场三条：
> 1. 黑洞生效正常；想加「开局 1 秒从小猛然变大」，并在最后 1 秒快速闪两下。
> 2. 怪被吸过去的位置太集中，看起来像一条线；想要围成一个小圈。
> 3. 进入下一关、或末尾精英生成时，转头会出现黑屏卡顿。

---

## 1. 黑洞：成长 + 结束闪烁

### 参数（`src/core/constants.js`）

| 参数 | 值 | 说明 |
|---|---:|---|
| `BLACK_HOLE.GROW_TIME` | 1.0 s | 从出现到长到最终大小的时间 |
| `BLACK_HOLE.START_SCALE` | 0.06 | 出现瞬间的尺寸（相对最终大小） |
| `BLACK_HOLE.BLINK_TIME` | 1.0 s | 结束前开始闪烁的时间窗 |
| `BLACK_HOLE.BLINK_COUNT` | 2 | 最后 1 秒闪两下 |

### 曲线（`src/game/blackHole.js`，纯函数，可单测）

- `blackHoleScaleAt(t)`：`easeOutQuart`，前 0.5 秒就长到约 0.94；1 秒后只剩 ±2.5% 的呼吸。
- `blackHoleBlinkAt(t)`：`|sin(2πp)|`，在最后 1 秒的 25% / 75% 处各出现一个峰值，正好两下；进入最后 1 秒前恒为 0，6 秒整归 0。
- `BlackHoleFx.update()` 同时压暗核心 / 螺旋 / 吸积盘，并放大 16%；纯压暗在加色混合下不够显眼，配合放大才看得出来。

## 2. 吸附落点：从「一条线」改成「小圈」

旧实现：每只怪停在自己原来的来向上（`atan2(z - 洞心z, x - 洞心x)`）。怪从正面来时方位角几乎一样，远看就叠在一条线上。

新实现：

- `_bhCapture()` 记录第一只被吸的怪的来向作为 `_bhSlotBase`；
- 之后每只按黄金角 `SLOT_GOLDEN = π × (3 − √5) ≈ 137.5°` 依次错开；
- 所有怪仍停在 `RIM = 2m` 的洞缘上，因此自然围成一个直径 4m 的小圈；
- 精英到位后仍做原来的径向振荡，并绕洞心缓慢旋转，不会和小怪完全重叠。

纯函数 `blackHoleSlotAngle(index, base)` 有单测：8 只从几乎同一条线来的怪，落地后最小角间隔 > 0.28 rad。

## 3. 切关 / 末尾精英卡顿

现场「转头黑一下」不是画面本身变黑，而是单帧耗时过长，WebXR 合成器补不出位移，视野边缘露出未重投影区域。定位到三处一次性尖峰：

### 3.1 淡入材质在雾散那一帧一次性恢复

`world.setFadeRoots()` 为了做穿云淡入，会把本关材质临时改成 `transparent = true`；雾散时 `_restoreFade()` 又一次性改回最终状态。`transparent` 变化会触发 shader 重编译，几十份材质挤在同一帧，正好是「进入下一关」的黑屏点。

修法：

- `World.restoreFadeStep(camera, maxCount = 1, budgetMs = 2.5)`：每帧只恢复 1 份材质，恢复后立刻 `initTexture + compile`，全部藏在云雾窗内；
- 淡入登记时把 `geometry + 物体类型` 一并存进 `_fadeMats`，编译时用正确探针（Mesh / Sprite / Points / Line / InstancedMesh），避免编出错误 program；
- 雾散时若还有剩余，才由原来的 `_restoreFade()` 兜底。

### 3.2 转向才第一次看见的物体

Frustum culling 让背后的物体不参与渲染；玩家一转头，纹理上传 + 着色器编译全压在那一眼。

修法：`World.warmSceneGpu(camera, budgetMs = 2.0)` 在穿云窗内遍历场景，把尚未预热的材质按预算逐个 `initTexture + compile`。已预热的材质进 `WeakSet`，不会重复。

### 3.3 融合吸收 / 切关时同帧 dispose 十几只怪

`Balloon.dispose()` 会删材质、贴图与几何；共用 shader program 的引用计数可能因此归零，下一帧新精英又要同步重编译。

修法：

- `BalloonManager.remove(b, deferDispose = true)`：先从场景和列表摘掉（视觉上立即消失），资源推进 `_retired`；
- `flushRetired(max = 2)`：只在下一关云雾窗里每帧释放 2 只；
- `clear()` 切关也走「先摘后放」；
- 融合吸收的怪不再在汇聚那一帧集中 dispose。

### 3.4 融合落地不再同帧克隆整批精英

`FUSE.SPAWN_STAGGER = 0.075s`：融合大光点落地后，精英按 0.075 秒间隔逐只生成，把「GLB 克隆 + 名牌/血条贴图 + 首帧绘制」摊到几帧。`_active` 与 `_canClear` 都把待生成队列算进去，不会提前判通关。

## 4. 验证

### 单测

- `tests/black-hole.test.mjs`：19 项（原 16 + 3）
  - 尺寸曲线：0 秒很小、0.5 秒 > 0.85、1 秒基本到位；
  - 闪烁：最后 1 秒两个峰值、中间回暗、结束归零；
  - 环形分布：8 只同向来的怪落地后最小角间隔 > 0.28 rad。
- `tests/fade-warm.test.mjs`：4 项
  - 延迟释放：`remove(b, true)` 只摘不 dispose，`flushRetired` 才释放；
  - 切关清场同样先摘后放；
  - `restoreFadeStep` 每帧 1 份、最后关闭 fadeOn；
  - `warmSceneGpu` 只预热未见过的材质，贴图与 shader 各做一次。
- `tests/climax-clear-gate.test.mjs`、`tests/elite-batch-watch.test.mjs`：适配逐只错帧生成。
- 全量：**454 / 454 通过**。

### 上机自测

1. 第 3 关商店买黑洞 → 释放：漩涡从一个小点 1 秒内猛然撑开；
2. 持续 5 秒后开始闪两下，随后消失，怪从洞的位置继续走；
3. 同时吸 5~10 只怪：落点围成小圈，不再是一条线；精英在小圈上前后摆动；
4. 打完一关进下一关，云雾散开时左右转头：不再黑屏/冻结；
5. 末尾精英融合落地：大光点炸开后精英逐只出现（间隔很短），转头无黑屏；
6. 回归：Boss 免疫、20 DPS、飞毯弧线、被吸期间不攻击/不治疗全部照旧。

## 5. 可调参数

| 参数 | 位置 | 现值 | 说明 |
|---|---|---:|---|
| `BLACK_HOLE.GROW_TIME` | `constants.js` | 1.0 | 想更「猛」可调 0.6~0.8 |
| `BLACK_HOLE.START_SCALE` | `constants.js` | 0.06 | 想从更小的点出现可调 0.03 |
| `BLACK_HOLE.BLINK_TIME` | `constants.js` | 1.0 | 闪烁窗口 |
| `BLACK_HOLE.BLINK_COUNT` | `constants.js` | 2 | 闪烁次数 |
| `FUSE.SPAWN_STAGGER` | `spawnDirector.js` | 0.075 | 精英逐只生成间隔；卡顿仍明显可调 0.12 |
| `restoreFadeStep` 每帧份数 | `game.js` | 1 | 调大更快恢复，但单帧编译更多 |
| `warmSceneGpu` 每帧预算 | `game.js` | 2.0 ms | 云雾窗内的预热预算 |
