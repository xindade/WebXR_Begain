# 12 · 第 18 关魔术师 Boss：开场演出与召唤池（第三十八修）

## 0. 一句话结论

把「站桩 30m 外当血包 + 阶段末齐射杂兵」改成 **两段式登场演出（念白 → 飞回 Boss 位 → 瞬间变大 2 倍）**
和 **场上维持池召唤（恒定 20 只、其中 3 只阶段精英怪，掉到 5 只以下才补满）**；
登场与结束都挂在**开场语音**上，语音播完就开打。

## 1. 两条需求（现场原话）

| # | 需求 | 现状问题 |
|---|---|---|
| 1 | 「Boss 的压迫感还不够」 | Boss 全程站桩在 30m 外、开场 10 秒是纯白靶、机制 40 秒一轮毫无升级；体型与玩家视角距离恒定，没有「巨物感」 |
| 2 | 「Boss 的召唤小兵机制也有点问题」 | 按时间点分波召唤：激光阶段一次 3 波 ×（25 小怪 + 5 忍者）= 90 只，玻璃阶段 2 × 10 骑士；**出生距离按「剩余时间反推」→ 全都在阶段结束那一刻同时抵达自爆**（清干净=零威胁，漏几只=5×N 秒杀，没有中间态）；且**忍者被 `_clampToRing` 锁在 10~15m 环带、永远进不了 4×8 自爆区 ⇒ 永不自爆、只增不减**，长局里场上会堆几十只固定炮台 |

## 2. 开场演出（10 秒 → 语音驱动）

### 2.1 时间轴

| 时刻 | 动作 |
|---|---|
| 0s | 以 **第 15 关开场魔术师**的位置/体型出现（`INTRO.POS = [0, 7.4, -10]`、`SCALE_HEIGHT = 5.0`），开始念白 `music/魔术师Boss开头.wav` |
| `INTRO.CUE_AT`（默认 5.4s，对齐「我就是Boss中的Boss」） | 起飞：`FLY_TIME = 0.6s` 沿 smoothstep 飞回 `POSITIONS[0]`（正前 30m） |
| 飞行结束那一帧 | **瞬间变大**：身高 = 常规体型 × `BIG_MULT(2)` → 10m 变 20m |
| 语音播完（`ended`） | 立刻进激光阶段（`_finishIntro` → `_enterPhase('laser')`），**不再有 10 秒白靶** |

### 2.2 关键实现

- 位置逐帧由**纯函数** `introPose(cfg, t)` 给出（`src/game/bossMagician.js`），无状态机、无累积误差：
  `t < CUE_AT` → 念白位；`CUE_AT ~ CUE_AT+FLY_TIME` → smoothstep 插值；飞完 → `big: true`。
- 「变大」是一次性开关 `_grow()`：模型身高、**命中半径**、**血条抬高**三者按同一比例缩放
  （`_radiusForHeight(h) = PROXY_RADIUS × h / 常规身高`）——否则 20m 的 Boss 用 8m 命中球会「打空气都掉血」。
- 代理由 Boss 控制器接管（`controlled = true`），所以**飞行/闪现都不触发 4×8 自爆判定**。

### 2.3 三条兜底（缺一个都会卡场）

| 风险 | 兜底 |
|---|---|
| 语音 404 / 解码失败 / 自动播放被拦 → `ended` 永不触发 | `PHASE.INTRO`（默认 8s）硬切：`_updateIntro` 里 `phaseTimer >= PHASE.INTRO` 即 `_finishIntro()` |
| 语音**早于** `CUE_AT + FLY_TIME` 结束（换语音/改 CUE_AT 时容易踩） | `_finishIntro()` 先补 `_grow()` 并把代理摆到 `POSITIONS[0]`，再进激光——不会留下半大的 Boss |
| 上一关的语音还没播完就切关 | 沿用第三十六修的 `_openingVoiceSeq` 自增序号作废旧回调；`_disposeOpening` 一并作废 |

## 3. 召唤池（波次 → 维持池）

### 3.1 规则（`constants.MAGICIAN_BOSS.POOL`，可用 `userConfig` 覆盖）

| 参数 | 值 | 含义 |
|---|---|---|
| `MAX` | 20 | 场上维持的召唤物总数（含精英） |
| `ELITE` | 3 | 其中精英怪数量 |
| `REFILL_AT` | 5 | **存活 < 5 只**才触发补充，一次补满到 `MAX` |
| `REFILL_COOLDOWN` | 0.5s | 两次补充之间的最小间隔 |
| `SPAWN_R` | 15 | 出生半径（米，距场地中心，正好在场地外侧） |
| `ELITE_BY_PHASE` | `laser: shield` / `glass: ghost` / `nine: octopus` | 各阶段精英怪敌种 |
| `BASIC_TYPE` | `basic` | 其余位置用普通怪 |
| `PER_FRAME` | 3 | 每帧最多落地几只（错峰，防 GLB 解码/立绘抓帧同帧卡死） |
| `BEAM_ENABLED` / `BEAM_Y` | true / 8 | 召唤物先以「从 Boss 身上飞出的光点」出现，落地才成怪 |

### 3.2 关键实现

- 计划由**纯函数** `planRefill(cfg, state)` 给出：`{elites, basics}`，不到阈值返回 `null`。
  **「场上」包含「已发出光点但还没落地」的部分**（`_pendingRefill`），否则光点在飞的 1 秒内会被重复补满。
- **切阶段不清场**：`_enterPhase` 只换 `ELITE_BY_PHASE` 的种类，已有怪一只不删（旧精英留在场上直到被打掉）。
- 光点出发点走 `waves._queueSpawn(type, pos, { from })` 的**新增参数** `opts.from`
  （原先只有「最近传送门」一个来源；Boss 关没有传送门，所以这里从 Boss 代理位置 + `BEAM_Y` 起跳）。
- 出生**不覆盖 `speed`**：以敌种自身速度飘向玩家（原实现为了「准时抵达」把基础怪提速到 2.0 m/s 并反推出生距离，正是「阶段末齐射」的来源）。

### 3.3 顺带修掉的两处确定性缺陷

| 缺陷 | 说明 |
|---|---|
| 忍者只增不减 | 旧召唤出来的忍者被 `balloons._clampToRing` 锁在 10~15m 环带、**永不进 4×8 自爆区** ⇒ 永不自爆；现在不再召唤忍者，且召唤池有上限，从机制上不可能堆积 |
| 18 关 BGM 不随血量升压 | `game._updateBossIntensity` 读的是 `waves.faceBoss \|\| waves.boss`，魔术师的血在 `_magicianBoss._proxy` 上、两者都是 `null` ⇒ 只按「75 秒到顶」升压。**本次未改**（属另一条线，见下方「遗留」） |

## 4. 参数表（改完刷新页面即生效；`userConfig.MAGICIAN_BOSS` 可覆盖同名键）

| 键 | 默认 | 说明 |
|---|---|---|
| `INTRO.VOICE_URL` | `music/魔术师Boss开头.wav` | 开场语音（实测 **7.494s**，48kHz/16bit/立体声） |
| `INTRO.POS` | `[0, 7.4, -10]` | 念白位置（与第 15 关开场魔术师同款）；觉得「飘太高」就调这里的 y |
| `INTRO.SCALE_HEIGHT` | 5.0 | 念白体型（米） |

| `INTRO.FLY_TIME` | 0.6 | 飞回 Boss 位耗时（秒） |
| `INTRO.BIG_MULT` | 2 | 变大后 = 常规 10m × 此倍数 |
| `INTRO.LOG_VOICE` / `LOG_STEP` | true / 0.5 | 把语音当前时间打进留痕，便于标定 `CUE_AT`；标定完改 false |
| `PHASE.INTRO` | 8 | 开场兜底上限（秒） |

## 5. 踩坑（调试记录）

1. **`introPose` 的 `big` 判定必须带容差**：`t` 由帧累加，末端常常差 `1e-16` 到不了 1 → 用 `k >= 1 - 1e-6`，
   否则「飞到了但不变大」，一帧内看不出、上机就是「Boss 飞回去还是小个子」。
2. **命中半径必须跟着体型走**：只改 `mesh.scale` 不改 `radius/effectiveRadius/hitRadius` 时，
   20m 的 Boss 会「看着巨大、打不到」或「打空气也掉血」。
3. **「场上数量」要算上在飞的光点**：只数已落地的怪 → 光点落地前每帧都满足「< 5」→ 一次补 20 只、连补好几轮。
4. **别在开场念白期间跑召唤**：`_updateSummonPool` 只在 `phase !== 'intro'` 时调用，否则 Boss 还没亮相就先刷 20 只。
5. **模型位置同步要放在阶段推进之后**：旧顺序是「先同步模型、再切阶段」，闪现/飞行会慢一帧（肉眼可见的「拖尾」）。

## 6. 验证方法

```powershell
npm test                                   # 60/60（其中 tests/boss-magician.test.mjs 8 项覆盖本节两套逻辑）
```

- 单测直接断言：`introPose` 三段行为、变大后身高 = 10m × 2、命中半径同比放大；
  `planRefill` 在 0 只 / 4 只 / 5 只 / 光点在飞 四种状态下的计划；
  激光/玻璃/黑白球墙三阶段的精英怪种类；`SPAWN_ENEMIES=false` 完全不召唤。
- 实机验收：进第 18 关 → 看到魔术师在正前方念白 → 讲到「我就是Boss中的Boss」时飞回去并瞬间变大
  → 语音一停激光就起；场上**恒定不超过 20 只**召唤物、其中 3 只是当前阶段的精英怪，
  打光到 4 只才会重新补满；激光阶段是盾牌骑士、玻璃墙阶段是幽灵、黑白球墙阶段是章鱼。
