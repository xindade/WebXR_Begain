# 第七十二修：黑洞竖直吸附环与本地精英立绘

## 目标

1. 黑洞吸住的小怪不再躺在水平面上围圈，而是像黑洞一样**竖直**围在漩涡外缘；整圈贴着黑洞正面，不穿模、不被黑色盘面遮住。
2. 商店「精英预告」卡的立绘改成**开发机预烧 PNG**，头显进店只读本地图片，不再每次抓 GLB。

## 一、黑洞竖直吸附环

### 原理

黑洞视觉本身是一块**竖直平面**（`BlackHoleFx` 用 `lookAt(viewer.x, center.y, viewer.z)` 摆正）。
吸附环必须共用同一组基向量，才能和漩涡同向：

```text
front = normalize(playerXZ - holeXZ)       // 黑洞平面法线，指向玩家
right = normalize(worldUp × front)         // 环的水平轴
up    = worldUp                            // 环的竖直轴

ringCenter = holeCenter + front × RING_FRONT
pos(angle, r) = ringCenter
              + right × cos(angle) × r
              + up    × sin(angle) × r
```

- 旧实现是 `(cos, 0, sin)`，只会铺在水平面（XZ）上，所以现场看到「一圈怪平躺在地上」。
- `RING_FRONT = 0.55m`：整圈只向玩家前移半米，仍贴着黑洞；同时保证怪物写深度时黑色盘面不会盖在它们前面。
- `angle` 仍按黄金角逐只错开；精英的径向振荡只改 `r`，不改变环的朝向。

### 参数

| 参数 | 值 | 说明 |
|---|---:|---|
| `BLACK_HOLE.RIM` | 2.0 m | 怪物停留的环半径 |
| `BLACK_HOLE.RING_FRONT` | 0.55 m | 环相对洞心的前移量 |
| `BLACK_HOLE.CENTER_Y` | 2.0 m | 洞心高度（环下沿接近地面） |
| `BLACK_HOLE.OSC_AMP` | 0.8 m | 精英径向振荡幅度 |

### 验证

- `tests/black-hole.test.mjs`：所有落点到环心距离 = `RIM`；同一竖直平面（z 相同）；y 同时出现高于/低于环心 1.2m 的点；所有点仍在黑洞正面。
- 现场：释放黑洞后，怪围绕漩涡上、下、左、右排布，不再铺成地面圆环。

## 二、精英预告本地立绘

### 为什么改

旧链路在头显上每次进店都把 GLB 离屏渲染 + 两次 `readRenderTargetPixels`：

- 会卡顿；
- 偶发整张全透明；
- 现场出现过「所有卡都变成同一只怪」的抓帧串图。

立绘是静态内容，应该在开发机烧一次，随包发布。

### 生成

```powershell
node tools/gen-portraits.mjs
```

- 用本地 Chrome headless + WebGL 渲染；
- 模型、取景半径、灯光与旧 `captureGLB` 同口径；
- 盾甲兵仍是「骑士右上 + 盾牌左下」的 2D 合成，直接烧成一张 `shield.png`；
- 产物目录：`src/assets/portraits/`。

| 文件 | 对应精英 |
|---|---|
| `knight.png` | 铁甲兵 |
| `shield.png` | 盾甲兵（骑士+盾牌合成） |
| `healer.png` | 治疗术士 |
| `ninja.png` | 忍者队长 |
| `ghost.png` | 幽灵法师 |
| `octopus.png` | 章鱼将军 |

### 运行时

- `src/content/eliteBrief.js` 的 `ELITE_PORTRAIT_URL` 是唯一映射表；`elitePortrait()` 返回 `{ url, baked: true }`。
- `src/game/enemyPortrait.js` 遇到 `baked` 只做 `new Image()` 解码，不再要求 renderer，也不碰 GLB。
- 图片失败仍回退到原有简笔画图标（`makeCardTexture` 的三级回退不变）。
- `shop.previewPortraits()` 的去重改成按 `portraitKey` 比较，避免同 URL 被排队多次。

### 打包注意

- PNG 放在 `src/assets/portraits/`，因此 `tools/cast-apk/build-apk.ps1` 的 `src → assets/game/src` 同步会**自动带进 APK**。
- 改了模型后必须重新跑 `node tools/gen-portraits.mjs`，再重打 APK；EXE 与服务器内容包不包含这组图。

## 踩坑

1. **不要用 x/z 平面角去量竖直环**：竖直后 z 不再变化，角度会全部挤在一起；应用 `right/up` 两轴。
2. **不要直接把环放在黑洞平面上**：黑色盘面会按深度盖住一部分怪；保留 0.55m 前移。
3. **不要在头显上重新抓帧**：静态图已经随包，抓帧只会重新引入卡顿与串图。
4. **盾甲兵不要和铁甲兵共用 `knight.png`**：必须用单独的 `shield.png` 合成图，否则两张卡看起来一模一样。

## 验证

- `npm test`：465 项全部通过。
- 商店第 3 关：铁甲兵 / 盾甲兵 / 治疗术士 / 忍者队长四张图的模型各不相同，盾甲兵同时有骑士和盾牌。
- 第 9 关：幽灵法师 / 章鱼将军两张图正确。
