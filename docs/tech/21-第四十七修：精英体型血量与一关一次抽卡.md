## 2. 精英强化（体型 / 血量 / 出生距离与速度）

### 2.1 参数表（`src/core/constants.js` 的 `ELITE_TUNING`）

| 键 | 值 | 说明 |
|---|---|---|
| `SIZE_MUL` | `3` | **总体型**倍数：模型 / 占位 / 盾 / 血条 / 命中球一起放大，且**覆盖**敌种自带的 `scale`（名牌按倒数缩回原大，见 §2.3） |
| `SPAWN_DIST` | `24` | 出生距离（米）：原 `15`（`waves._eliteSpawnPositions` 里写死） |
| `SPAWN_SPREAD` | `9` | 出生点横向散布（米）：原 `6`；同时把「避让半径」也乘 `SIZE_MUL`，3 倍体型的怪不会叠一起 |
| `TRAVEL_SECONDS` | `10` | 「10 秒」基准 |
| `TRAVEL_FRACTION` | `2/3` | 10 秒内走过的路程比例 ⇒ 余下 1/3 再走 5 秒到场 |
| `HP_MUL` | `2` | **末尾批**血量基准：本批基础血量之和 × 该系数（再被下面两行夹住） |
| `HP_MIN_SECONDS` | `2.5` | 末尾批「纯输出秒数」下限：DPS 再高也不会一秒蒸发（仪式感） |
| `HP_MAX_SECONDS` | `6` | 末尾批「纯输出秒数」上限 ★ **可击杀保证**：再难的批也只打 6 秒纯输出 |

> ★ 第四十八修起，上表**只对「末尾精英」生效**；前面零星出现的普通精英走原生口径（体型 / 速度 / 固定血量），见 §2.5。

### 2.2 末尾批血量：`climaxEliteHp(base, batchBaseTotal, dps, tune)`

```
rawTotal = 本批基础血量之和 × HP_MUL          // 基础血量 = ELITE_BASE_HP[敌种]
target   = clamp(rawTotal, DPS × HP_MIN_SECONDS, DPS × HP_MAX_SECONDS)
HP(某只) = round(该只基础血量 × HP_MUL × target / rawTotal)
```

- **口径**：先把**整批**的「纯输出秒数」夹在 `[HP_MIN_SECONDS, HP_MAX_SECONDS]`，再按各型基础血量**成比例**摊到每一只。
  于是「一批 ≈ 打 6 秒」（上限）既是玩家追求的输出验证，也是**打不死的兜底**；上限那一行就是「可击杀保证」。
- **DPS 口径**：复用 `game._playerDPS()`（攻击力 × 多重弹道 × 真实射速，射速取自 `input._gunCooldown`
  ⇒ 连杀加速期间自动算进去），经 `waves.hooks.playerDps` 注入，waves 不反向持有 game。
- **为什么按批摊**：用户原话是「确保玩家可以打十秒」。第 4 关融合批是 3 只、第 7~17 关老脉冲一批 8~10 只，
  若只只都给满额度 → 那就是几十上百秒的活，关卡（40s 倒计时 + 清空才通关）会直接变成打不完。
- 拿不到 DPS（`_playerDPS` 异常 / 单测环境）时退回**基础血量 × HP_MUL**，不会出现 0 血或 NaN。

### 2.3 体型与名牌的「倒数缩放」

血量/体型都放大后，最容易翻车的三处（都在 `src/game/balloons.js`）：

| 坑 | 现象 | 修法 |
|---|---|---|
| `sizeMul` 与 `t.scale` **相乘** | `heart / ninja / ghost / octopus` 本来就写着 `scale:3`（第三十五修「精英怪整体放大 3 倍」）→ 3×3 = **9 倍**：忍者 `effectiveRadius` 0.6×9 = 5.4m、DepthSprite 宽 10.8m，糊脸挡满整个场地 | `sizeMul` 定为**总体型倍数**：显式 `sizeMul` 优先、**覆盖** `t.scale`（只有没传时才退回 `t.scale`）⇒ 所有精英一律 3 倍。实现见构造里的 `_explicitSize`，回归见 `tests/elite-size.test.mjs` |
| 只放大 `mesh.scale` | 看着大、**打不到**（`effectiveRadius / hitRadius` 还是原值） | `effectiveRadius = radius × sizeMul`（`sizeMul` 已含 `t.scale`），`hitRadius` 跟着它走（Boss 时代的同款教训） |
| 名牌也是 `mesh` 子节点 | 名牌被一起放大 3 倍 → 字糊脸、还飘到 9 倍高（`position.y` 是局部坐标） | 名牌 `scale / inv`、`position.y / inv`（`inv = sizeMul`）⇒ 世界尺寸与 1 倍体型完全一致（精英名牌自身世界高 0.48m，见 `ELITE_LABEL.SCALE`） |

- 血条同样是子节点 ⇒ 跟着模型一起放大（与既有 `t.scale` 行为一致，`healthBarRadius` 不用改）。
- 盾兵的盾绕骑士公转：`shieldDist` 是局部坐标 ⇒ 自动按体型等比外扩，不需要单独改。
- 现场想再夸张一点只改 `ELITE_TUNING.SIZE_MUL`（编译期常量，**要重打 APK** 才生效）。

### 2.4 速度：由「10 秒走 2/3」反推（`eliteTravelSpeed`）

```
v = SPAWN_DIST × TRAVEL_FRACTION / TRAVEL_SECONDS    // 24 × 2/3 / 10 = 1.6 m/s
```

- 速度与出生距离**同源**：以后改 `SPAWN_DIST`，节奏自动跟着走（不会变成提前到场或永远走不到）。
- 落点：`waves._eliteOpts` 把 `speed` 作为构造参数传进 `Balloon`（覆盖敌种默认速度），
  只影响精英，普通杂鱼/旧脉冲之外的怪都不受影响。
- ⚠ 第四十八修起，这条速度**只对末尾精英生效**；普通精英用敌种原生速度（见 §2.5）。

### 2.5 第四十八修：分两档 —— 只有「末尾精英」强化

**现场反馈**（2026-10-14，另一台机器实测）：
① 精英怪**永远**是 3 倍大，但需求是「每关**末尾**的精英才变大」；
② 血量根本打不死就过来了 —— 末尾确实要厚（给玩家做输出验证），可**下一关非末尾**出现时也是这么厚，
   结果玩家连清杂鱼都做不到。

**根因**：第四十七修让 `ELITE_TUNING` 对**所有**精英生效（体型 / DPS 血量 / 远距 / 定速一律套用）。
`waves.js` 里两条精英通路都走 `_eliteOpts`：脚本批（`_spawnEliteEvent`）**和** 7~17 关旧三期脉冲
（`_fireElitePhase` 的 early/mid）；连 L2 / L5 每 10s 一只的零星铁甲兵、L4 的 2 只直出，也一起变成了
3 倍大 + DPS 血量的「墙」。

**改法** —— 唯一定义：**末尾批 = 脚本事件里带 `goldReturn` 的那一批**（弹「…精英来袭」横幅 → 清场融合 → 金点 → 抽卡）。

| 档 | 判定 | 体型 | 出生 | 速度 | 血量 |
|---|---|---|---|---|---|
| **末尾精英** | `isClimaxEvent(ev)`：事件带 `goldReturn` | ×`SIZE_MUL`(3) | `SPAWN_DIST` 24m / 散布 9 | `eliteTravelSpeed` 1.6 m/s | `climaxEliteHp(...)`（§2.2 夹取） |
| **普通精英** | 其余（L2/L5 每 10s、L4 直出、旧脉冲 early/mid） | `sizeMul:1`（连敌种自带 `scale` 也压回 1） | 15m / 散布 6 | 敌种原生 `speed` | `ELITE_BASE_HP[型]`（固定值） |

- 旧三期脉冲：`_fireElitePhase` 里 `climax = phase === 'late'` ⇒ 只有后期算关卡收尾。
- 普通精英显式传 `sizeMul: 1`，是因为 `balloons.js` 的 `sizeMul` 是**覆盖**语义：
  不传就会退回敌种自带的 `scale:3`（heart / ninja / ghost / octopus），所以必须显式压 1。
- 纯函数与回归：`tests/spawn-director.test.mjs`（`isClimaxEvent` / `climaxEliteHp` 的上限·下限·比例·无 DPS 兜底）。
- 服务端也要同发：`spawnDirector.js` 是 `src/content/**` 受管路径（见 §5）。

## 3. 一关只给一次抽卡（修「一局两次选项卡」）

### 3.1 现场现象与根因

现象：精英批被击杀 → 弹选项卡 → **场上还有杂鱼在生成** → 清完之后**又弹一次选项卡**。

根因（第四十六修留下的三条叠加）：

1. `_updateEliteWatch` 只盯**精英层**（mini / skill / support）：精英一死就发金点，此时**杂鱼（trash 层）还在**；
2. 金点落地 → `_enterMidCard()` 开一次中途抽卡（不推进关卡）；滴流继续补杂鱼；
3. 清完杂鱼 + 到本关倒计时 → `waves.cleared` 成立 → 又走「通关抽卡」（`_enterCard()`）⇒ **第二次**。

### 3.2 改法（三处，互相独立）

| # | 改动 | 位置 |
|---|---|---|
| ① | 金点批清空时**顺手清掉场上全部非精英 + 停掉本关杂鱼滴流**（`_clearTrash()` + `_dripStopped`） | `waves._updateEliteWatch` / `_refillDrip` |
| ② | 新增 `game._draftsThisLevel`，`_enterCard()` 每次开卡 +1；`_enterMidCard()` 发现本关已开过就**不重复开** | `game._enterCard` / `_enterMidCard` |
| ③ | 通关分支：本关已开过卡 → **跳过开卡，但照常推进关卡**（`_onCardDone()`），`_levelClearHeld` 同理 | `game._updatePlaying` / `_onMidCardDone` |

要点：**不能简单地把通关抽卡删掉** —— `_onCardDone()` 里才是 `levelIndex++` 与加载下一关；
所以「跳过」必须走「推进但不开卡」，否则会卡在本关。

### 3.3 一关一次之后的节奏

| 关 | 之前 | 现在 |
|---|---|---|
| 1 / 2 / 4 / 5（有脚本） | 精英清场一次 + 通关一次 = **2 次** | 精英清场那次（卡池/必出卡与通关一致），通关**静默推进** = **1 次** |
| 3 / 6 / 9 / 12 / 15 / 18 | 通关一次 | 不变（这些关没有金点批） |
| 7 / 8 / 10 / 11 / 13 / 14 / 16 / 17（旧三期脉冲） | 通关一次 | 不变（`ELITE_SCHEDULE` 不登记金点批） |

## 6. 踩坑与未决

- **别把「跳过通关抽卡」写成「不推进关卡」**：`_onCardDone()` 是唯一的 `levelIndex++` 出口（见 §3.2 ③）。
- **`sizeMul` 是「覆盖」不是「相乘」**：`heart / ninja / ghost / octopus` 自带 `scale:3`，两者相乘是 **9 倍**；现场若发现精英「大得离谱」，先查这条（回归：`tests/elite-size.test.mjs`）。
- **别只放大 `mesh.scale`**：第 38 修（第 18 关 Boss）踩过一次「看着大、打不到」，这次连 `hitRadius` 一起放大。
- **名牌的局部坐标**：`position.y` 是 mesh 局部坐标 ⇒ 放大体型后必须除回 `sizeMul`，否则飘到天上去。
- **别让「强化」撒到普通精英头上** ★：第四十七修就是全量套用 → 中段精英也变 3 倍大 + DPS 血量的墙，
  玩家长时间被堵、连清杂鱼都做不到。判据只有 `goldReturn`；普通精英必须显式 `sizeMul: 1` + 固定血量（见 §2.5）。
- 第 7~17 关仍是**旧三期脉冲**（未按三层骨架重排），但只有 `phase === 'late'` 吃末尾强化，
  early/mid 已回到原生口径；等骨架重排那批一起调更合适（见 `docs/tech/20` §9）。
- **普通精英显式 `sizeMul:1` 也会改到 7~17 关的 `ghost / heart / ninja / octopus`**：
  这几种敌种自带 `scale:3`（第三十五修「精英怪整体放大 3 倍」），压回 1 倍后它们比之前**小 3 倍**。
  这是「除了末尾一律正常大小」这条规则的直接后果；若现场觉得它们太小不像精英，
  把 `waves._eliteOpts` 的 `!climax` 分支里 `sizeMul: 1` 去掉（退回敌种自带 `scale`）即可，
  方向相反也只需改这一处。
- 末尾精英血量**随玩家 DPS 浮动**：同一关不同构筑下硬度不同 —— 这是用户明确要的口径；
  但它被 `[HP_MIN_SECONDS, HP_MAX_SECONDS]` 夹住，所以「越强越难打」不会失控成打不死的墙。
  现场若想更硬/更软，只改 `HP_MAX_SECONDS` 即可。
