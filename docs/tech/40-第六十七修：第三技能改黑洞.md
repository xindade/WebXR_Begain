# 第六十七修：第三技能改黑洞（吸附 / 精英振荡 / 飞毯弧线）

> 现场目标：把第 3 关第三个技能选项卡的「散射强化」换成「黑洞」。
> 原始描述：在玩家面前 15 米处生成一个黑色旋转漩涡，将所有怪朝这个方向吸引，持续 6 秒。
> 小怪最先被吸过去（1 秒），精英随后（2 秒）；小怪到位后完全静止，精英表现为「向前挪一点又被拉回去一点」，循环往复。
> 难点：怪物被吸过去时可能经过玩家飞毯 —— 既要表现吸力，又不能让玩家受伤。

---

## 1. 现场已确认的 6 条口径

| # | 口径 | 落点 |
|---|---|---|
| 1 | 伤害 **20/秒**，靠近洞心才受伤 | `BLACK_HOLE.DPS=20`、`DAMAGE_RADIUS=3.5`、`TICK=0.5` |
| 2 | **Boss 免疫** | `isBlackHoleImmune()`：`isBoss / isDragonPart / invincible / 受控 Boss 实体` |
| 3 | 方向取**释放瞬间的头部朝向** | `camera.getWorldDirection()` → 水平投影 → 洞心锁定，之后转头不跟随 |
| 4 | 被吸期间**暂停攻击** | `Balloon._updateBehavior()` 顶部 `if (this._bhCaptured) return;` |
| 5 | 6 秒结束后**原地放回** | `_endBlackHole()` 只清标 + 恢复 `moveFrozen`，不重置位置 |
| 6 | 默认技能「能量散射」**保留** | 只替换 `SKILL_CARDS` 里的 `scatterburst`，`scatter` 分支原样保留 |

## 2. 数值与时间线

| 参数 | 值 | 说明 |
|---|---:|---|
| `DIST` | 15 m | 洞心距玩家（水平距离） |
| `CENTER_Y` | 2.0 m | 洞心高度：竖立漩涡下沿贴地 |
| `RIM` | 2.0 m | 怪物停留的洞缘半径（避免糊在漩涡中心挡视线） |
| `DURATION` | 6 s | 吸附总时长 |
| `COOLDOWN` | 12 s | 6 s 控制 + 6 s 空窗 |
| `PULL_BASIC` | 1.0 s | 小怪吸附到位时间 |
| `PULL_ELITE` | 2.0 s | 精英（含末尾精英）吸附到位时间 |
| `OSC_AMP` / `OSC_PERIOD` | 0.8 m / 1.2 s | 精英径向振荡幅度 / 周期 |
| `DPS` | 20 | 每秒伤害（× `player.skillDamageMul`） |
| `DAMAGE_RADIUS` | 3.5 m | 伤害圈（罩住洞缘） |
| `TICK` | 0.5 s | 每跳 10 点，避免每帧刷伤害数字 |
| `ARC_HEIGHT` | 4.0 m | 掠过飞毯时的过顶弧线高度 |

时间线：

```
0s        释放：扣 skillCost 能量、锁洞心/朝向
0~1s      小怪 smoothstep 吸到洞缘 → 完全静止
0~2s      精英吸到洞缘（比小怪慢一倍）
1~6s      精英径向振荡：RIM → RIM+0.8 → RIM（每 1.2s 一轮）
每 0.5s   洞心 3.5m 内结算 10 点伤害（Boss 免疫）
6s        清标、恢复 moveFrozen、原地放回、销毁漩涡
```

## 3. 关键实现

### 3.1 释放：头部朝向 + 释放瞬间锁定

`game._startBlackHole()`：

```js
const head = cam.getWorldPosition(new THREE.Vector3());
const dir  = cam.getWorldDirection(new THREE.Vector3()); // 相机这份已经是真实朝向
dir.y = 0;
if (dir.lengthSq() < 1e-6) dir.set(0, 0, -1);
dir.normalize();
this._bhCenter.set(head.x + dir.x * BLACK_HOLE.DIST,
                    BLACK_HOLE.CENTER_Y,
                    head.z + dir.z * BLACK_HOLE.DIST);
```

- **不要**再对 `getWorldDirection()` 取反（three 的 `Camera` 重写了它，返回值已是视线方向）；
- 洞心位置与圆盘朝向都在这一帧锁定：释放后玩家转头/走动，漩涡不跟着动。

### 3.2 捕获：全量 + 新刷出的怪

`_updateBlackHole(dt)` 每帧遍历 `balloons.list`：

- 没有 `_bhCaptured` 且不在免疫名单 → `_bhCapture(b)`；
- 已经在吸附中 → `_bhMoveTo(b, dt)`；
- 因此 **6 秒内新刷出的怪也会被吸**（出怪光点落地那一帧起算）。

`_bhCapture` 会保存：

| 字段 | 用途 |
|---|---|
| `_bhFrom` | 起点（`Vector3`） |
| `_bhAngle` | 相对洞心的初始极角（洞缘落点） |
| `_bhDur` | 1s / 2s |
| `_bhElite` | 是否走振荡 |
| `_bhArc` / `_bhCtrl` | 是否穿过飞毯 / 二次贝塞尔控制点 |
| `_bhPrevFrozen` | 进黑洞前的 `moveFrozen`，释放时原样恢复 |

### 3.3 免疫名单

```js
export function isBlackHoleImmune(b) {
  if (!b || b.alive === false) return true;
  if (b.isBoss || b.isDragonPart) return true;
  if (b.type && b.type.invincible) return true;
  if (b.behavior === 'treasure') return true;
  if (b.controlled && b.behavior !== 'heal') return true;
  return false;
}
```

- `controlled && behavior !== 'heal'`：龙身、魔术师召唤物、脸谱 Boss、九宫格球等由 Boss 控制器逐帧接管位置的实体，**不能抢位置**；
- **治疗术士是例外**（`controlled === true` 但只是站桩）→ 允许被吸，吸附期间治疗行为同样暂停。

### 3.4 位置接管：小怪静止 / 精英振荡

```js
const u = Math.min(1, elapsed / dur);
const s = u * u * (3 - 2 * u);                 // smoothstep：起步慢、末端快
const hold = Math.max(0, elapsed - dur);
const rimR = elite ? blackHoleEliteRadius(hold) : BLACK_HOLE.RIM;
const ang  = angle + (elite ? 0.35 * hold : 0); // 精英缓慢绕洞心转，避免完全叠死
```

精英振荡公式：

```js
r = RIM + OSC_AMP * 0.5 * (1 - cos(2π · hold / OSC_PERIOD))
```

`hold=0` 时正好在 `RIM`（不会瞬移），半周期到 `RIM+0.8`，整周期回到 `RIM`。

### 3.5 飞毯难题：三层处理

1. **逻辑层（必须）**：被抓的怪打 `_bhCaptured` 标 →
   - `game._checkExplosions()` 直接 `continue`：**不结算 4×8 自爆**；
   - `isBombMarkTarget()` 排除：不显示「爆」字、不触发内圈滴滴；
   - `_updateBehavior()` 顶部 return：不扔弹、不闪现、不跳跃；
   - `_applySeparation()` 跳过：不被分离力推离洞缘。
2. **视觉层**：起点→洞心的线段若穿过飞毯带（`|x| ≤ BOUND_X+r`、`|z| ≤ BOUND_Z+r`），
   改走**过顶二次贝塞尔**：控制点抬高 `ARC_HEIGHT=4m`，怪物从头顶飞过，不从飞毯里穿过去。
3. **判定函数**：`segmentCrossesCarpet()` 用 Liang-Barsky 裁剪（纯 2D XZ），
   不依赖渲染、可单测；只有真正穿过才走弧线，其余直飞（省得每只怪都画大弧）。

> 关键坑：`_checkExplosions()` 只看 `|x|/|z|`，**不看高度**。
> 如果不加 `_bhCaptured` 跳过，过顶弧线经过飞毯上方时仍会被判「入侵」→ 玩家莫名其妙掉血。

### 3.6 伤害

```js
const dmg = BLACK_HOLE.DPS * BLACK_HOLE.TICK * (player.skillDamageMul || 1); // 10 × 倍率
```

- 只结算距洞心 `DAMAGE_RADIUS=3.5m` 内的怪（“靠近了才会受伤”）；
- `takeDamage(dmg, true)`：`ignoreReduction=true`，与激光剑同口径；
- 伤害数字走 `damageNumbers.spawn()`；击杀统一走 `game._onKilled()`（积分 / 商店币 / 金点 / 击杀音都复用既有链路）；
- **不逐怪播命中音/震动**：20 只怪 × 2 跳/秒会糊成一片；释放瞬间由 `audio.playBlackHole()` 播一次低频下坠音。

### 3.7 视觉

`src/game/blackHole.js` 的 `BlackHoleFx`：

- 程序化 Canvas 漩涡贴图（5 条螺旋臂 + 径向紫光），不引入任何新素材；
- 3 个 mesh / 3 次 draw call：纯黑核心（普通混合）+ 加色螺旋面片 + 紫色吸积盘圆环；
- 竖立圆盘，`lookAt(viewer.x, center.y, viewer.z)` 保证严格垂直地面；
- `update(dt)` 只做旋转 / 呼吸缩放 / 圆环透明度，无粒子、无每帧 new。

## 4. 踩坑记录

1. **`fixedSkills` 是旧分支**：第 3 关现在是商店关，技能本体由 `SKILL_CARDS` 在商店正前方出售；
   `_enterCard()` 里的 `fixedSkills` 分支已不可达，但一并改成 `blackhole`，避免以后切回旧流程时口径不一致。
2. **`moveFrozen` 不能无脑置 false**：教学关精英会用它做「暂停移动」；
   所以捕获时存 `_bhPrevFrozen`，释放时恢复原值。
3. **`controlled` 不能一概而论**：治疗术士也是 `controlled`，但它只是站桩，必须允许被吸；
   其余 `controlled` 都是 Boss 控制器接管，抢位置会把 Boss 演出弄坏。
4. **击杀链会改数组**：伤害节拍遍历 `balloons.list.slice()`，每次结算前再 `includes()` 复核，
   与如来神掌/激光剑同口径，防召唤者/脸谱子实体连锁删除导致重复结算。
5. **不要在每帧结算伤害**：20 只怪 × 72fps 会把伤害数字纹理上传打爆；0.5s 一跳是性能与可读性的平衡点。
6. **`scatterburst` 常量与方法保留**：`SCATTER_BURST` 仍被子弹池容量测试引用；
   `_castScatterBurst()` 变成不可达死代码，但删掉会牵连测试与历史口径，暂留。

## 5. 验证

### 单测（`tests/black-hole.test.mjs`，16 项）

- 参数口径：15m / 6s / 20 DPS / 1s·2s；
- 免疫名单真值表（Boss / 龙部件 / 无敌 / 受控 / 治疗术士）；
- 精英振荡公式：0 → RIM、半周期 → RIM+AMP、整周期 → RIM；
- 飞毯穿越判定：穿 / 不穿 / 斜插擦边；
- 释放锁定：相机 -Z → 洞心 `(0, 2, -15)`，转头不移动；
- 吸附节奏：小怪 1s 到洞缘并静止、精英 1s 还在路上/2s 到位；
- Boss 原地不动、不吃伤害；
- 6s 到期原地放回、恢复原 `moveFrozen`；
- 伤害节拍：3.5m 内每 0.5s 扣 10、远处不掉血、Boss 免疫、倍率生效、击杀走 `_onKilled`；
- 被吸怪不显示「爆」、不结算自爆；
- 被吸的治疗术士暂停治疗光环（`_applyHealAura` 跳过 `_bhCaptured`）；
- 技能表不再卖 `scatterburst`、冷却 12s、装备后左手剑收起。

### 上机自测清单

1. 第 3 关商店买「黑洞」→ 左手柄侧键释放，正前方 15m 出现紫色漩涡；
