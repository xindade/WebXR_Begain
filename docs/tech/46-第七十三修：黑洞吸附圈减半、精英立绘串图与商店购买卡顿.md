# 第七十三修：黑洞吸附圈减半、精英立绘串图与商店购买卡顿

## 现场反馈

1. 黑洞吸附的小怪没有留出中心点，围成的圈要再缩小一半。
2. 第 3 关精英预告又变成「铁甲兵 / 盾甲兵 / 盾甲兵…」，后面全是盾甲兵；第 9 关也要一起检查。
3. 商店里选中并购买后会卡一下。

## 修复

### 1. 黑洞吸附环半径与视觉半径解耦

- `BLACK_HOLE.RIM` 继续作为黑洞漩涡 / 吸积盘的视觉半径（2.0m），不再兼作怪物吸附半径。
- 新增 `BLACK_HOLE.ABSORB_RIM = 1.0`，怪物围成的竖直环正好是视觉半径的一半。
- 吸附环仍使用 `right × cos + worldUp × sin` 的竖直平面，并保留 `RING_FRONT = 0.55m`，怪物位于黑盘朝向玩家的一侧，不被深度遮挡。
- 精英到位后的径向振荡也改用 `ABSORB_RIM`，不会再膨胀回旧洞缘。

### 2. 精英预告串图

根因有两层：

- 服务器 `content/1.0.0/src/content/eliteBrief.js` 还是旧版本，仍下发 GLB 路径；APK 启动后会优先使用服务器覆盖层，覆盖掉 APK 内的本地 PNG 逻辑。
- 旧运行时 GLB 抓帧在头显上会复用错误的模型/缓存，表现为多张卡都变成同一只怪。

修复：

- 客户端 `enemyPortrait.js` 增加旧式 GLB spec 到本地 PNG 的强制映射：
  - 骑士 → `knight.png`（带盾牌模型 → `shield.png`）
  - 心形怪 → `healer.png`
  - 忍者 → `ninja.png`
  - 幽灵 → `ghost.png`
  - 章鱼 → `octopus.png`
- 即使服务器还下发旧内容包，APK 也只解码本地 PNG，不再运行时抓 GLB。
- 已重新发布服务器内容版本 `1.0.0`，`eliteBrief.js` 与本地逐文件 sha256 一致。

### 3. 商店购买卡顿

旧流程在购买动画结束后调用 `_build()`：先销毁店里全部卡片的 geometry / material / CanvasTexture，再重新创建 8 张卡并上传贴图，头显上会出现一帧明显停顿。

修复：

- `ShopDraft` 改为按区（技能区 / 道具区）和稳定身份（技能 id、道具槽位）增量同步。
- 已存在的卡复用 holder、mesh、material、CanvasTexture，只更新位置、价格和文案。
- `cardDraft.repaintCardTexture()` 直接在原 canvas 上重绘并置 `needsUpdate`，不换纹理对象、不重编译 shader。
- 被买走的道具槽补位时只重绘该槽；技能买完后只移除对应升级卡。
- 精英预告立绘到位时也只重绘对应的一张卡，不再每来一张图就重建整列。
