## 0. 一句话结论

**金点观察改成按「批」判定；精英名牌分两套（冰蓝 / 金红 + Boss 后缀）；每关开局在准星前弹一张标题卡。**

- 观察：`waves._eliteWatch` 从「按层」改成「按 `batchId`」—— 只有这一批自己生成的怪能算数。
- 名牌：`ELITE_LABEL`（普通精英，冰蓝）与 `BOSS_LABEL`（末尾精英，金红 + `CLIMAX_SUFFIX`）分开配置，
  绘制代码共用一份。
- 标题卡：名字写在 `content/levels.js` 的 `lv.name`（**唯一来源**），开局 `LEVEL_TITLE.DELAY` 秒后
  在准星前方弹 `第 N 关 · 场景名`。

## 1. 修「普通精英被打死就弹选项卡」（第 4 关）

### 1.1 现场现象

第 4 关 20s 的普通精英（两只铁甲兵）被打死时，**末尾精英刚出来**（还在融合光点里飞），
选项卡就弹了出来 —— 金点抽卡提前触发。

### 1.2 根因：观察条目按「层」，而两批同层

`waves._spawnEliteEvent` 每批精英都会压一条观察条目，旧实现记的是 `layer`：

```js
// 旧（第四十六~四十八修）
this._eliteWatch.push({ layer, gold: !!ev.goldReturn, seen: false, t: 0, hold: ev.via === 'merge' });
// 判定
const alive = this._countLayer(w.layer);      // ← 数的是「这一层还剩几只」
```

第 4 关的两批**都是 mini 层**（`eliteKnight` / `shield` 都映射到 mini）：

| 批 | 时间 | 组成 | 出现方式 | goldReturn |
|---|---|---|---|---|
| 普通批 | 20s | 铁甲兵 ×2 | portal（每只直飞） | ✖ |
| 末尾批 | 30.7s | 铁甲兵 ×2 + 盾甲兵 ×1 | merge（清场融合） | ✅ |

于是：20s 那两只（同层）先落地 → 末尾批的条目被它们顶成 `seen = true`；
玩家在融合演出（in 0.9s + out 0.55s ≈ 1.45s）期间把这两只打死 → `_countLayer('mini') === 0`
→ 判定「本批已清空」→ `goldToCards()` → **选项卡在末尾精英落地之前就弹了**。

### 1.3 改法：观察对象改成「这一批」

```js
// waves._spawnEliteEvent
const batch = ++this._eliteBatchSeq;                        // 每批一个唯一编号
if (ev.goldReturn) this._eliteWatch.push({ batch, seen: false, t: 0, hold: ev.via === 'merge' });
```

- 编号沿三条落地路径传到气球：`_queueElite`（光点入队）→ `Balloon.batchId`；
  融合批额外存进 `_fuseGroups[].out.batch`，落地时传给 `_spawnEliteNow`。
- `_countBatch(batch)` 只数 `b.alive && b.batchId === batch` 的气球。
- 只有末尾批才压观察条目（普通批本来也不需要金点），顺便去掉了旧代码里的 `if (!w.gold) continue`。

> `capOnField`（同层上限）仍然按层计数 —— 那是「控节奏」用的，语义本来就是层，不要改成批。

## 2. 顺带修掉：无传送门时精英会丢配置

`waves._queueSpawn` 有三条「直接落怪」的兜底分支（`effect === false` / 无传送门 / 找不到最近的传送门），
它们调 `_commitSpawn` 时**只带 `onSpawn`，把 `opts.balloon` 丢了**：

```js
// 旧：精英会退化成「杂鱼血量 + 不挂名牌 + 1 倍体型」
return this._commitSpawn({ type, pos, onSpawn: opts.onSpawn });
```

正常关卡都有传送门，所以这条路径平时走不到；但只要传送门没建好（`PORTAL_BEAM.ENABLED=false`、
`getPortals()` 拿不到、刚切关的那几帧），精英就会静默掉档。现在三处都改成：

```js
return this._commitSpawn({ type, pos, onSpawn: opts.onSpawn || null, balloon: opts.balloon || null });
```

## 3. 名牌分两档（普通精英 / Boss）

### 3.1 文案：Boss 后缀

`content/spawnDirector.js` 新增纯函数（收「基础显示名」，与敌种表解耦）：

```js
export const CLIMAX_SUFFIX = ' Boss';
export function eliteLabelText(baseName, climax) {
  return climax ? String(baseName) + CLIMAX_SUFFIX : String(baseName);
}
```

判据沿用第四十八修：`climax` = 该批事件带 `goldReturn`（横幅 → 清场融合 → 金点 → 抽卡）。
落点 `balloons` 构造：`ELITE_DISPLAY_NAME[t.id] || t.name` 再套 `eliteLabelText`，
所以「铁甲兵」/「铁甲兵 Boss」两档文案只差一个后缀。

### 3.2 样式：两套配置，一份绘制代码

| 档 | 配置 | 视觉 |
|---|---|---|
| 普通精英 | `ELITE_LABEL` | 冰蓝外描边 + 深蓝**垂直渐变**底 + 内衬发丝线 + **四角括号**；冷色、克制 |
| 末尾精英 | `BOSS_LABEL` | 金红外描边 + 暗红渐变底 + **左右菱形**装饰 + 文字**外发光**；比普通精英大 ~28% |

绘制只有 `balloons._drawNameLabel(x, W, H, text, S)` 一份，靠配置字段分流：

```
底板    BG_TOP / BG_BOTTOM（垂直渐变）+ RADIUS（圆角）
外框    EDGE / EDGE_W
内衬    HAIRLINE / HAIRLINE_INSET
四角    CORNER / CORNER_W / CORNER_LEN / CORNER_INSET
装饰    ORNAMENT: 'none' | 'diamond'
文字    COLOR / OUTLINE / OUTLINE_W / FONT / GLOW
尺寸    CANVAS_W / CANVAS_H / SCALE / Y_PAD
```

- 所以「换个颜色、加粗、加角标、加发光」都只是改数字，不用碰绘制代码。
- **不传 style 的老用法（占位怪的白字名牌）行为完全不变**：`RADIUS` 缺省 0 → 仍是一块纯半透明底 + 白字描边，
  没有圆角也没有边框。
- ⚠ `SCALE` 的宽高比必须等于 `CANVAS_W/CANVAS_H`（两档都按 4:1），否则字会被拉扁 —— 有单测守着。
- ⚠ 名牌是 `mesh` 的子节点，仍按 `sizeMul` **倒数缩回**（第四十七修），所以「3 倍体型的 Boss」名牌
  世界尺寸只由 `SCALE` 决定，不会跟着变成 3 倍。

## 4. 关卡标题卡

### 4.1 名字放哪

`content/levels.js` 每关加一个 `name`，并导出两个纯函数：

```js
export function levelName(n)                  // 查名字；越界/没写 → ''
export function levelTitleText(n, template)   // 填 {n} / {name}；没名字 → ''
export function shouldShowLevelTitle(lv, cfg) // 总开关 / 机制关跳过 / 有名字才弹
```

**这是名字的唯一来源**，18 关的名字（2026-10-14 **第二轮现场定稿**；机制关 3/9/15 统一叫「魔术空间」）：

| 关 | 名字 | 关 | 名字 | 关 | 名字 |
|---|---|---|---|---|---|
| 1 | 落日余晖 | 7 | 云海鲲鹏 | 13 | 夕阳双糖 |
| 2 | 长夜突袭 | 8 | 血月之夜 | 14 | 云卷暴风 |
| 3 | 魔术空间 | 9 | 魔术空间 | 15 | 魔术空间 |
| 4 | 双马拱日 | 10 | 彩虹之桥 | 16 | 天梯初现 |
| 5 | 暮色极光 | 11 | 雷云密布 | 17 | 黎明之前 |
| 6 | 脸谱画廊 | 12 | 巨龙云潭 | 18 | 公主堡垒 |

> 用字建议 4 个字：标题卡按固定画布绘制，**太长会自动降字号**（92px → 最低 40px），
> 但字越小远处越难读。

### 4.2 怎么显示给玩家

**复用 `warningBanner.WarningBanner3D`，换一个 style**（`show(text, 'title')`）：

- 为什么要复用：头显沉浸态里页面 DOM 不可见（同 winBanner / 中场预警的结论），只能在场景里做；
  而该类本来就「一个 Sprite + 一张 canvas，文本/样式变了才重绘」—— 18 关各建一张标题卡
  等于白送 18 次纹理上传。
- `styleConfig(style)` 纯函数决定用哪组参数：`'title' → LEVEL_TITLE`，**其它（含不传）→ MID_WARNING**
  （所以 `_showBanner` / 中场预警这些老调用点行为不变，有单测）。
- 新样式画法：深蓝渐变底 + 冰蓝双层描边 + 左右菱形与横线 + 一行居中文字（先描边压字）；
  位置 = 准星前方 `DIST` 米再**上抬 `RISE`**（别正好压在准星上挡视线）。

### 4.3 触发时机

`game._startLevelAudio()` 末尾排一个定时（那是「穿云散开 / 关卡正式开始」的统一点）：

```
_startLevelAudio()  →  _queueLevelTitle()    // 记下文案 + _levelTitleAt = LEVEL_TITLE.DELAY
_updatePlaying()    →  _tickLevelTitle(dt)   // 倒计时到点 → midWarning.show(text, 'title')
```

- `_clearRoundExtras()`（回菜单 / 重开 / 新一局 / 切关都调）里把 `_levelTitleAt` 清零 ——
  切关时立即作废上一关没弹完的卡。
- **机制关(3/9/15) 默认不弹**（`LEVEL_TITLE.SKIP_MECHANIC = true`）：它们开局有魔术师开场动画，
  标题卡会叠在动画上。想强行显示改 `false`。
- ⚠ 标题卡与「精英来袭 / 中场预警」**共用同一个 Sprite**，所以时间窗必须错开：
  标题在开局 `DELAY(0.8) ~ 3.6s`，脚本里最早的精英横幅在 5s（第 2 关）。
  若日后要同屏同时显示两者，得再建一个实例。

## 5. 重打包边界（**本轮必须重打 APK + 重发服务器内容**）

| 改了什么 | 重打 EXE | 重打 APK | 服务器内容 |
|---|---|---|---|
| `src/game/*.js`、`src/core/constants.js`、`src/content/levels.js` 的 `name` | ✖ | ✅ | — |
| `src/content/levels.js`、`src/content/spawnDirector.js` | ✖ | ✅ | ✅ **必须** |

> `src/content/**` 是受管路径（客户端对它是「只认服务器下发、不回落 assets」）——
> 只重打 APK 不发内容，头显拿到的还是旧 `levels.js`（没有名字）/ 旧 `spawnDirector.js`（没有 `CLIMAX_SUFFIX`），
> 标题卡与 Boss 后缀都不会出现。两件一起做：
> ```
> tools\cast-apk\build-apk.ps1
> powershell -ExecutionPolicy Bypass -File tools\deploy-content.ps1 -DryRun   # 先看差异
> powershell -ExecutionPolicy Bypass -File tools\deploy-content.ps1
> ```

## 6. 踩坑与未决

- **别把层计数改成批计数**：`capOnField`（同层上限）与 `MAX_ELITES`（同屏精英上限）是「控节奏」，
  按层/全局计数才对；只有「金点该不该发」才按批。
- **别在 `_queueSpawn` 的兜底分支丢 `opts.balloon`**：丢一次就是精英掉一档（血量/体型/名牌全没），
  而且平时走不到、只在没门的那几帧炸（见 §2）。
- **名牌的两套样式是「配置」不是「分支」**：想再分一档（例如机制关守关怪）只需再加一组常量。
- **`SCALE` 与画布宽高比必须一致**（4:1），否则字被拉扁 —— 单测 `level-title-label.test.mjs` 守着。
- **标题卡与精英横幅共用 Sprite**：两者的时间窗不能重叠（见 §4.3）。
- 未决：18 关的名字是**暂定**的，等现场确认（改名只动 `content/levels.js` 一张表）。
- 未决：机制关(3/9/15) 的标题卡默认不弹（被开场动画挡），若现场想要，改 `SKIP_MECHANIC = false`
  或把它延后到开场演出结束之后再弹（需要接 `openingModel` 的结束回调，本轮未做）。
