# WebXR 打气球 · 技术文档索引

> 本文档集面向「从零复现 / 移植」场景：把本项目里**无法一次做对、必须反复调试**的关键技术，
> 按主题拆成独立文档。每篇统一结构：**目标 → 原理 → 关键实现 → 参数表 → 踩坑（多次调试点） → 验证方法**。

---

## 1. 项目概况

| 项 | 值 |
|---|---|
| 形态 | WebXR VR 射击肉鸽（打气球），纯静态站点 |
| 目标设备 | PICO 4（SoC：Adreno XR2，浏览器内核 Chrome 105） |
| 渲染 | Three.js r168，`importmap` 把 `three` 指到本地 `vendor/three.module.js` |
| 工程形态 | **纯静态 ES Modules，无构建步骤、无 node_modules**（`vendor/` 本地化依赖） |
| 输入 | 双 6DoF 手柄（WebXR `xr-standard`）；桌面回退 WASD + 鼠标 |
| 性能预算 | 72 fps（头显），因此纹理/分辨率/胶水层都按此裁剪 |
| 关卡 | 18 关：普通(1/4/7/10/13/16) / 危机(2/5/8/11/14/17) / Boss(6/12/18) / 激光机制(3/9/15) |

**为什么这份文档值得单独存在**：本项目几乎每个子系统都踩过「看起来能跑、实机必翻车」的坑
（控制器左右手、PICO 摇杆轴向、EXR 色彩空间、离屏捕获空图、视频解码×编码争用……），
这些结论都是实机实测得到的，照抄代码不等于能跑对。

## 3. 模块依赖关系

```
constants.js（全部可调参数：MOVE / SHOOT / SKY_* / DEPTH_SPRITE_* / WRIST_UI / WAITING_ROOM / CAST …）
   │
   ├─ 01 VR 输入 ── input.js ──► world.camera / world.renderer.xr / rig
   ├─ 02 调试日志 ─ pagelog.js（经典脚本，独立）
   │                wrist-ui.js ──► 挂在 input 的 grip 上
   ├─ 03 模型优化 ─ glbCache.js ──► GLTFLoader + DRACOLoader(vendor/draco)
   │                glbCapture.js ──► depthSprite.js（GLSL3 材质）
   ├─ 04 天空盒 ─── world.js（渐变 ShaderMaterial + 全景穹顶 + EXRLoader）
   ├─ 05 打包 ───── tools/cast-pc（Electron）/ tools/cast-apk（Gradle + NanoHTTPD）
   ├─ 06 视频 ───── waitingRoom.js ──► VideoTexture / CanvasTexture ──► world.setAmbientVisible
   ├─ 08 授权 ───── tools/cast-server（license 签发）/ tools/cast-pc（licenseGate，**默认关闭**）
   └─ 09 清单 ───── sync-content.js ──► /api/manifest ──► tools/cast-pc userData/manifest ──► 头显 overlay
```

## 4. 建议阅读顺序

1. **先读 01**：输入是所有交互的入口，理解 `rig / camera / controller` 三级关系后，其余模块更好定位。
2. **再读 02**：调试日志是后续所有实机调试的工具，先布好「眼睛」。
3. **03 / 04 可并行**：一个管「模型怎么进场景」，一个管「场景长什么样」。
4. **06** 依赖 05 的打包形态（影片阶段要通知 PC 端），建议在打包之后读。
5. **05 最后实操**：打包是发布动作，代码稳定后再做。
6. **11** 独立小专题（抽卡必出卡 + 开场演出对齐），可随时单读。
7. **12** 第 18 关 Boss 专题（开场演出 + 召唤池）：上机调「念白高度 / 起飞时刻 / 召唤手感」时对照它的参数表。

## 5. 「必须多次调试」的清单（各文档都收录，此处汇总）

| 主题 | 一次做对会翻车的点 |
|---|---|
| VR 输入 | 控制器左右手**不能按索引**（PICO 不保证 0=左）；PICO 摇杆在 `axes[2]/[3]` 且前推为负；瞄准方向是**本地 −Z**（`getWorldDirection` 给的是 +Z=背后）；控制器要挂 `rig` 而非 `camera`；按键必须做**边缘检测** |
| 调试日志 | 日志脚本必须是**经典脚本（非 module）**才能早于业务模块加载并捕获加载期报错；沉浸态 DOM 不可见 → 必须有头显内面板 |
| 模型优化 | Draco 解码器要**离线本地**；克隆必须重绑骨骼；`fitToRadius` 必须**先缩放再居中**；离屏捕获要判空并回退；深度图是**数据**不能 sRGB 解码 |
| 天空盒 | **不能**用 `scene.background` 的 equirect（绕过各向异性 → 糊）；EXR 走线性（`NoColorSpace`）；穹顶要转 yaw 对齐正前；各向异性钳到 4 |
| 打包 | EXE 的 `asar:true` → 改渲染层必须重出 EXE；APK 的 assets 是**拷贝**，改 JS 后要重跑同步；Gradle/JDK 版本敏感 |
| 视频播放 | 沉浸态 DOM 不可见 → 必须纹理化；`<video>` 只能**一个消费者**；自动播放被拦要静音重试；**解码 × 编码争 VPU** → 影片期间不推流；必须三重兜底防软锁 |
| 授权 / License | 「生成密钥」≠「签发凭据」；静态凭据可被拷贝转发（需 PoP 绑实例私钥）；共享密钥**不可能**藏进「要给头显看」的凭据；Ed25519 在 `minSdk 24` 不可用（选 P-256）；Node 对 ECDSA 默认输出 **DER**（与 Java 天然对齐，勿设 `ieee-p1363`）；离线兜底常开会架空授权服务器 |

| 端口 fallback（第三十七修） | `server.listen(port, cb)` 的 cb 在 **EADDRINUSE 时不会被摘掉**，重试成功会「新旧回调一起触发」⇒ 初始化跑两遍（本项目里就是 `ipcMain.handle` 重复注册 → 主进程弹「Attempted to register a second handler for 'cfg:get'」），且第一遍已按旧端口建好窗口 ⇒ 窗口连到**占用 8443 的别人**、服务却在 8444。修法：失败即 `removeListener('listening', …)` + `done` 只回调一次；见 `tools/cast-pc/lib/net-listen.cjs`、`tests/listen-fallback.test.mjs` |
| 抽卡 / 开场演出（第三十六修） | 「必出卡」会被 `availableAttributes` 的**满级过滤**静默吃掉（现场表现为「偶发不出」）→ 必出卡必须带「一张都不可用」时的退化路径；异步 `ended` 回调**切关后仍会触发** → 必须用自增序号作废，否则会把新一关的演出收掉；收场一律 `dispose()`，`visible=false` 等于没消失 |
| 第18关 Boss 演出与召唤（第三十八修） | 「按剩余时间反推出生距离」= 全波怪在**阶段结束那一刻同时抵达自爆**（要么零威胁、要么秒杀，没有中间态）；`_clampToRing` 锁住忍者 ⇒ 忍者**永不自爆、只增不减**；只改 `mesh.scale` 不改 `radius/effectiveRadius/hitRadius` ⇒ 巨物「看着大、打不到」；「场上数量」必须算上**在飞的光点**，否则光点落地前每帧都触发补满 |
| 服务器清单（第二十四修） | 「**启动无条件先清**」才是主防线 —— 平台关局是 `kill`，`before-quit` 不会执行；清单缓存先落 `.tmp` 再 `rename` **原子替换**；清单不可用时**绝不回落**本地旧文件（应急才 `--local-content`）；`ver` 指定了就必须命中，**不回落 `current`**；头显启动清理要留 `if (!passThrough)` 例外（否则把玩家当场踢出 VR） |

| 平台二次拉起（第二十六修） | 平台的「启动游戏」会在 ~20s 后**重发整套**（含 `kill`）⇒ 头显侧会换进程；「免打扰」判据原先只存在**进程内**（`sLaunched` / `lastPageHitMs`）→ 新进程判据全空 → 建 2D 窗口 → PICO 弹「退出PICO浏览器」并挤掉 XR 会话。修法：**页面在场证据跨进程落盘**（`PagePresence`，6s 内打点 / 90s 内打点且 `xr=1` 都算活）+ 页面在 XR 里时**不发任何前台动作**只 `finish()` + 5s 兜底复核 |
| 曳光与神掌（第四十二修） | 曳光是**定长后拖**，而子弹出生点在**枪管内部**（`SHOOT.SPAWN_OFFSET`）—— 不同步限制后拖长度就会「光从枪管屁股漏出来」；伤害数字是**对象池 + canvas 贴图**，一掌几十只怪同帧 `spawn` = 几十次纹理上传 ⇒ 必须**上传节流 + 分帧结算**；节流后**未上传的条目必须隐形**（否则池复用会露出上一只怪的旧数字）；`spawn()` 里赋 `opacity` 必须在 `_draw()` **之后**；枪管挂点不能用 `Box3.setFromObject`（那是世界坐标，枪会随玩家动） |
| 红点环与神掌朝向（第四十三修） | 「集齐」判据**不能看连杀数**（`game` 在触发那一帧就把计数清零，计数器永远看不到 10）→ 看 `_rapidUntil` 是否变化；`InstancedMesh` **没有逐实例 visible**，隐藏只能写零缩放矩阵；加色混合下淡出只能**调暗实例色**（改共享材质 `opacity` 会触发着色器重编译）；`mist.instanceColor` 必须构造时就建；`?aim=` 解析不能写 `Number(q.get(k))`（取不到是 `null`，`Number(null)=0` 会把「没写这轴」误当成 0） |
| 神掌翻面 / 技能框计数 / 开场黑边（第四十四修） | 闩锁判据**不能用「相邻帧方向点积」**：它只识别「急转弯」，识别不出「已经绕到背后」—— 相机不在掌图飞行线上时（掌图沿 y=0、相机 y≈1.6）方向永不掉头 ⇒ 判据形同虚设（旧单测把相机放原点，所以「看起来是对的」）；正确判据是「掌图中心 − 相机」在**飞行轴**上的投影符号；`renderer.compile`（r168）对**材质**走 `scene.traverse`（不看 visible，预热不必显示出来）、对**灯光**走 `traverseVisible`，且第三参 `targetScene` 必须是真场景（`renderStates.get(targetScene)`）—— 但**绝不能**顺手对整个场景 compile（那本身就是影片里的一次卡顿）；贴边框的方块会压到底部文字（基线从 `h-26` 抬到 `h-42`） |
| 神掌固定朝向 / 分帧构建 / EXE 调角（第四十五修） | **冻结一个本来就错的姿态没有意义** —— 「每帧朝相机」用 `setFromUnitVectors` 走**最短弧**，会把相机方向的 `+Y` 分量解成**绕飞行轴的倾角**（相机 y≈1.6、掌图 y=0 ⇒ 必然存在），所以冻下来的永远是斜的；要钉死的是**回转量**，不是冻结时机。切关卡顿同源：`CloudFx` 原先**自己也是从 0 淡入** ⇒ 那一帧等于没遮 ⇒ 雾必须建在 `_sceneBefore` 快照**之前**（建在后面就会进差集、自己淡入）；差集为空时 `setFadeRoots([])` 会把 `_fadeOn` 置 false ⇒ `extendFadeRoots()` 早退 ⇒ 分帧建出的物体**啪地满显**（本修给它加了 `forceOn` 第二参）；分帧任务必须 `try/catch`，别让半成品关卡带崩渲染循环。正式包的 `userConfig.js` 会被清单**重拉覆盖** ⇒ 直接改文件没用，要「覆盖表 + 下发前套用」，且**套用后必须重算 `sha256`/`size`**（否则头显自校验失败）；`asar:true` ⇒ 改渲染层必须**重出 EXE**（`npm run dist`） |
| 三层出怪 / 清场融合 / 金点抽卡（第四十六修） | `isElite` 必须在**构造时**传入（`balloons.spawn(type,pos,opts)`）—— 名牌是在 `Balloon` 构造函数里建的，等到 `onSpawn` 才置 `isElite` 的话名牌**永远建不出来**（旧 `_fireElitePhase` 就是这么写的）；光点落地前**拿不到 balloon 引用** ⇒ 批次清空只能**按层**判定（`_countLayer`）；`SPAWN_LAYER.MAX_ELITES` 只能是「安全网」（设 3 会让第 4 关 30s 那批被上限吃掉）；`getWorldDirection` 返回 **+Z**（相机前向是 −Z）⇒ 金点起点忘了取反会从**脑后**飞出；清场后不暂停滴流等于没清（`_eliteWatch.hold` 门禁）；中途抽卡必须与通关抽卡分开（`_enterCard(mid)` + `_onMidCardDone()`，否则 `_onCardDone()` 直接 `levelIndex++` 进下一关）；换召唤类型要同步改 `_buildIntroPreloadQueue`（否则穿云窗不预热、登场首帧又卡） |
