# WebXR 打气球 · 技术文档索引

> 本文档集面向「从零复现 / 移植」场景：把本项目里**无法一次做对、必须反复调试**的关键技术，
> 按主题拆成独立文档。每篇统一结构：**目标 → 原理 → 关键实现 → 参数表 → 踩坑（多次调试点） → 验证方法**。

## 1. 项目概况

| 项 | 值 |
|---|---|
| 形态 | WebXR VR 射击肉鸽（打气球），纯静态站点 |
| 目标设备 | PICO 4（SoC：Adreno XR2，浏览器内核 Chrome 105） |
| 渲染 | Three.js r168，`importmap` 把 `three` 指到本地 `vendor/three.module.js` |
| 工程形态 | **纯静态 ES Modules，无构建步骤、无 node_modules**（`vendor/` 本地化依赖） |
| 输入 | 双 6DoF 手柄（WebXR `xr-standard`）；桌面回退 WASD + 鼠标 |
| 性能预算 | 72 fps（头显），因此纹理/分辨率/胶水层都按此裁剪 |
| 关卡 | 18 关：普通(1/4/7/10/13/16) / 危机(2/5/8/11/14/17) / Boss(6/12/18) / 激光机制(3/9/15) |

**为什么这份文档值得单独存在**：本项目几乎每个子系统都踩过「看起来能跑、实机必翻车」的坑
（控制器左右手、PICO 摇杆轴向、EXR 色彩空间、离屏捕获空图、视频解码×编码争用……），
这些结论都是实机实测得到的，照抄代码不等于能跑对。

## 3. 模块依赖关系

```
constants.js（全部可调参数：MOVE / SHOOT / SKY_* / DEPTH_SPRITE_* / WRIST_UI / WAITING_ROOM / CAST …）
   │
   ├─ 01 VR 输入 ── input.js ──► world.camera / world.renderer.xr / rig
   ├─ 02 调试日志 ─ pagelog.js（经典脚本，独立）
   │                wrist-ui.js ──► 挂在 input 的 grip 上
   ├─ 03 模型优化 ─ glbCache.js ──► GLTFLoader + DRACOLoader(vendor/draco)
   │                glbCapture.js ──► depthSprite.js（GLSL3 材质）
   ├─ 04 天空盒 ─── world.js（渐变 ShaderMaterial + 全景穹顶 + EXRLoader）
   ├─ 05 打包 ───── tools/cast-pc（Electron）/ tools/cast-apk（Gradle + NanoHTTPD）
   └─ 06 视频 ───── waitingRoom.js ──► VideoTexture / CanvasTexture ──► world.setAmbientVisible
```

## 4. 建议阅读顺序

1. **先读 01**：输入是所有交互的入口，理解 `rig / camera / controller` 三级关系后，其余模块更好定位。
2. **再读 02**：调试日志是后续所有实机调试的工具，先布好「眼睛」。
3. **03 / 04 可并行**：一个管「模型怎么进场景」，一个管「场景长什么样」。
4. **06** 依赖 05 的打包形态（影片阶段要通知 PC 端），建议在打包之后读。
5. **05 最后实操**：打包是发布动作，代码稳定后再做。

## 5. 「必须多次调试」的清单（各文档都收录，此处汇总）

| 主题 | 一次做对会翻车的点 |
|---|---|
| VR 输入 | 控制器左右手**不能按索引**（PICO 不保证 0=左）；PICO 摇杆在 `axes[2]/[3]` 且前推为负；瞄准方向是**本地 −Z**（`getWorldDirection` 给的是 +Z=背后）；控制器要挂 `rig` 而非 `camera`；按键必须做**边缘检测** |
| 调试日志 | 日志脚本必须是**经典脚本（非 module）**才能早于业务模块加载并捕获加载期报错；沉浸态 DOM 不可见 → 必须有头显内面板 |
| 模型优化 | Draco 解码器要**离线本地**；克隆必须重绑骨骼；`fitToRadius` 必须**先缩放再居中**；离屏捕获要判空并回退；深度图是**数据**不能 sRGB 解码 |
| 天空盒 | **不能**用 `scene.background` 的 equirect（绕过各向异性 → 糊）；EXR 走线性（`NoColorSpace`）；穹顶要转 yaw 对齐正前；各向异性钳到 4 |
| 打包 | EXE 的 `asar:true` → 改渲染层必须重出 EXE；APK 的 assets 是**拷贝**，改 JS 后要重跑同步；Gradle/JDK 版本敏感 |
| 视频播放 | 沉浸态 DOM 不可见 → 必须纹理化；`<video>` 只能**一个消费者**；自动播放被拦要静音重试；**解码 × 编码争 VPU** → 影片期间不推流；必须三重兜底防软锁 |
| 授权 / License | 「生成密钥」≠「签发凭据」；静态凭据可被拷贝转发（需 PoP 绑实例私钥）；共享密钥**不可能**藏进「要给头显看」的凭据；Ed25519 在 `minSdk 24` 不可用（选 P-256）；Node 对 ECDSA 默认输出 **DER**（与 Java 天然对齐，勿设 `ieee-p1363`）；离线兜底常开会架空授权服务器 |
