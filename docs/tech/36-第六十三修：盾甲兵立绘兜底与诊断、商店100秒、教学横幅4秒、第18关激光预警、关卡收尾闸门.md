## 2. 逐条拆解

### 2.1 盾甲兵立绘：先证明「链路是通的」，再把兜底与诊断补齐

**现场症状**：第 3 关商店右侧预告列里，盾甲兵那张显示的是**简笔画图标**，没有立绘。

**第一步是取证，不是改代码。** 卡面立绘不是美术图，而是**运行时把敌人 GLB 离屏渲成正视图**抓出来的
（`captureGLB` → 两次 `readRenderTargetPixels` 回读），所以「到底哪一步失败」必须真渲染才知道。
为此把之前只在仓库外跑过一次的离屏预览脚本**沉淀进仓库**：`tools/portrait-preview/`（见 §2.1.1）。

**结论（桌面端，Electron 33 + 真 WebGL）**：

```
Model/骑士.glb   抓帧成功（不透明像素 46040）
Model/盾牌.glb   抓帧成功（不透明像素 35045）
portraitCanvas(盾甲兵) 合成成功（不透明像素 31590）   ← 就是 §2.1.2 里那张图
```

也就是说 **桌面端链路本身是通的**，问题出在「头显上某一步失败时没有兜底」。

**关键实现（三处，都在 `enemyPortrait.js`）**：

1. **主/副模型各自独立兜底**：旧代码是一句
   `const main = await captureOne(renderer, spec.url);` —— 主模型（骑士）一抛，整个 IIFE 就 reject，
   外层 catch 把整卡判成 `null` ⇒ 卡面回退简笔画。**现场看到的「图标」就是这条路径。**
   现在两个模型各自 `try/catch`，只有 `!main && !side` 才回退整卡。
2. **盾牌抓不到 → 左下角画「盾」简笔画**：只画骑士的盾甲兵卡和**铁甲兵卡长得一模一样**
   （第五十七修踩过同一个坑）。所以 `composePortrait` 新增第 6 个参数 `sideIcon`，
   在「盾牌那格空着」时用 `drawSketchIcon` 画一枚浅钢蓝的「盾」。
   （为此把 `cardDraft.drawSketchIcon` 从模块私有改成 `export`。）
3. **诊断进留痕**：头显上看不到 DevTools，所以 `portraitCanvas(renderer, spec, log)` 新增一个日志出口，
   `game._warmShopPortraits` 把它接到 `this.log`（留痕通道）。每次抓起/失败都会留一行，含**不透明像素数**：
   0 = 这张图事实上什么都没有；数值很小 = 取景不对（模型只剩一条边）。
   数值由新导出的 `opaquePixels(cv)` 统计（拿不到 2D 上下文时返回 -1，绝不抛）。

**⚠ 仍未定**：头显上失败的真正原因。桌面复现不出来，只能靠下一次现场测试的留痕里那行
`[立绘] …`（它会把「哪一个模型 / 抓到几个像素 / 报什么错」一次说清）。这轮先保证**最坏情况也不丢卡**。

### 2.4 教学关固定横幅取消 + 一次性横幅 4 秒

第六十二修加的「场地前上方常驻提示板」现场不要了，改回纯一次性横幅、但时长拉到 4 秒。

- 停用方式 = `TUTORIAL_HINT.ENABLED = false`（`constants.js` + `userConfig.js` 两处）。
  `TutorialHintBoard.show()` 第一行就是 `if (this.cfg.ENABLED === false) return;`，所以**代码与参数全部保留**，
  想开回来只改这一个开关（比删文件干净得多：删了要同时清 `game.js` 的 import / 构造 / update / 两个钩子 / `_loadLevel` 的 hide）。
- `MID_WARNING.SECONDS 2 → 4`：这是**所有 warn 类一次性横幅**共用的时长
  （教学提示、精英来袭、方位来袭都读它）。`LEVEL_TITLE` / `HEAL_BANNER` 各有自己的 `SECONDS`，没动。
- `TUTORIAL.ELITE.HINT_DELAY`（2.4s）**不用改**：它只是「最早什么时候排下一条」，
  横幅没播完时 `_queueBanner → _flushBanner` 会因为 `_bannerBusy()` 继续排队等它收掉（注释已同步）。

### 2.5 第 18 关激光阶段预警横幅

现场要「激光出现前提醒：激光出现，快离开场地中间」。

**弹点选在 `bossMagician._enterPhase('laser')`**（而不是在 `game.update` 里另做边沿检测）：

- 这是「**每次**进激光」的唯一真值点，含 `laser → glass → nine → laser` **循环回来**那一次；
- 横幅走现成的 `waves.hooks.banner`（`game._loadLevel` 注入 → `game._showBanner` → 通用一次性横幅），
  Boss 控制器本来就持有 `this.waves`（`magicianGlassWall` 就是这么挂的），**不需要新注入**；
- **时机是准的**：激光气球要 ~2s 才成形（先垂直升 1s、再向下伸光束 1s），
  进阶段就弹 ⇒ 玩家有 2s 往两侧走开，正是「不能触碰」的那段。

开关 = `MAGICIAN_BOSS.LASER_WARN = { ENABLED:true, TEXT:'激光出现，快离开场地中间' }`。

### 2.6 ★ 关卡收尾闸门：只打死忍者精英也能通关（第 3 条）

**现象**：有时候把场上最后一只精英（第 13/14/16/17 关 35s 那批忍者）打死，本关就直接通关了，
末尾的「前方精英来袭」横幅、清场融合、末尾批**根本没出现**。

**根因**：关卡收尾判据是 `elapsed >= stopAt && _active === 0 && !_climaxHeld`（`_updateDpsSpawn`），
它**不看脚本进度**。而 `_active` 含全部存活气球，所以「时间到 + 场上清空」在场上被打空的**任意一帧**都成立。

把第 13 关的时间线摊开就很直观（脚本事件 5/15/25/35s 精英，45s 末尾横幅，47s 末尾批；本关时长 60s）：

```
t=35s  普通忍者 ×3 出场
t=45s  末尾横幅「前方精英来袭」到点 → _holdClimaxBanner 发现场上还有精英
       ⇒ 冻结脚本时钟（横幅/融合/末尾批一起推迟），最多 30s 兜底
t=58s  玩家把最后一只忍者打死
       ⇒ 闸门放行（_climaxHeld=false），而此刻 elapsed 已 ≥ stopAt、场上正好空了
       ⇒ 同一帧 _updateDpsSpawn 判 cleared = true
       ⇒ 脚本事件 45s / 47s 永远没机会跑 —— 末尾批没生成就通关了
```

**修法**：新增 `_canClear()`，把判据从「时间 + 场上」扩成三条独立闸门：

```js
_canClear() {
  return !this._climaxHeld && !this._scriptPending() && this._eliteWatch.length === 0;
}
```

- `_scriptPending()` = `_scriptElapsed < scriptEndTime(_script)` —— **脚本时钟**还有事件没走完就不许收尾。
  必须用 `_scriptElapsed`（被闸门冻住的正是它），不能用 `elapsed`。
- `_eliteWatch.length === 0` —— 末尾批已经在金点观察队列里就等它结算（金点 → 抽卡 → 才收尾）。
- `scriptEndTime`（`spawnDirector.js`，纯函数）= 事件表里最后一个时间点；
  **无限循环事件（`every` 且没写 `until`）不计入** —— 否则关卡会被一条滴流事件无限延长成软锁。

**不会软锁**（两个条件都自带出口）：脚本时间轴有限；观察队列最迟 8s 自己丢弃
（`_updateEliteWatch` 的 `w.t > 8` 兜底）。末尾精英走到飞毯边会自爆收场，所以「玩家打不死」也照样收尾。

**验证方式**：把 `_canClear()` 临时退回旧口径（`return !this._climaxHeld;`），
`tests/climax-clear-gate.test.mjs` 的 ★回归用例**立刻变红**（`cleared` 从 false 变 true）—— 已实测。

## 4. 踩坑

1. **「主模型 await 挂在 IIFE 里」= 一处挂全卡挂**。要分别 `try/catch`，最后只判「两个都没抓到」。
2. **只画骑士的盾甲兵 = 铁甲兵**。盾甲兵只要缺盾，就必须补一枚「盾」标，不能只靠「有图」。
3. **离线预览页必须 `<base href="/">`**：游戏里的模型路径是相对**站点根**的（`Model/xxx.glb`），
   页面放在子目录里会 404，而且症状是「每张卡都回退简笔画」，很容易误判成立绘代码坏了。
4. **脚本时钟 ≠ 关卡时钟**：末尾横幅闸门冻的是 `_scriptElapsed`，而收尾判据看的是 `elapsed`。
   两者用了同一个 `elapsed` 就会漏掉「闸门放行那一帧刚好场上清空」这个窗口 —— 就是第 3 条那个 bug。
5. **教学关的固定板停用要用开关，不要删代码**：删了要同时清 `game.js` 的 import / 构造 / `update` /
   两个钩子 / `_loadLevel` 的 hide，改动面和风险都比一个 `ENABLED:false` 大得多。
6. **`MID_WARNING.SECONDS` 是「所有 warn 类横幅」的时长**，不是中场预警专用；改它等于改教学提示、
   精英来袭、方位来袭的停留时间（本轮就是要这个效果，但以后别误伤）。
7. **卡面标题是写死字号、且不换行**：`未知 Boss ①` → `未知 Boss 阶段一` 只多 3 个字就顶到卡框了。
   以后往卡名 / 阶段名里加字，都要走 `titleFont()` 的量宽自适应，**别只改文案**。
