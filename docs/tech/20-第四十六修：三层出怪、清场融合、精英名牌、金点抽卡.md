## 0. 一句话结论

1. **三层出怪**：新增 `src/content/spawnDirector.js`（纯数据 + 纯函数）写「关卡 → 事件表」，
   `waves.js` 新增调度（层色光点 / 三种出现方式 / 节流）。**有关卡脚本的关走脚本，没有的继续走旧的三期脉冲**，
   两套互斥（`_elitePlan = this._script ? null : …`），不会翻倍出怪。
2. **清场融合（merge）**：场上**全部非精英**化为光点（**不结算积分**）+ 不足 `FUSE.COUNT`（5）个从最近传送门补足
   → 汇聚成一个大号**层色**光点 → 落地生成整批精英；融合期间与在场期间**暂停杂鱼滴流**，把注意力留给精英。
3. **可读性才是重点**：白（杂鱼）/ 蓝（无技能精英）/ 紫红（有技能精英）三层光点 + 三种合成音；
   精英挂**红字描边名牌**（铁甲兵 / 盾甲兵 / 治疗术士 / 幽灵法师 / 忍者队长 / 章鱼将军）；
   方位横幅复用中场预警那套 Sprite（只改文案：前方/左边/右边精英来袭）。
4. **正反馈闭环**：精英伤害数字**整条转金** + 击杀积分 ×2 + 精英音色；批次清空 → 上扬提示音 + **金点飞向选项卡**
   → 落地消失并**弹出三张选项卡**（`_enterMidCard()`：与通关抽卡同一套卡池，但**不推进关卡**）。

## 1. 三层怎么分（`LAYER` / `TYPE_LAYER`）

| 层 | 光点色 | 起手 | 组成 | 角色 |
|---|---|---|---|---|
| `trash` 杂鱼 | 白 | 全程（DPS 内外圈滴流） | `basic`（+ 后续可扩小体型） | 保证永远有怪打，是「背景音」 |
| `mini` 无技能精英 | 蓝 | **前期**（进度 ~10%，脚本里是绝对秒） | 铁甲兵 `eliteKnight` / 盾甲兵 `shield` | 前期给压力，中后期放量验证构筑 |
| `skill` 有技能精英 | 紫红 | **中期**（脚本里更晚） | 幽灵法师 / 忍者队长 / 章鱼将军 | 中期给压力，后期验证构筑 |
| `support` 辅助目标 | 绿 | 跟 `mini` 同批 | 治疗术士 `heart` | 只治不攻，制造「先杀谁」的取舍 |

**为什么不能继续用「三期脉冲」**：`_updateEliteWaves` 是三个独立 `if`，到点**一次性生成整组 combos**
—— 既没有密度曲线（前少后多是玩家感知的关键），也会同帧齐发（后期那期和中期那期可能同时成立），
而且一期里盾兵+幽灵+忍者+心形+章鱼**混在一起**，玩家根本分不清该先打谁。三层 + 层色光点 + 方位文案
就是把「打击优先级」直接画到画面上。

## 3. 三种出现方式（`via`）

| via | 做法 | 用在 |
|---|---|---|
| `portal` | 最近传送门飞光点 → 目标点（**现有行为**，只多了层色） | 第 2/5 关的滚动铁甲兵、第 4 关 20s 那批 |
| `merge` | **清场融合**：场上非精英化光点（不结算）+ 补足 `FUSE.COUNT` → 汇聚 → 大号层色光点 → 落地生成整批 | 第 1/2/4/5 关的高潮批次 |
| `direct` | 原地直接生成（`_spawnEliteNow`） | 融合落地的实际生成 |

**`merge` 的四条规则**（用户逐条确认过）：
1. **清全部非精英**（不是只清一部分）；
2. 被吸收的杂鱼**不结算积分**（否则可以靠清场刷分）；
3. 光点**不足 5 个就从最近传送门补足**（玩家把场清空时也能演出「汇聚」）；
4. 清场前后**暂停杂鱼滴流**（`_refillDrip` 里 `_eliteWatch.some(w => w.hold)` 门禁），
   注意力集中在精英上 —— 这也是第 4 关「可以去除杂兵」的实现。

## 4. 呈现层（全部复用现有件）

| 表现 | 实现 | 复用/新增 |
|---|---|---|
| 三层光点颜色 | `_makeBeamMesh(color, size)` | 扩参（原来只有固定色） |
| 三层出生音 | `audio.playLayerSpawn(layer)`（正弦→三角→锯齿，音高递增） | 新增（**代码合成，不需要音频文件**） |
| 方位横幅 | `game._showBanner(text)` → `midWarning.show(text)` | **复用第四十二修的中场预警 Sprite**（本来就支持任意文案） |
| 精英名牌 | `balloons._makeNameLabel(text, style)` + `ELITE_LABEL` | 扩参（红字 + 深色描边 + 半透明底） |
| 金点→选项卡 | `game._goldToCards()` → 金点飞向 `(0, CARD.ROW_Y, CARD.ROW_Z)` → 落地 `_enterMidCard()` | 新增 |
| 治疗线 | `fx.HealLinkFx`（Line + 加号 Sprite 沿线循环） | 新增（并入 `FxEffects`） |
| 精英击杀反馈 | 伤害数字 `elite` 染色 + `_addScore(score × ELITE_FEEDBACK.SCORE_MUL)` | 扩参 |

**金点为什么会「弹出」选项卡**：`_enterCard(mid)` 多了一个参数 —— 中途抽卡走 `_onMidCardDone()`，
它**只回到游戏、不推进关卡**（`_onCardDone()` 才是 `levelIndex++` + `_loadLevel`）。
若此刻本关其实已经通了（时间到 + 场上清空），则由 `_levelClearHeld` 挂起标记在抽卡结束后补一次通关抽卡 ——
不会出现「刚抽完卡又立刻抽一次」的双抽，也不会因为金点在飞就把通关吞掉。

## 5. 节流（轻量 SpawnDirector）

| 节流 | 参数 | 为什么 |
|---|---|---|
| 同屏精英总数 | `SPAWN_LAYER.MAX_ELITES = 6` | **安全网**，不是节奏工具：第 4 关 20s 那批可能还活着，30s 那批必须照出（所以不能设成 3） |
| 层间最小间隔 | `SPAWN_LAYER.LAYER_GAP = 4s` | 堵掉旧路径「中期/后期同帧齐发」 |
| 本层同屏上限 | 脚本里的 `capOnField` | 第 2/5 关「场上最多一只铁甲兵」，避免玩家来不及清 |
| 杂鱼滴流门禁 | `_eliteWatch.hold` | 融合批在场期间不补杂鱼 |
| 批次观察兜底 | 8s 没见到该层 → 丢弃观察 | 防止异常情况下金点永不触发（不软锁） |

`_updateEliteWatch` 用**「层」**而不是「逐只跟踪」判定批次清空：光点在落地前拿不到 balloon 引用，
按层判定最稳（代价是「同层的其它怪没死完就不会触发金点」，第 2/5 关正合需求）。

## 7. 踩坑（本修踩到的）

| 坑 | 说明 |
|---|---|
| **`isElite` 必须在构造时传入** | 名牌是在 `Balloon` 构造函数里建的；旧的 `_fireElitePhase` 是在 `onSpawn` 里才 `b.isElite = true` —— 那样名牌永远建不出来。改成给 `_queueSpawn` 传 `balloon: { hp, isElite: true }`，一路透传到 `balloons.spawn(type, pos, opts)` |
| **光点落地前拿不到 balloon 引用** | 所以批次清空只能**按层**判定（`_countLayer`），逐只跟踪在光点阶段是空的 |
| **MAX_ELITES 设小了会吃掉脚本批次** | 设成 3 时，第 4 关 20s 的两个铁甲兵只要还活着，30s 那批（3 只）就被上限挡掉 —— 它只能是「安全网」（6） |
| **`getWorldDirection` 给的是 +Z** | 相机前向是 -Z（`_enterCard` 里也有同样的取反注释）；金点起点若忘了取反会从**脑后**飞出来 |
| **融合批不清滴流就白清场** | 清完场后 `_refillDrip` 0.3s 就又开始补怪，等于清场没有意义 ⇒ 加 `hold` 门禁 |
| **中途抽卡必须与通关抽卡分开** | 复用 `_enterCard` 时，回调 `_onCardDone()` 会 `levelIndex++` + 加载下一关；中途必须走 `_onMidCardDone()`（只回游戏），并用 `_levelClearHeld` 处理「刚好这关也通了」的叠加 |
| **第 6 关中心格换类型要同步预载** | `_buildIntroPreloadQueue` 里 `addType('knight')` 必须一起改成 `eliteKnight`，否则穿云窗不预热、登场首帧又卡 |

## 9. 边界与未决

- 本轮只编排 **1 / 2 / 4 / 5** 关；**7~17 关仍是旧的三期脉冲**（未按三层骨架重排）。
  后续建议骨架：`mini` 从进度 10% 起手、每 8~10s 一波；`skill` 从 35% 起手、每 10~12s 一波，
  每关只换怪种与密度（第 7 关盾甲兵为主 → 8 关引入幽灵法师 → 10 关幽灵为主 + 治疗术士 → 11 关忍者起手
  → 13/14 忍者为+幽灵 1:1 → 16 章鱼少量登场 → 17 章鱼为主）。
- 杂鱼池仍只有 `basic`（`SPAWN_RING.pool`）：本轮**故意没动** —— 三层结构先立起来，
  扩杂鱼种类（小体型 `summoner`/`chest`/`eliteKnight`；`dragonhead` 技能未实现，暂排除）留待下一批。
- 治疗线连的是「`healRadius` 内最近的怪」（含杂鱼），这正是 `heart` 实际的治疗对象；上限 4 条（性能）。
- 金点**不触发额外抽卡次数**（一次批次 = 一次选项卡），与通关抽卡是同一套卡池与同一套「打气球选卡」交互。
- `MAX_ELITES` / `LAYER_GAP` 是全局的；如果以后某关需要更密的编排，改成脚本级覆盖（在事件里写 `capOnField` / `maxOnField`）。
- 第 7~17 关的精英现在会**多出名牌**且积分 ×2（`_fireElitePhase` 改动的副作用）—— 属于有意为之的一致性改动。
