# 01 · VR 输入实现（移动射击）

> 源码：`src/vr/input.js`（约 310 行）｜参数：`src/core/constants.js` 的 `MOVE` / `SHOOT` / `GUN_MODES`
> 复现难度：★★★（概念简单，但设备差异导致大量实机调试）

---

## 1. 目标

用**一套输入接口**同时支撑两种运行形态，游戏逻辑完全不感知差异：

| 形态 | 移动 | 视角 | 射击 | 技能 |
|---|---|---|---|---|
| 桌面（预览调试） | WASD / 方向键 | 鼠标 Pointer Lock | 鼠标左键 | `F` 键 |
| VR（PICO 4） | 右手摇杆 | 头显 6DoF 自然转头 | 右手扳机 | 右手握柄(grip) |
| — | — | — | 退出 VR：右手 A/B 键 | — |

对外只暴露 4 个方法：`update(dt)`、`getMuzzle()`、`consumeSkill()`、`getController()/getGrip()`。

## 2. 数据模型

```js
export class InputManager {
  constructor(world, playerRig) {
    this.world  = world;        // 取 camera / renderer / isPresenting
    this.rig    = playerRig;    // 玩家根节点（XZ 位移写在这里）
    this.camera = world.camera;

    this.keys = new Set();      // 桌面键位
    this.yaw = 0; this.pitch = 0;      // 桌面视角（弧度）
    this.locked = false;               // Pointer Lock 状态
    this.shots = [];                   // 本帧待发射 [{position, direction}]
    this.shotsFired = 0;               // 累计开火次数（单调递增，供枪模型后坐力用）

    this._cooldowns = { desktop: 0, left: 0, right: 0 };  // ms

    // handedness -> controller；不按索引存，靠 connected 事件填
    this._hands = { left: null, right: null };
    this._grips = [];           // 索引存储，供手腕面板挂载
  }
}
```

关键点：**`shots` 每帧清空**（见 `update()`），输入层只负责「本帧有没有开火」，弹道由上层消费。

## 4. VR 通道 `_bindXR()`

### 4.1 拿控制器：靠 `handedness`，不靠索引

```js
for (let i = 0; i < 2; i++) {
  const ctrl = this.world.renderer.xr.getController(i);
  const grip = this.world.renderer.xr.getControllerGrip(i);
  this._grips[i] = grip;
  ctrl.userData.hand = null;
  ctrl.userData.prevTrigger = false;
  ctrl.userData.prevGrip = false;
  ctrl.userData.prevAB = false;

  ctrl.addEventListener('connected', (e) => {
    // ✅ 正确做法：从事件里取 handedness（PICO 上索引与左右手不保证对应）
    const hand = e.data?.handedness || (i === 0 ? 'left' : 'right');
    ctrl.userData.hand = hand;
    ctrl.userData.inputSource = e.data;
    this._hands[hand] = ctrl;
    this._gripHands[hand] = this._grips[i];

    const ray = ctrl.userData.rayLine;
    if (ray && hand === 'right') {
      ray.material.color.setHex(SHOOT.RAY_COLOR);                                 // 右手射线变红
      ray.rotation.x = THREE.MathUtils.degToRad(SHOOT.RIGHT_PITCH_DEG);           // 与子弹共用俯角
    }
  });

  ctrl.addEventListener('disconnected', () => {
    if (ctrl.userData.hand) this._hands[ctrl.userData.hand] = null;
    ctrl.userData.inputSource = null;
  });
  // …创建射线…
}
```

### 4.2 射线可视光标

```js
const geo = new THREE.BufferGeometry().setFromPoints([
  new THREE.Vector3(0, 0, 0), new THREE.Vector3(0, 0, -1),   // 本地 -Z
]);
const line = new THREE.Line(geo, new THREE.LineBasicMaterial({ color: SHOOT.RAY_COLOR_LEFT }));

```

### 4.3 挂载父节点：`rig`，不是 `camera`

```js
// 控制器位姿本身已在参考空间内；再作为 camera 子节点会重复叠加头部变换导致偏移。
this.rig.add(ctrl);
this.rig.add(grip);
```

> **这是最容易踩的一个坑**：直觉上「手的姿态应该跟着头」，于是挂到 `camera` 下。
> 但 WebXR 给的控制器位姿已经是参考空间（stage/floor）下的绝对姿态，挂到 `camera` 后会**再叠加一次头部变换**，
> 表现为手柄模型和射线随头部转动产生双倍偏移。

### 4.4 读 gamepad

```js
_gamepadOf(hand) {
  const session = this.world.renderer.xr.getSession?.();
  if (session?.inputSources) {
    for (const src of session.inputSources) {
      if (src.handedness === hand && src.gamepad) return src.gamepad;
    }
  }
  return null;
}
```

## 5. 移动 `_moveVector()` + `_applyLocomotion()`

### 5.1 采集

```js
_moveVector() {
  const m = { x: 0, z: 0 };
  if (this.world.isPresenting) {
    const gp = this._gamepadOf('right');          // 仅右手摇杆负责移动
    if (gp) {
      let sx = 0, sy = 0;
      if (gp.axes.length >= 4) { sx = gp.axes[2]; sy = gp.axes[3]; }   // PICO：摇杆在 [2]/[3]
      else if (gp.axes.length >= 2) { sx = gp.axes[0]; sy = gp.axes[1]; } // 标准回退
      if (!(Math.abs(sx) < MOVE.DEADZONE && Math.abs(sy) < MOVE.DEADZONE)) {
        m.x = sx; m.z = sy;                        // PICO 前推为负，取反在下面做
      }
    }
  } else {
    if (this.keys.has('KeyW') || this.keys.has('ArrowUp'))    m.z -= 1;
    if (this.keys.has('KeyS') || this.keys.has('ArrowDown'))  m.z += 1;
    if (this.keys.has('KeyA') || this.keys.has('ArrowLeft'))  m.x -= 1;
    if (this.keys.has('KeyD') || this.keys.has('ArrowRight')) m.x += 1;
  }
  const len = Math.hypot(m.x, m.z);
  if (len > 1) { m.x /= len; m.z /= len; }         // 斜向不加速
  return m;
}
```

> 已移除「左手摇杆控制传送门」的实现（2026-08-25 实测确认不需要）。

### 5.2 施加位移

```js
_applyLocomotion(m, dt) {
  if (m.x === 0 && m.z === 0) return;
  const speed = MOVE.SPEED * dt;
  if (this.world.isPresenting) {
    // 顺相机「水平」朝向移动（y 分量清零，避免抬头就飞）
    const forward = _v.set(0, 0, -1).applyQuaternion(this.camera.quaternion); forward.y = 0; forward.normalize();
    const right   = _v2.set(1, 0, 0).applyQuaternion(this.camera.quaternion); right.y = 0; right.normalize();
    const fwdAmt = -m.z;                       // ⚠ PICO 前推(负) → 前进(正)
    this.rig.position.x += (forward.x * fwdAmt + right.x * m.x) * speed;
    this.rig.position.z += (forward.z * fwdAmt + right.z * m.x) * speed;
  } else {
    const sin = Math.sin(this.yaw), cos = Math.cos(this.yaw);
    this.rig.position.x += (m.x * cos + m.z * sin) * MOVE.SPEED * dt;
    this.rig.position.z += (-m.x * sin + m.z * cos) * MOVE.SPEED * dt;
  }
  // 行动边界硬钳制（与 world 的可视化边界板一致）
  this.rig.position.x = THREE.MathUtils.clamp(this.rig.position.x, -MOVE.BOUND_X, MOVE.BOUND_X);
  this.rig.position.z = THREE.MathUtils.clamp(this.rig.position.z, -MOVE.BOUND_Z, MOVE.BOUND_Z);
}
```

> **位移写在 `rig` 上，不写 `camera`**：`camera` 是 `rig` 的子节点，由 WebXR 统一接管头显位姿；
> 写 `rig` 才能让「头部自然转动」与「摇杆位移」正确叠加。

## 6. 瞄准与射击

### 6.1 方向 = 本地 −Z（核心坑）

```js
// 世界 -Z 朝向（相机/手柄的「指向前方」方向）。
// 注意：getWorldDirection 返回的是 +Z 轴，对相机和 XR 手柄而言那是后方，
// 必须取 -Z 才是真正的瞄准方向，否则子弹/卡牌射线会反着打。
_forwardOf(obj, out) {
  obj.getWorldQuaternion(_q);
  return out.set(0, 0, -1).applyQuaternion(_q).normalize();
}
```

### 6.2 右手枪瞄准（含俯角与枪口偏移）

```js
_rightAim(ctrl, outPos, outDir) {
  const t = THREE.MathUtils.degToRad(SHOOT.RIGHT_PITCH_DEG);
  // 本地方向：(0,0,-1) 绕 X 轴旋转 t → (0, sin t, -cos t)
  outDir.set(0, Math.sin(t), -Math.cos(t));
  ctrl.getWorldQuaternion(_q);
  outDir.applyQuaternion(_q).normalize();
  ctrl.getWorldPosition(outPos);
  outPos.addScaledVector(outDir, SHOOT.SPAWN_OFFSET);   // 模拟枪口前移
}
```

`RIGHT_PITCH_DEG = -27°` 是**手持 AK 模型的实际倾角**，是上机对着模型手调出来的值；
它同时被用于红色射线（`connected` 里）与子弹方向，**两者必须共用同一个值**，否则「射线指向」和「子弹落点」会错位。

### 6.3 枪口位姿

```js
getMuzzle(outPos, outDir) {
  const ctrl = this._hands['right'];
  if (ctrl) { this._rightAim(ctrl, outPos, outDir); return; }   // VR：右手柄
  this.camera.getWorldPosition(outPos);                          // 桌面：相机
  this._forwardOf(this.camera, outDir);
}
```

### 6.4 桌面开火

```js
_tryShootDesktop(dt) {
  this._cooldowns.desktop -= dt * 1000;
  if (this.desktopShooting && !this.world.isPresenting && this._cooldowns.desktop <= 0) {
    this.camera.getWorldPosition(_v);
    this._forwardOf(this.camera, _v2);
    this.shots.push({ position: _v.clone(), direction: _v2.clone() });
    this.shotsFired++;
    this._cooldowns.desktop = this._gunCooldown;
  }
}
```

### 6.5 VR 开火与按键（全用边缘检测）

```js
_updateXR(dt) {
  const session = this.world.renderer.xr.getSession?.();
  if (!session?.inputSources) return;
  this._cooldowns.right -= dt * 1000;
  this._cooldowns.left  -= dt * 1000;

  for (const src of session.inputSources) {
    const gp = src.gamepad; if (!gp) continue;
    const hand = src.handedness;
    const ctrl = this._hands[hand];

    const trigger = (gp.buttons[0]?.value || 0) > TRIGGER_THRESHOLD;   // 模拟量 → 阈值 0.5
    const grip    = gp.buttons[1]?.pressed || false;
    const btnA    = gp.buttons[4]?.pressed || false;   // 右:A / 左:X
    const btnB    = gp.buttons[5]?.pressed || false;   // 右:B / 左:Y

    if (ctrl) {
      if (hand === 'right' && grip && !ctrl.userData.prevGrip) this._skillQueued = true;  // 边缘 → 技能
      ctrl.userData.prevGrip = grip;
    }

    if (hand === 'right') {
      if (trigger && ctrl && this._cooldowns.right <= 0) {
        this._rightAim(ctrl, _v, _v2);
        this.shots.push({ position: _v.clone(), direction: _v2.clone() });
        this.shotsFired++;
        this._cooldowns.right = this._gunCooldown;
      }
      if (ctrl) ctrl.userData.prevTrigger = trigger;

      const ab = btnA || btnB;
      if (ctrl) {
        if (ab && !ctrl.userData.prevAB) session.end?.();   // 边缘 → 退出 VR
        ctrl.userData.prevAB = ab;
      }
    } else if (hand === 'left') {
      if (ctrl) ctrl.userData.prevTrigger = trigger;
    }
  }
}
```

> **为什么必须边缘检测**：`pressed` 是电平信号，VR 一帧 10~14ms，按住 A/B 会连续触发 `session.end()`；
> 按住 grip 会每帧排一次技能。`prevXxx` 保存上一帧状态，只在「本次真、上次假」时触发一次。

## 7. 主循环与对外接口

```js
update(dt) {
  this.shots.length = 0;            // 每帧清空，只保留本帧新开火
  this._applyDesktopLook();
  const m = this._moveVector();
  this._applyLocomotion(m, dt);

  if (this.world.isPresenting) this._updateXR(dt);
  else this._tryShootDesktop(dt);
}

getController(hand) { return this._hands[hand]; }        // targetRay，用于射击/瞄准
getGrip(hand)       { return this._gripHands[hand]; }    // grip，用于挂手腕面板
consumeSkill()      { const v = this._skillQueued; this._skillQueued = false; return v; }  // 一次性
```

### 枪械模式与射速（抽卡系统接口）

```js
setGunMode(mode) {                     // 关卡切换时调用：preview=初始态, full=满状态
  const g = GUN_MODES[mode] || GUN_MODES.preview;
  if (g) {
    this._baseGunCooldown = g.cooldown;  // 刷新基线（每关切回原速，清掉上关射速卡倍率）
    this._fireRateMul = 1;
    this._gunCooldown = g.cooldown;
  }
}

setFireRateMul(mul) {                  // 射速卡调用（mul<1=更快）
  this._fireRateMul = mul;
  this._gunCooldown = this._baseGunCooldown * mul;   // 真实改写节流源 → DPS 随之变化
}
```

> 射速卡**不是**改一个显示参数，而是直接改节流间隔，所以 DPS 统计会真实跟着变。

## 8. 参数表（`src/core/constants.js`）

| 常量 | 典型值 | 含义 / 单位 | 调参影响 |
|---|---|---|---|
| `MOVE.SPEED` | — | 移动速度 m/s | 与关卡尺度挂钩，过快易晕 |
| `MOVE.DEADZONE` | — | 摇杆死区（0~1） | 过小会漂移，过大会不灵敏 |
| `MOVE.BOUND_X` / `BOUND_Z` | — | XZ 行动边界（米，对称） | 与 `world._buildBoundary` 地板一致 |
| `SHOOT.COOLDOWN` | 60 | 桌面/默认射击冷却 ms | 与 `GUN_MODES` 覆盖 |
| `SHOOT.SPEED` | 15 | 子弹速度 m/s | 影响弹道段长 |
| `SHOOT.POOL_SIZE` | 500 | 子弹对象池容量 | 与 InstancedMesh 容量绑定 |
| `SHOOT.RIGHT_PITCH_DEG` | **-27** | 右手枪俯角（度） | 射线与子弹共用，改则同改 |
| `SHOOT.SPAWN_OFFSET` | 0.5 | 枪口前移（米） | 防子弹从模型内部穿出 |
| `SHOOT.RAY_LENGTH` | — | 可视射线长度（米） | 只影响观感 |
| `SHOOT.RAY_COLOR` / `RAY_COLOR_LEFT` | — | 右手红 / 左手青 | — |
| `TRIGGER_THRESHOLD`（文件内常量） | 0.5 | 扳机模拟量阈值 | 过低会误触，过高要按到底 |
| 鼠标灵敏度（硬编码） | 0.0022 | rad/px | — |
| pitch 夹取（硬编码） | ±1.2 | rad（约 ±69°） | 防翻转 |

## 9. 踩坑清单（多次调试点）

| 现象 | 真因 | 结论 |
|---|---|---|
| 左手柄操作却触发右手逻辑 | 用索引 0/1 判定左右手 | 必须用 `connected` 事件的 `e.data.handedness` |
| 摇杆推不出移动 / 前进变后退 | PICO 摇杆在 `axes[2]/[3]` 且**前推为负** | 先判 `axes.length>=4` 取 2/3，再在位移处取反 |
| 子弹、卡牌射线全部反向 | 用 `getWorldDirection()`（返回 **+Z**=背后） | 统一用 `_forwardOf()` 取本地 **−Z** |
| 手柄/射线随头转动双倍偏移 | 把控制器挂到了 `camera` 下 | 挂 `rig` |
| 射线指向与弹着点不一致 | 射线与子弹用了不同俯角 | 共用 `SHOOT.RIGHT_PITCH_DEG` |
| 按一下 A 键直接退出 VR / 技能连放 | 电平信号当边沿用 | `prevTrigger/prevGrip/prevAB` 做边缘检测 |
| 斜向移动比直行快 | 未归一化 | `len>1` 时归一 |
| 抬头往前走会「起飞」 | 直接用相机前向含 y 分量 | `forward.y = 0` 后归一化 |
| 首次点击开了一枪 | 未区分「锁指针」与「开火」 | 未锁定时只 `requestPointerLock()` 并 return |

## 10. 验证方法（PICO 实测清单）

- [ ] 双手柄同时在位时，左手柄握把只挂日志面板、右手柄握把触发技能（左右不串）
