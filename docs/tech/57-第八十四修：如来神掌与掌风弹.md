# 第八十四修：如来神掌与掌风弹

日期：2026-10-23

## 目标

保留如来神掌的巨掌横扫演出，但把它从「技能自己清屏」改成「清场 + 5 秒射击强化窗口」：

1. 初始横扫伤害 350，负责清杂兵和打出神掌气势；
2. 收掌后 5 秒内，所有新打出的普通枪弹（含多重弹道）变成掌风弹；
3. 掌风弹伤害 = 玩家攻击力 ×1.5，穿透 1 个敌人；
4. 掌风弹只强化射击，不再产生全屏伤害。

## 初始横扫

- `BUDDHA.DAMAGE = 350`
- `BUDDHA.DAMAGE_MUL_CAP = 3`：技能倍率最高按 3 倍计算，避免 350×5 继续秒精英。
- `BUDDHA.ELITE_MUL = 0.5`：精英只吃初始横扫的一半伤害。
- `BUDDHA.BOSS_MUL = 0.25`：Boss / 龙部件只吃四分之一。
- 起手压缩：`GROW_TIME 0.8s + MOVE_TIME 0.6s`，约 1.4 秒完成横扫并进入掌风弹阶段。
- 伤害统一由 `src/game/buddhaMath.js` 的 `buddhaSweepDamage()` 计算，分帧队列只负责结算节流。

技能满级时，后期基础怪约 1000 血，1050 的初始横扫仍能清掉；精英和 Boss 不会因为技能倍率叠加被顺带删除。

## 掌风弹窗口

- `BUDDHA.PALM_WIND.DURATION = 5`
- 起算点：横扫的 `grow/move` 结束、进入 `pause` 的那一帧。
- 不从按下技能时开始算，避免 1.4 秒起手吃掉强化时间。
- `DAMAGE_MUL = 1.5`、`PIERCE = 1`、`TRAIL_MUL = 1.2`。
- 只注入到 `player.fire()` 的普通枪弹（含多重弹道）；技能弹与商店追踪弹、穿甲弹保留原来的颜色和形态。
- 掌风弹曳光同步变金；若同时处于连杀加速期，仍优先显示加速蓝并保留更长的尾迹。
- 重复释放只刷新窗口，不叠加；切关、死亡、回菜单、重开统一清空。

## 渲染与性能

- 普通子弹仍是原来的球体 `InstancedMesh`。
- 掌风弹新增一个独立 `InstancedMesh`，最多增加 1 次 Draw Call。
- 掌风弹几何体是 2 个三角形的 `PlaneGeometry`，尺寸 0.16m × 0.24m。
- 贴图是专用 128×192 Canvas 掌形蒙版，`alphaTest = 0.35`，不做大面积半透明混合。
- 面片按相机世界四元数做 billboard，实例色负责金色 / 加速蓝色。
- 按现有 12 弹道、20 发/秒、2 秒存活估算，最多约 480 颗活跃掌风弹，约 960 个三角形。

## UI 与反馈

- 收掌时播放上扬金鸣 + 短风声（`playPalmWindStart`）。
- 窗口结束时播放回落提示音（`playPalmWindEnd`）。
- 右手枪技能框第二行改为金色「掌风弹 N.Ns」倒计时，结束后恢复冷却显示。
- 技能卡文案同步为「全屏350，收掌后5秒子弹化为掌风弹（伤害×1.5，穿透1）」。
