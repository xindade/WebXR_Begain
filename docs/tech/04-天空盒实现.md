# 04 · 天空盒实现

> 源码：`src/core/world.js` ｜ 参数：`constants.js` 的 `SKY_PANORAMA` / `PANO_DOME_YAW` / `SKY_BRIGHTNESS` / `SKY_EXR_BRIGHTNESS`
> 依赖：`vendor/EXRLoader.js`（EXR 为本地化加载器）｜ 复现难度：★★★

---

## 1. 需求：两套并存的天空

项目里同时存在两种天空，按关卡切换：

| 系统 | 用于 | 表现 |
|---|---|---|
| **渐变天球**（`ShaderMaterial`） | 绝大多数关卡 | 上/下两个颜色 + `smoothstep` 垂直渐变，可做「昼/黄昏/夜」平滑过渡 |
| **全景穹顶**（贴图球） | 空中城堡等指定关卡 | 把 360° 等距柱状全景图（JPG 或 EXR）贴到穹顶球上 |

外加一层**星空**（3 层 `Points`），只在渐变天空下显示（全景图自带天空）。

## 2. 渐变天球

### 2.1 着色器

```glsl
// 顶点：输出世界坐标
varying vec3 vWorldPos;
void main() {
  vec4 wp = modelMatrix * vec4(position, 1.0);
  vWorldPos = wp.xyz;
  gl_Position = projectionMatrix * viewMatrix * wp;
}

// 片段：按世界坐标归一化后的 y 做垂直渐变
uniform vec3 topColor;
uniform vec3 bottomColor;
varying vec3 vWorldPos;
void main() {
  float h = normalize(vWorldPos).y * 0.5 + 0.5;                 // y∈[-1,1] → h∈[0,1]
  gl_FragColor = vec4(mix(bottomColor, topColor, smoothstep(0.0, 1.0, h)), 1.0);
}
```

### 2.2 构建

```js
_buildSky() {
  const geo = new THREE.SphereGeometry(90, 32, 16);      // 渐变天球段数低（着色器插值，不需要细分）
  this._skyUniforms = {
    topColor:    { value: new THREE.Color(0x1a2a6c) },   // 初始 = 黄昏
    bottomColor: { value: new THREE.Color(0xff9a76) },
  };
  const mat = new THREE.ShaderMaterial({
    uniforms: this._skyUniforms, vertexShader: SKY_VERT, fragmentShader: SKY_FRAG,
    side: THREE.BackSide,      // 从球内看
    depthWrite: false,         // 背景不写深度
  });
  this.sky = new THREE.Mesh(geo, mat);
  this.ambient.add(this.sky);  // ⚠ 挂在 ambient 组下（见 §6）
}
```

### 2.3 昼夜过渡

```js
setSkyMood(mood) {
  if (this._panoActive) this.clearSkyPanorama();   // 上一关是全景 → 先复原
  const presets = {
    day:   { top: 0x4aa3ff, bottom: 0xbfe3ff },
    dusk:  { top: 0x1a2a6c, bottom: 0xff9a76 },
    night: { top: 0x05060f, bottom: 0x2a2a5a },
  };
  const p = presets[mood] || presets.dusk;
  this._skyTarget = { top: new THREE.Color(p.top), bottom: new THREE.Color(p.bottom) };
}

_updateSky(dt) {
  if (this._panoActive) return;                    // 全景关：跳过渐变/星空缓动
  if (!this._skyTarget) return;
  const k = Math.min(1, dt * 0.6);                 // 指数缓动
  this._skyUniforms.topColor.value.lerp(this._skyTarget.top, k);
  this._skyUniforms.bottomColor.value.lerp(this._skyTarget.bottom, k);
  // 星空透明度随「昼/夜」联动
  const dayness = this._skyTarget.top.getHex() === 0x4aa3ff ? 1 : (this._skyTarget.top.getHex() === 0x05060f ? 0 : 0.5);
  this._starLayers.forEach(l => { l.material.opacity = THREE.MathUtils.lerp(l.material.opacity, 1 - dayness, k); });
}
```

## 3. 全景穹顶（核心实现）

### 3.1 为什么不用 `scene.background`

three 支持直接把等距柱状贴图设为 `scene.background`（equirect 模式），但那会：

- 走 three 内部的 **equirect → 平面 quad 转换**，**绕开纹理各向异性过滤** → 在大俯仰角看天空时**发糊**；
- 受帧缓冲倍率限制，进一步降低清晰度；
- 无法方便地做「亮度倍率」「旋转对齐」等控制。

因此改成：**一张环绕原点的大球网格，用球面 UV 直接采样等距柱状图**。

```js
setSkyPanorama(url) {
  const isEXR = url.toLowerCase().endsWith('.exr');
  const apply = (tex) => {
    if (!this._skydome) {
      const geo = new THREE.SphereGeometry(90, 64, 48);          // 段数比渐变球高：贴图要细
      const mat = new THREE.MeshBasicMaterial({ side: THREE.BackSide, depthWrite: false });
      this._skydome = new THREE.Mesh(geo, mat);
      this._skydome.renderOrder = -1;                            // 最先绘制，作为背景层
      this._skydome.frustumCulled = false;                       // 永远填满视野，勿被剔除
      this._skydome.rotation.y = PANO_DOME_YAW;                  // 把 360 照片正前(图中心)对齐玩家初始朝向(-Z)
      this.scene.add(this._skydome);
    }
    this._skydome.material.map = tex;
    // 亮度倍率：MeshBasicMaterial 的 color 与贴图相乘 → 实现整体变暗/变亮
    this._skydome.material.color.setScalar(isEXR ? SKY_EXR_BRIGHTNESS : SKY_BRIGHTNESS);
    this._skydome.material.needsUpdate = true;
    this._skydome.visible = true;

    this.sky.visible = false;                                  // 隐藏渐变天空球
    this._starLayers.forEach((l) => { l.visible = false; });   // 隐藏星空（全景自带天空）
    this._panoActive = true;
  };
  const cached = this._panoCache[url];
  if (cached) { apply(cached); return; }
  this.loadSky(url).then(apply).catch(() => {});               // 兜底：未预加载时也能用
}

clearSkyPanorama() {
  if (this._skydome) this._skydome.visible = false;
  this.sky.visible = true;
  this._starLayers.forEach((l) => { l.visible = true; });
  this._panoActive = false;
}
```

要点：

| 设置 | 原因 |
|---|---|
| `side: BackSide` | 从球内看 |
| `depthWrite: false` + `renderOrder: -1` | 当作纯背景，先画，不参与深度 |
| `frustumCulled: false` | 球心在原点、相机在球内，包围盒剔除可能误判 |
| `rotation.y = PANO_DOME_YAW` | 等距柱状图的**图中心**是「正前方」，要与玩家初始朝向 **−Z** 对齐 |
| `material.color.setScalar(k)` | 用颜色乘数做整体明暗，比改贴图省事 |

### 3.2 纹理配置（EXR 与 JPG 规则不同）

```js
_configurePano(tex, isEXR) {
  if (isEXR) {
    // OpenEXR 为线性 HDR 数据：
    // - 不应用 sRGB 解码（否则会二次提亮），走 DataTexture 默认线性色彩；
    // - DataTexture 默认 flipY=false（与 JPG 相反），会导致画面上下颠倒，
    //   故强制 flipY=true 以与 JPG 全景在穹顶球面上的朝向一致；
    // - 开启 mipmap（DataTexture 默认 false，半浮点 WebGL2 可生成）保远距离清晰。
    tex.colorSpace = THREE.NoColorSpace;
    //tex.flipY = true;
    tex.generateMipmaps = true;
  } else {
    // 作为普通 2D 贴图（UVMapping）由穹顶球面 UV 直接采样；
    // 不设 EquirectangularReflectionMapping（那是给环境反射用的，会改采样方式）。
    tex.colorSpace = THREE.SRGBColorSpace;
  }
  // 各向异性：天空在视野边缘以掠射角显示时仍能保持锐利，减少发糊。
  // 上限钳到 4：最大各向异性(常为 16)在 EXR(70MB) 上纹理带宽压力很大，钳制后肉眼差异极小但省带宽。
  tex.anisotropy = Math.min(4, this.renderer.capabilities.getMaxAnisotropy());
  tex.minFilter = THREE.LinearMipmapLinearFilter;
  tex.magFilter = THREE.LinearFilter;
}
```

⚠ 注意注释里 `tex.flipY = true` 被**注释掉**了——因为实际使用的加载路径下翻转行为与预期不同，
当前实测「上下不倒」即可，不要盲目取消注释。

### 3.3 懒加载 + 缓存

```js
loadSky(url, onProgress) {
  return new Promise((resolve, reject) => {
    const isEXR = url.toLowerCase().endsWith('.exr');
    const cached = this._panoCache[url];
    if (cached) { onProgress?.(1, 1); resolve(cached); return; }     // 已缓存直接 resolve
    const loader = isEXR ? this._exrLoader : this._texLoader;
    loader.load(url,
      (tex) => { this._configurePano(tex, isEXR); this._panoCache[url] = tex; resolve(tex); },
      (ev)  => { onProgress?.(ev.loaded, ev.total); },
      (err) => reject(err));
  });
}
```

启动预览阶段用 `loadSky` + 进度回调驱动加载条 → 死亡重开同一关**不重复加载**。

## 4. 星空

```js
_buildStars() {
  this._starLayers = [];
  const make = (count, radius, size) => {
    const pos = new Float32Array(count * 3);
    for (let i = 0; i < count; i++) {
      const r = radius * (0.85 + Math.random() * 0.15);
      const theta = Math.random() * Math.PI * 2;
      const phi = Math.acos(2 * Math.random() - 1);                 // 球面均匀分布
      pos[i * 3]     = r * Math.sin(phi) * Math.cos(theta);
      pos[i * 3 + 1] = Math.abs(r * Math.cos(phi)) * 0.9 + 2;       // 下半球压平（地面不要星星）
      pos[i * 3 + 2] = r * Math.sin(phi) * Math.sin(theta);
    }
    const geo = new THREE.BufferGeometry();
    geo.setAttribute('position', new THREE.BufferAttribute(pos, 3));
    const mat = new THREE.PointsMaterial({ color: 0xffffff, size, sizeAttenuation: true, transparent: true, opacity: 0.9 });
    const pts = new THREE.Points(geo, mat);
    this.ambient.add(pts);
    this._starLayers.push(pts);
  };
  make(160, 85, 0.5);
  make(130, 80, 0.35);
  make(100, 75, 0.25);
}
```

三层不同半径/大小 → 有纵深感；`phi` 用 `acos` 保证球面均匀（否则会在两极堆积）。

## 5. 渲染器设置（与天空清晰度直接相关）

```js
this.renderer = new THREE.WebGLRenderer({ canvas, antialias: false, powerPreference: 'high-performance' });
this.renderer.setPixelRatio(Math.min(window.devicePixelRatio, 1.0));   // 降采样
this.renderer.xr.enabled = true;
// 头显实际渲染分辨率倍率。
// 原值 1.5 在「龙 Boss 关」（14 段高模 + 70MB EXR 天空）会严重掉帧 → 降到 1.25，
// 填充率开销下降约 (1.25/1.5)^2≈31%，PICO 4 帧率更稳；若实测仍不足可再降（1.0）。
this.renderer.xr.setFramebufferScaleFactor(1.25);
this.renderer.toneMapping = THREE.NoToneMapping;   // 不做色调映射 → 全景亮度由 SKY_*_BRIGHTNESS 控
this.renderer.shadowMap.enabled = false;           // VR 关阴影
```

> `NoToneMapping` 与 `SKY_BRIGHTNESS` 是配套的：不映射色调，亮度就完全由天空材质的颜色乘数决定，便于线性调参。

## 6. `ambient` 组：世界背景的统一开关

```js
// 环境氛围组：天空/星空/边界/坐标网格等「世界背景」统一挂此组，
// 等待房间期间整体隐藏 → 背景纯黑、仅留视频屏幕（见 waitingRoom）。
this.ambient = new THREE.Group();
this.scene.add(this.ambient);

setAmbientVisible(v) { if (this.ambient) this.ambient.visible = v; }
```

> ⚠ **必须知道的一个渲染语义**：three 中**父组不可见 → 子节点完全不渲染**。
> 直播方案曾因为 `world.sky` 挂在 `ambient` 下、而 `ambient` 被隐藏，导致 PC 端黑屏；
> 当时的修复是**临时把 sky reparent 到 scene 根**（渲染完再挂回）。
> 绝不能为了让 sky 显示而把 `ambient.visible` 设回 `true`——组里几百个坐标标注 Sprite 会瞬间吃光 GPU。

## 7. 参数表

| 常量 | 含义 | 调整影响 |
|---|---|---|
| `SKY_PANORAMA` | 关卡 → 全景图路径映射 | JPG / EXR 混用，按扩展名自选加载器 |
| `PANO_DOME_YAW` | 穹顶绕 Y 旋转（弧度，`π/2`） | 全景图「正前」对齐玩家初始 −Z；偏了就把地平线转歪 |
| `SKY_BRIGHTNESS` | JPG 全景亮度乘数 | `MeshBasicMaterial.color` 标量 |
| `SKY_EXR_BRIGHTNESS` | EXR 全景亮度乘数 | EXR 线性 HDR，与 JPG 分开调 |
| 各向异性上限 | **4**（硬编码） | 省纹理带宽；提高会糊边改善但掉帧 |
| 渐变天球几何 | `SphereGeometry(90, 32, 16)` | 段数低即可（着色器插值） |
| 穹顶几何 | `SphereGeometry(90, 64, 48)` | 段数要高（贴图采样） |
| 缓动系数 | `dt * 0.6` | 昼夜过渡速度 |

## 8. 踩坑清单

| 现象 | 真因 | 结论 |
|---|---|---|
| 全景天空明显发糊 | 用了 `scene.background` equirect 模式，绕过各向异性 | 改用**大球网格 + 球面 UV 采样** |
| EXR 天空过曝/发白 | 被当成 sRGB 二次解码 | EXR 必须 `NoColorSpace`（线性） |
| EXR 天空上下颠倒 | `DataTexture` 默认 `flipY=false`，与 JPG 相反 | 按注释处理翻转；**不要盲目改**，以实测为准 |
| 全景「正前方」不对 | 等距柱状图中心未对齐玩家朝向 | `_skydome.rotation.y = PANO_DOME_YAW`（π/2） |
| 天空在视野边缘出现一闪一闪 | 穹顶被视锥剔除 | `frustumCulled = false` |
| 天空把远处物体挡住 | 写了深度 / 绘制顺序错 | `depthWrite:false` + `renderOrder:-1` |
| 全景关星星还亮着 | 星空未随全景隐藏 | `setSkyPanorama` 里隐藏 `_starLayers` |
| 换关后渐变天空不恢复 | 没调 `clearSkyPanorama` | `setSkyMood` 里先检测 `_panoActive` 并复原 |
| 龙 Boss 关掉帧严重 | `framebufferScaleFactor` 1.5 + 14 段高模 + 70MB EXR | 降到 **1.25**（填充率开销↓约 31%） |
| 等待房间黑屏 / 影片期背景不该有天空 | 天空挂在 `ambient`，父组隐藏则子节点不渲染 | 用 `setAmbientVisible(false)` 隐藏整组；若需单独显示天空，用**临时 reparent**，不要开 `ambient.visible` |
| 8K 全景图导致进关卡顿 | CPU 解码 8K PNG 太慢 | 资源侧统一转 **4K JPG**（PICO 性能优先） |
| 亮度怎么调都不对 | 开着 `toneMapping` 与亮度乘数打架 | `NoToneMapping` + `SKY_*_BRIGHTNESS` |

## 9. 验证方法

- [ ] 进入有全景的关卡：360° 环视一圈，**地平线水平**、正前方与关卡设计朝向一致（不歪、不上下颠倒）
- [ ] 抬头看天顶：**不发糊**（与 `scene.background` 方案对比可见差异）
- [ ] EXR 关：亮度与 JPG 关观感接近，无过曝；天空梯度自然
- [ ] 渐变关：`day / dusk / night` 切换时颜色平滑过渡（不是硬切），星空随夜晚淡入
- [ ] 从全景关进入普通关：渐变天空球与星空**正确恢复**（不残留全景）
- [ ] 死亡重开同一全景关：不重复加载（进度条瞬间到 100%）
- [ ] 龙 Boss 关帧率：`framebufferScaleFactor` 1.25 下较原 1.5 有明显改善
- [ ] 等待房间：背景纯黑、只有视频屏（`setAmbientVisible(false)` 生效）
