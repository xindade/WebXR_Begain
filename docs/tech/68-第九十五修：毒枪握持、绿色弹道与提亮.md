# 第九十五修：毒枪握持、绿色弹道与提亮

## 现场反馈

1. 瘟疫毒枪初始位置偏高，需要垂直向下移动 3cm；
2. 瘟疫子弹应为绿色，不再沿用默认黄色；
3. 毒枪模型整体偏暗，需要提亮。

## 改动

### 1. 握持高度

- `PLAGUE_WEAPON.POSITION.y`：`-0.25` → `-0.28`，即相对原位置垂直下移 3cm。
- `src/core/constants.js` 与 `src/core/userConfig.js` 同步修改。

### 2. 瘟疫子弹绿色

- 瘟疫角色默认弹色：`0x7bed9f` → `0x4dff88`，更明确的高亮绿色。
- `BulletManager` 新增 `defaultTint`：普通弹自动使用角色默认色，弹体与曳光同步变绿。
- 颜色优先级：显式特殊弹色（追踪紫 / 穿甲红）> 角色默认色 > 普通黄；掌风弹保持金色，不受角色默认色覆盖。
- 新局在 `Game.start()` 按 `player.character.bulletTint` 设置；回菜单清空。

### 3. 毒枪提亮

只对毒枪模型材质生效，不动 AK / 火箭筒：

- `MODEL_COLOR_MUL = 1.15`：材质颜色乘 1.15；
- `MODEL_EMISSIVE = 0.25`：把基础色纹理接为自发光贴图，补一层 25% 自发光；
- `MODEL_MAX_METALNESS = 0.65`：无环境贴图时金属度过高会发黑，压到 0.65。

实现位于 `RightGun._brightenModel()`，模型加载完成后执行一次。
