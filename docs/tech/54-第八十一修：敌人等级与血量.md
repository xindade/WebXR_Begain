# 第八十一修：敌人等级与血量

日期：2026-10-18

> ⚠ 第八十二修已调整「远程普通精英倍率」与「末尾精英血量/速度」口径，当前实现以
> [55-第八十二修：Boss与末尾精英强度](./55-第八十二修：Boss与末尾精英强度.md) 为准。

## 目标

把「怪物血量」从按敌种写死的固定值，改成**按关卡成长的等级制**；同时保证：

- 普通关精英是「比杂鱼厚一点」，不会吃掉玩家大半输出；
- 末尾精英有仪式感和输出验证，但整批本体最多打 6 秒；
- Boss 本体 / Boss 召唤物继续走各自规则，不套等级血量；
- 玩家能从怪头顶直接读到等级，Boss 只显示 `Boss`。

## 公式

### 等级

```text
基础怪 LV = 关卡数
精英   LV = 关卡数 + 首次出场偏移
```

| 类型 | 基础血量 | 每级成长 | 偏移 | 首次出场 |
|---|---:|---:|---:|---:|
| 基础怪 | 100 | 50 | 0 | L1 = 150 |
| 铁甲兵 | 1000 | 100 | +1 | L1 → Lv.2 = 1200 |
| 盾甲兵 | 1000 | 150 | +2 | L2 → Lv.4 = 1600 |
| 治疗术士 | 3000 | 200 | +3 | L5 → Lv.8 = 4600 |
| 忍者队长 | 2000 | 200 | +4 | L8 → Lv.12 = 4400 |
| 幽灵法师 | 3000 | 250 | +5 | L11 → Lv.16 = 7000 |
| 章鱼将军 | 6000 | 300 | +6 | L14 → Lv.20 = 12000 |

### 本体血量

```text
本体 = 基础血量 + 每级成长 × LV
```

### 普通精英

```text
忍者 / 幽灵 / 章鱼：本体 + 进入本关时快照 DPS × 1，体型 ×2
其它精英          ：本体，体型 1
```

### 末尾精英（关卡收尾那一批）

```text
整批本体总血量 = min(本批本体之和, 进入本关时快照 DPS × 6)
每只本体       = 整批本体总血量 × 该只本体 / 本批本体之和
每只最终血量   = 每只本体 + 进入本关时快照 DPS × 5
```

`DPS × 6` 是「整批本体」的可击杀保证；每只额外的 `DPS × 5` 才是末尾精英的压迫感来源。

## Boss 例外

- Boss 本体（脸谱 / 龙 / 魔术师）不套等级血量；
- Boss 召唤物（脸谱蓝阵、魔术师召唤池、龙召唤）不套等级血量，也不显示 `Lv.N`；
- Boss 本体头顶只显示 `Boss`，不显示名字与等级；
- 龙 Boss 新增头顶血条，跟随龙头，标题同样只写 `Boss`。

## 教学关

教学关精英不再固定 4000 血，改走统一公式：第 1 关铁甲兵 = `Lv.2 / 1200 HP`。

## 显示

- 基础怪头顶：「Lv.N」+「爆」；同一关共用一个 `InstancedMesh` 和一份按关卡缓存的纹理。
- 普通精英：`Lv.N 铁甲兵`；末尾精英：`Lv.N 铁甲兵 Boss`。
- Boss 关的基础怪不显示等级（`stageLevel = 0`）。

## 关键文件

- `src/content/enemyLevels.js`（新）：等级 / 本体血量 / 普通精英 / 末尾批 / 基础怪构造参数。

- `src/core/constants.js`：`HP_MAX_SECONDS = 6`、`HP_BONUS_SECONDS = 5`、龙血条尺寸。
