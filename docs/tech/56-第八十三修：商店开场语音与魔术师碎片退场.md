# 第八十三修：商店开场语音与魔术师碎片退场

日期：2026-10-18

## 现场口径

- 商店关（第 3/9/15 关）加入 `music/商店语音.wav`；
- 等**云雾散尽 + 关卡名横幅收掉**后才播放；
- 语音播放完，魔术师动画立即停止，并变成碎片消失。

## 音频

| 项 | 值 |
|---|---|
| 文件 | `music/商店语音.wav` |
| 时长 | 约 5.79 s |
| 配置 | `OPENING_MAGICIAN.SHOP_VOICE_URL / SHOP_VOICE_ENABLED / SHOP_VOICE_VOLUME` |

同一份文件也复制进 `tools/cast-apk/app/src/main/assets/game/music/`，否则 APK 内没有这个音频。

## 起播闸门

纯函数 `levels.shopVoiceReady({ introActive, titleAt, titleText, bannerShowing })`：

```text
允许起播 = !云雾中
        && 标题卡已排完（titleAt = 0）
        && 标题文案已消费（titleText = null）
        && 当前横幅已收掉（bannerShowing = false）
```

`game._tickShopVoice()` 每帧检查一次，起播后立刻清 `_shopVoicePending`，不会重复播放。
默认时间线：雾 4.0 s 结束；标题卡 1.5 s 弹、2.8 s 收 → 约 4.3 s 起播语音。

## 动画同步与退场

- 语音起播时调用 `OpeningModel.restartTimer()`，把 10 s 兜底重新计时，避免长横幅把模型提前收掉。
- 语音 `ended` → `game._shatterOpening()`：
  1. 用 `Box3` 取模型世界包围盒；
  2. `OpeningModel.shatter()` 停止 mixer、从场景摘除模型；
  3. 在身体中轴 / 左右 / 上下 5 个点调用 `fx.debrisBurst()`，淡紫色碎片覆盖整个人形。
- 语音加载失败 / `ended` 不触发：`OpeningModel.SHOW_SECONDS`（10 s）走同一个 `onExpire → _shatterOpening()` 兜底。
- 切关 / 回菜单走 `_disposeOpening()`：直接移除，不播放碎片。
