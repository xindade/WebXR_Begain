# 第九十三修：瘟疫范围疫爆与精英连锁

## 目标

解决瘟疫医生「感染」实战中只传最近 1 只、只传一半层数、没有范围表现的问题。让毒素在高叠层敌人死亡时形成可感知的“一死一大片”，但通过范围、单次目标数和连锁预算避免一具尸体直接无脑清屏。

现场口径：**精英不做额外限制，每次可以吃满传递层数，并且可以继续向外传播。**

## 规则

| 项目 | 口径 |
|---|---|
| 触发 | 中毒目标死亡且层数 ≥2 |
| 2 层死亡 | 只弱传给最近的 1 只，+1 层 |
| 1 层死亡 | 不传播 |
| 3 层起 | 范围疫爆 |
| 范围 | 尸体为中心、水平 5 米圆柱（与地面圆环一致，忽略高度差） |
| 单次目标 | 最近的 6 只可感染敌人 |
| 传递层数 | `floor(死亡时层数 × 70%)` |
| 目标上限 | 不超过目标当前叠层上限，已满层目标不占名额 |
| 精英 | 无额外限制：可吃满层，死亡后可继续传播 |
| Boss / 龙部件 | 不接收传播；只吃原有单体毒伤 |
| 连锁预算 | 1.5 秒滑动窗口内最多影响 18 只 |

数值示例：5 层死亡 → 6 只各 +3；8 层（加大剂量 Lv.1）→ 5 层；10 层 → 7 层。2 层只弱传 1 只 +1，保留“低层不形成无限链”的断链设计。

## 实现

- `src/core/constants.js`：新增 `INFECT_RATIO=0.7`、`BURST_MIN_STACKS`、`BURST_RADIUS`、`BURST_TARGETS`、`BURST_WINDOW`、`BURST_MAX_TARGETS` 与 `PLAGUE_BURST` 表现参数。
- `src/game/characters/rules.js`：新增纯函数 `plagueBurstLayers()` 和 `plagueBurstTargets()`；范围按水平 XZ 半径计算，与地面圆环严格一致；`infectionStacks()` 改为按 70% 疫爆层数计算。
- `src/game/game.js`：`_spreadPlague()` 改为范围多点传播；维护 `_plagueBurstTimes` 连锁预算；排除 Boss / 龙部件 / 无敌物 / 聚宝盆 / 已死目标；精英不做限制。
- `src/game/fx.js`：新增池化 `PlagueBurstFx`，尸体位置扩散绿色冲击环；被感染目标闪绿色火花。
- `src/vr/audio.js`：新增 `playPlagueBurst(chain)`，低频毒雾爆开 + 湿润噪声，连锁越高音高越亮。
- `src/content/tutorial.js`：教学卡「感染」文案改为“向周围敌人扩散毒素；层数越高，疫爆范围越强”。

## 性能

- 疫爆环固定 3 个池，复用同一份 RingGeometry，只在 0.55 秒内可见；
- 每个被感染目标只复用现有 Spark 粒子池，不新建粒子系统；
- 目标选择只遍历当前气球列表一次（≤ 场上敌人数量），不引入每帧常驻开销；
- 音效 80ms 节流，避免同一帧多具尸体叠加播放。

## 现场测试口径

1. 用瘟疫医生叠满 5 层后击杀一只怪，尸体周围应出现绿色扩散环，附近最多 6 只头顶跳出绿色毒伤；
2. 附近精英应一次吃到 3 层，并且精英死亡后继续向周围传播；
3. 连续引爆多具尸体时，同一波扩散最多覆盖 18 只，不应瞬间清空全屏；
4. Boss 与龙部件不接收传播，只保留原本的单体毒伤；
5. 1 层毒死亡不传播；2 层毒死亡只弱传最近 1 只 +1 层。
