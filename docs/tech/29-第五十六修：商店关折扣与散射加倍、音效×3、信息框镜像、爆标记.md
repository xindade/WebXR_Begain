## 2. 平台关不掉 EXE：为什么，以及我们现在怎么兜

- **平台侧的关闭是「按登记名 kill」**：结束本局时下发字符串 `{"cmd":"kill","msgData":"<进程名>"}`（启动器执行），
  实测**只能按进程名杀**，没有「按 exe 路径 / 游戏目录关闭」的能力。
- 所以只要**平台注册表里的路径/进程名**与现场实际运行的 EXE 不一致（改名、换版本、`rebrand`、手工双击），
  `kill` 就**静默打空** —— 现象正是「平台点了结束游戏，EXE 还开着」。
- **我们的兜底（本轮新增，不必等平台）**：平台「关闭游戏」是 `kill` + `0x10 CloseGame` **两路同发**（PC 的 51124 与头显的 51124 都收到）。
  现在 PC 端收到 `0x10` 后：先回 `0x02` ack（平台在等这个确认），再 **0.8s 后自己 `app.quit()`**，
  1.5s 后 `process.exit(0)` 硬兜底。开关 `--keep-alive` / `--no-exit-on-close`（要排练/常驻时用）。
- 与头显侧同源：APK 侧早就是「页面收到 `cmd=16` 自己退出」，本轮把同一条原则补到 PC 端。

## 3. 散射 ×2（`SHOOT.SPREAD_ANGLE`）

- 口径不变：`半角 = SPREAD_ANGLE × min(1, (n-1)/(SPREAD_FULL_N-1))`，`SPREAD_FULL_N = 12`；
  **正中永远有一条 `t=0` 的弹道**（`player.fire` 的偏移序列第一条固定 0），所以「准线上始终有一条」是天然成立的。
- 0.15 → 0.30 后的几何：12 条弹道用满 ⇒ 半角 ≈ **16.70°**、总张角 ≈ **33.40°**（相邻 ≈3.04°）；7 条时总张角 ≈18.59°（= 改前 9.15° 的两倍）。
- ⚠ 张角越宽，打**远距离单体**（Boss / 末尾精英）的有效 DPS 越低，而这些血量是按标称 DPS 标定的 —— 再往上加要连血量口径一起算。
- ⚠ `SPREAD_ANGLE` **同时写在 `constants.SHOOT` 与 `userConfig.SHOOT`**（后者的值经深合并覆盖前者），
  且 `userConfig.js` 在服务器内容包里 ⇒ **改完必须跑 `tools\deploy-content.ps1`**，否则现场那份旧配置会把新值盖回去。

## 4. 音效 ×3（音效总线 `sfxBus`）

- 之前：所有程序化音效直接 `connect(this.master)`（master 增益固定 `0.5 × volume`），与 BGM 共用同一条出口，
  想「只把音效调响」没有下手的地方（BGM 那侧走 `bgmBus.base × BGM_VOLUME`，已经是 4.0/5.4/4.0）。
- 现在：`master` 与音效之间插一层 **`sfxBus`（gain = `SFX_GAIN × volume`，默认 ×3）**，
  12 处音效连接的出口从 `master` 改为 `sfxBus`；BGM 仍直接进 `master` ⇒ **BGM 不受影响**。
- 直播推流同样受益：`ensureCastAudioTrack()` 取的是 `master`，音效已被 ×3 之后再并进流。

## 5. 信息框镜像到左手侧

- 面板是**右手柄 grip 的子节点**，只绕 X 轴下倾 90°，没有绕 Y 的镜像 ⇒ 只改 `POSITION.x` 的正负即可（贴图文字方向不变）。
- 生效值在 `userConfig.SKILL_HINT.POSITION`（`x: -0.119`，覆盖 `constants` 里的 `-0.1`）。
- 面板本身 `depthTest:false` + `renderOrder 1000` ⇒ 换到左侧也不会被枪模型挡住。
  ⚠ 左侧贴近右手腕，若现场觉得和左腕面板挤，微调 `x` 的绝对值（-0.10 ~ -0.14）/ `z` 即可，不用改代码。

## 6. 第 3 关商店价格减半

- 实现：`ShopDraft` 开店时取一次 `state.priceMul()`（= 第 3 关 `SHOP.LEVEL3_PRICE_MUL(0.5)`，其余关 1），
  技能本体 / 技能强化 / 道具的价格都乘它；**卡面文案与实扣同源**（同一处 `_skillPrice()/_upgradePrice()`）。
- 第 3 关实际价格：技能 **500**、强化 **750**、道具 **500 × 目标等级**。
- **刷新价（200 起逐次翻倍）不参与折扣** —— 用户口径只说了「道具+技能」。
- ⚠ 倍率**进店时取一次**：同一家店里不会因为关卡状态变化而变价。

## 7. 基础怪「爆」标记 + 飞毯边缘爆炸特效

### 7.1 「爆」标记为什么是 InstancedMesh

- 每怪一个 `Sprite`（像精英名牌那样）在几十只杂鱼时就是几十个 draw call —— 72fps 预算里太贵。
- 本修用**一个 InstancedMesh**（`BOMB_LABEL.MAX = 96`）画完所有基础怪头顶的「爆」字：无论多少只都只有 **1 个 draw call**。
- 所有实例朝向一致（都正对相机）⇒ 共用一个 `Quaternion`，逐帧只 `compose(position, quat, scale)`，
  `frustumCulled = false`（位置每帧变）、`depthTest = false` + `renderOrder 998`（画在怪之上，不被模型遮挡）。

### 7.2 判定与位置

- 判定是**纯函数** `isBombMarkTarget(b)`：`b.alive && !isElite && !isBoss && !isDragonPart && !controlled` ——
  只有 L1 层基础杂鱼挂；精英 / Boss / 龙部件 / 受控（龙身等）/ 已死都不挂。
- 跟随 `b.mesh.visible`（幽灵隐身时不显示标记）；高度 = `effectiveRadius × 2.6 + Y_PAD`（与精英名牌同一套算法，3 倍体型也贴得住）。

### 7.3 爆炸特效加强

- `_checkExplosions`（气球进入 4×8 飞毯区域自爆）除原有球形冲击波外，追加 **碎片 `debrisBurst(…, ×1.8)` + 火花 `spark(…)`**；
  两者都是 `fx.js` 的预分配实例池 ⇒ 只多几次 `setMatrixAt`，**不新增 draw call**。
- 同时 `EXPLOSION`：`DURATION 0.4 → 0.45`、`MAX_SCALE 2.5 → 3.4`、`START_OPACITY 0.7 → 0.85`。

## 8. 特殊弹「夸张化」（第 3 条）

现场写的是「**串糖葫芦**的**追踪**子弹从枪口射出，效果夸张（红色、体型变大）」。但两项道具的现状曾是：

| 道具 | 追加子弹 | 改前 | 改后 |
|---|---|---|---|
| 串糖葫芦 | **穿甲弹**（可穿透 3 个） | 青色 `0x00d2ff`，已从**枪口**射出（`shot.position` = 枪口位姿），无追踪 | **亮红 `0xff2f36`**，体积 **×3**，曳光 **×2** |
| 打狗还要看主人 | **追踪弹**（朝 5m 内最近精英） | 紫色 `0x9b59ff`，从**被击杀怪的位置**飞出 | 从**枪口**射出（`DOG_FROM_MUZZLE`），体积 **×2**，曳光 **×2** |

⇒ 现场那句话可以同时读成「串糖葫芦（名字）+ 追踪（只有打狗有）」两说，**两条链路本轮都按上表改了**，
不必二选一；要退回旧口径只改一处开关：

- 追踪弹想回到「从击杀点射出」：`SHOP.DOG_FROM_MUZZLE: false`（`userConfig` 改完刷新即生效）。
- 只想留穿甲弹的夸张化：把 `DOG_SCALE` / `DOG_TRAIL_MUL` 写回 `1`。

### 8.1 怎么实现「体积变大」而不新增 draw call

- 子弹全部是**一个** `InstancedMesh`、共享同一份 `SphereGeometry(BULLET_RADIUS)`，
  所以「某一发更粗」不能靠改几何体，只能改**那一发的实例矩阵**：
  `bullets.spawn(..., { scale })` → 每帧 `sync()` 里对该实例走 `makeScale(s,s,s)`（普通弹 `scale=1` 仍走 `identity()`，零额外开销）。
- 曳光（`fx.tracer`）本来就是**按段上传颜色 + 长度倍率**的池子，所以「加长 / 变色」只在 `game._updateFx` 多传两个参数：
  带 `tint` 的特殊弹用自己的颜色，`trailMul > 1` 时按倍率拉长（与连杀加速弹的 `TRACER_MUL` 同一机制）。
- ⚠ 尾迹上限依旧是 `b.origin`（第四十二修：曳光不得越过枪管），放大不改变这条。

## 9. 验证方法

- `npm test`：**300 项全绿**（本轮新增 `tests/bomb-label.test.mjs` 3 项 + `tests/shop.test.mjs` 第 3 关折扣 1 项 + 特殊弹外观 2 项；
  更新 `tests/bullet-volume.test.mjs` 的散射几何断言与 `tests/shop.test.mjs` 的打狗用例（枪口 + 夸张化 + 无输入源回退））。
  更新 `tests/bullet-volume.test.mjs` 的散射几何断言）。
- 现场手测：
  1. 散射：12 弹道时明显铺开（总张角 ~33°），准星正前方始终有一条弹道；
  2. 音效：命中/击杀/射击明显变响，BGM 不变；
  3. 信息框：面板出现在枪的**左侧**（原右侧）；
  4. 第 3 关商店：技能 500 / 强化 750 / 道具 500×等级；第 9/15 关仍是 1000 / 1500 / 1000×等级；
  5. 基础怪：头顶有「爆」字；撞到飞毯边缘时除了球形冲击还有碎片与火花；
  6. 平台：点「结束游戏」→ EXE 自行退出（**平台 kill 打空也能退出**）。
