# 第七十一修：黑洞吸附前置、散射×3、Boss 宝箱

## 目标

现场三条反馈：

1. 黑洞吸过去的怪有一部分在黑洞后面，被黑色盘面挡住 → 全部放到玩家可见的前侧；
2. 默认能量散射一发打不死精英 → 基础伤害 ×3；
3. 每打死一个 Boss 给一个宝箱：
   - 第 6 关脸谱 Boss：额外子弹宝箱，命中数值 0.1→2.0，持续 4 秒；
   - 第 12 关龙 Boss：维持原攻击力宝箱；
   - 每个宝箱开始前先弹 2 秒「宝箱出现，快攻击」。

## 1. 黑洞：吸附环整体前移

### 原因

黑洞视觉是一个竖立、正对释放瞬间玩家的圆盘（半径 `BLACK_HOLE.RIM = 2m`）。
吸附落点原本以洞心为圆心铺满 360°，其中远离玩家的一半在圆盘背面；
圆盘 `renderOrder 5~7` 且半透明黑底，会把这些怪盖住。

### 实现

- 释放时记录 `_bhFrontDir`：洞心 → 玩家的水平单位向量；
- 新增 `_bhAbsorbCenter = _bhCenter + _bhFrontDir × (RIM + OSC_AMP + FRONT_GAP)`；
- 所有吸附落点、精英振荡、黑洞伤害判定都改用 `_bhAbsorbCenter`；
- 前移量 = `2.0 + 0.8 + 0.6 = 3.4m`，大于精英最大外扩半径 2.8m，
  因此所有怪至少停在盘面前方 0.6m，深度测试会正确保留它们。

参数：`BLACK_HOLE.FRONT_GAP`（默认 0.6m）。想更靠前就调大，想更贴盘面就调小，
但必须保持 `FRONT_GAP > 0`，否则又会有怪被盘面挡住。

## 2. 能量散射基础伤害 ×3

- `SCATTER.DAMAGE_MUL = 3`；
- `_castScatter()` 每发伤害 = `(SCATTER.DAMAGE || player.atk) × DAMAGE_MUL × skillDamageMul`；
- 只影响默认「能量散射」，不改普通子弹、黑洞、激光剑、如来神掌。

## 3. Boss 宝箱

### 配置

| 配置 | 用途 | 关键口径 |
|---|---|---|
| `MASK_CHEST` | 第 6 关脸谱宝箱 | 4 秒；命中一次 +0.1；0.1→2.0；<0.5→0 条，0.5~<2.0→1 条，满 2.0→2 条 |
| `DRAGON_CHEST` | 第 12 关龙族宝箱 | 5 秒；按打出的弹数线性换攻击力，≥30 发 +150 封顶（原口径不变） |
| `CHEST_BANNER` | 所有宝箱 | 2 秒金色横幅：宝箱出现，快攻击 |

### 顺序

```
Boss 死亡 → _chestDue() → _startBossChest()
          → 2 秒横幅（_chestPending）
          → _beginChestWindow() 立箱 / 开计数
          → 4~5 秒受击计数
          → 光点飞向玩家
          → 兑现奖励，放行通关抽卡
```

`_chestRunning()` 在「2 秒横幅 + 计数 + 光点飞行」全程为真，
因此通关抽卡一定等宝箱流程收完才开。

### 奖励落地

- 脸谱箱：`player.shotCount += 结算条数`，上限复用 `ATTRIBUTE_STATS.multiShot[2]`（12 条）；
- 龙箱：`player.atk += 结算攻击力`，原逻辑不变。

### 第 18 关

第 18 关魔术师 Boss 死亡后直接进入通关横幅与本局结束，没有下一关，
因此本轮不插宝箱（避免把结算流程再拉长 6~8 秒）。如后续需要，可单独给终局加一个纯演出宝箱。

- `npm test`：全量 **465/465** 通过；
- `tests/black-hole.test.mjs`：新增「所有落点都在洞心朝玩家一侧」断言；
- `tests/dragon-chest.test.mjs`：新增脸谱箱数值/结算、2 秒横幅、先横幅后计数窗口断言；
- 现场建议：
  1. 第 3 关买黑洞，在第 4/5 关放一次 → 所有怪围在黑洞**前侧**，无黑盘遮挡；
  2. 用精英测试一次散射 → 伤害应为原来的 3 倍；
  3. 第 6 关打死脸谱 Boss → 2 秒横幅 → 脸谱宝箱 → 打箱子看数值涨到 2.0；
  4. 第 12 关打死龙 Boss → 2 秒横幅 → 龙族宝箱 → 攻击力加成不变。
