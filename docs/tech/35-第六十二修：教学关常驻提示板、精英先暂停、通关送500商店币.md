## 0. 现场稿（原样存档）

```
1-教学关的横幅提示时间太短了，来不及看清，我觉得可以将文字信息固定在场地的前上方，
  既不能阻挡玩家看怪的视线，又可以让玩家随时看到信息。直到更换为下个横幅。且只在教学关生效。
2-教学关中精英出现是可以先暂停移动（实践中发现玩家来不及思考，精英已经撞上场地了）。
新增功能：玩家完成教学关后直接送500商城币，给玩家更快启动
```

## 2. 原理

### 2.1 为什么「一次性横幅」救不了教学提示 —— 两者不该合并

第六十一修把横幅折成了两行，解决的是「太长顶出卡片」；但现场新诉求是**时间**：

```
warningBanner（一次性横幅）: 准星正前方 · 2s · 自动消失   → 负责「抓注意力」
TutorialHintBoard（常驻板）: 场地前上方 · 不超时 · 换字才换  → 负责「随时能读」
```

两者**同源**：文案都来自 `content/tutorial.js` 的 `TUTORIAL.BANNER`，由 `TutorialRunner._flushBanner()`
一处下发（同一次调用里既 `_showBanner(text)` 又 `_showTutorialHint(text)`）——
所以永远不会出现「板上写的和刚闪的横幅不是同一句」。**不要**把两者合并成一个组件：
一个是「闪一下」，一个是「钉在那儿」，生命周期完全不同。

### 2.2 位置是怎么算出来的（为什么是 y=4.4 / z=-6.2）

需求是「前上方、不挡怪」。两个约束夹出这个点：

```
下界（别挡怪）：3 倍体型精英（铁甲兵 radius 0.9 × SIZE_MUL 3 ≈ 2.7m 高）在最近处 9m，
                头顶 ≈ atan(2.7 / 9) ≈ 17°；再算它被冻住后玩家低头看它的视锥 ⇒ 板子下沿要 ≥ 20°
上界（别忘了抬头看）：仰角超过 ~30° 就变成「要专门抬头」，头显里体验很差
⇒ 取 21~28°：y = 4.4m 对玩家眼高 ~1.6m ⇒ 高差 2.8m，z = -6.2m ⇒ 仰角 atan(2.8/6.2) ≈ 24° ✓
```

板子在**场地坐标系**里静止（`POSITION` 是场地坐标，不跟头动），
但它是 `THREE.Sprite` —— 自带 billboard，所以玩家转头到哪儿都正对玩家，不用自己写朝向。

### 2.3 为什么板子要在**构造期**建（而不是教学关开始时建）

`_loadLevel` 会给 `_sceneBefore` 拍一张**场景快照**，开场穿云据此判断「哪些物件是本关新出现的」，
然后让它们从 0 淡入。如果板子是教学关开始时才 `scene.add()`，它就会被穿云当成「本关新物体」，
在开场云雾里从 0 一路淡入 —— 和它自己的 `FADE_IN` 叠在一起，看上去像闪了两下。

所以在 `Game` 构造期就 `new TutorialHintBoard(world.scene)`（默认 `visible = false`），
它永远在快照里；显示与否只由 `show()` / `hide()` 说了算。

### 2.4 为什么精英暂停要用「技能 **或** 秒表」双判据

教学关精英段的**目的**是逼玩家第一次用散射（HP 4000，基线 200 DPS 打不完，一次散射 50×100 秒杀）。
精英一落地就往飞毯走 ⇒ 玩家还没读完提示它就贴脸了。冻住它，但**不能等它自己解冻**当唯一出路：

```
放技能   → 立刻解除（这才是教学要的动作，玩家看到「原来用技能就能秒」，教学闭环）
等 6s    → 也解除（玩家在试枪、或根本没看懂提示，不能把人锁死在原地）
被子弹打中 → **不**解除（那正是要教的反例：打是打不动的，让它站着给玩家试）
```

`moveFrozen` 只跳过**位置推进**一个分支：

```js
// balloons.js update() 首行
if (!this.controlled && !this.moveFrozen) { /* 朝玩家移动 + 走到边自爆 */ }
```

于是朝向（billboard）、受击反馈、血条、名牌全部照常 ⇒ 看上去是「它停在那儿瞪着你」，不是卡死。
副作用是好的：冻住的怪永远走不进飞毯区，也就不会自爆收场。

## 3. 关键实现

### 3.1 `src/game/tutorialHint.js`（新）· `TutorialHintBoard`

| 成员 | 作用 |
|---|---|
| `show(text)` | 空串/`ENABLED:false` 直接忽略；**同文案不重绘**（省一次纹理上传）；每次都回到基准位并重新淡入；`_t = 0` |
| `hide()` | `visible = false` + `opacity = 0`（不销毁，随时可再显示） |
| `update(dt)` | 淡入插值；淡入结束后 `opacity` 只写一次（之后不再每帧写材质）；`BOB` 轻浮让玩家一眼看出「这是提示板不是场景物件」 |
| `_draw(text)` | 半透明圆角底板 + 冰蓝边框 + 左侧竖标签「教学」+ 正文 `wrapBannerText(≤3 行)` 先描边后填充 |
| `dispose()` | 从场景摘除 + 释放材质/纹理 |

- `renderOrder = 890`：场景之上、一次性横幅（900）之下、通关横幅（1000）之下。
- `get showing` / `get text`：给测试与调试用。

### 3.2 `src/content/tutorial.js` · 数据与纯函数

```js
ELITE: { ..., HINT_DELAY: 2.4, HOLD_SECONDS: 6 }
DONE:  { CARD_DELAY: 2.2, SHOP_COIN: 500 }

/** 冻住之后能不能放开：放技能 or 等够 HOLD_SECONDS（HOLD_SECONDS<=0 = 不冻 = 旧行为） */
export function eliteHoldOver(holdT, skillUsed) {
  if (skillUsed) return true;
  const H = TUTORIAL.ELITE.HOLD_SECONDS;
  return !(H > 0) || Number(holdT) >= H;
}
```

### 3.3 `src/game/tutorial.js` · 判定与下发

- 新增字段 `_elite` / `_holdT` / `_castsAtHold`（进段/换段都复位）。
- `update()` 里新增 **③b**：精英段每帧累积 `_holdT`；`used = g._skillCasts > _castsAtHold`；
  `eliteHoldOver(_holdT, used)` 成立就 `moveFrozen = false` 并打一条日志留痕（区分「玩家已放技能」/「等够 Ns」）。
- `_spawnElite()` 的 `onSpawn`：`b.moveFrozen = E.HOLD_SECONDS > 0`，同时记下 `_castsAtHold`。
- `_flushBanner()` 末尾：`this.g._showTutorialHint && this.g._showTutorialHint(text)` —— **同一次下发，横幅与板同文案**。
- `_finish()`：`_hideTutorialHint()`（出教学关即收板）。
- 顺手删掉一份重复定义的 `_clearWave`（上一轮编辑残留，第二份覆盖第一份且多了一行重复 push）。

### 3.4 `src/game/game.js`

- `import { TutorialHintBoard }`；构造期 `this.tutorialHint = new TutorialHintBoard(world.scene)`；`this._skillCasts = 0`。
- `_loadLevel()`：`this._skillCasts = 0; this.tutorialHint?.hide();`（技能计数与板子都不跨关）。
- `_triggerSelectedSkill()` 成功分支末尾：`this._skillCasts++`（**只有真的放出来才算**，能量不足不算）。
- `update()`：`this.tutorialHint?.update(dt)`。
- 新增 `_showTutorialHint(text)` / `_hideTutorialHint()` 两个转发钩子。
- `_finishTutorial()`：收板 + 送币

```js
const gift = TUTORIAL.DONE.SHOP_COIN | 0;
if (gift > 0) { this.shopCoin += gift; this.hud.setShopCoin(this.shopCoin); this.log(...); }
```

**只有教学关给这 500**：第 2~18 关通关**一律不奖励**（本项目不做关卡结算奖励）⇒
这笔钱压根不是「击杀能量入账」，所以在 `_finishTutorial` 里直接 `shopCoin += 500`，
**不改调 `_addShopCoin`**（那条路径是击杀入账用的，带「以战养战」加成，会把 500 变成 550）。

### 3.5 `src/game/warningBanner.js` · `wrapBannerText` 泛化成 N 行

原来只支持 2 行（写死两行取最优断点），提示板要 3 行 ⇒ 拆成两步纯函数：

```
_wrapIntoLines(s, maxW, maxLines, width)   // 在 [1, maxW] 里二分找**最小可行行宽预算**，使贪心折行 ≤ maxLines 行
_greedyLines(s, budget, width)             // 按**码点**贪心折（emoji/生僻字不会被劈成半个）
```

- 取**最小**可行预算 ⇒ 各行长度尽量接近（避免「一行挤爆、一行空着」）。
- 找不到可行预算（这段文字在 maxLines 行里就是放不下）⇒ 退化成「按最宽可用宽度贪心」，
  行数超标但**绝不超宽**，交给外层继续降字号兜底。
- `_drawWarn` / `_drawHeal` 调用处未改（默认 `maxLines = 2`）⇒ 一次性横幅行为不变。

### 4.1 `TUTORIAL_HINT`（`src/core/constants.js`，可经 `userConfig.js` 热调）

| 键 | 缺省 | 说明 |
|---|---|---|
| `ENABLED` | `true` | `false` = 整块常驻板关掉（回到「只有 2s 横幅」） |

| `TEXT_SIZE / MIN_SIZE` | `84 / 52` | 初始字号 / 降字号下限（px） |
| `MAX_LINES` | `3` | 最多折几行（折不下才降字号） |
| `TEXT_LEFT / TEXT_RIGHT` | `186 / 56` | 文字区左右内边距；左侧要让开「教学」标签 |
| `LINE_H` | `1.06` | 行距 = 字号 × 该系数 |
| `BOB / BOB_HZ` | `0.05 / 0.35` | 上下轻浮幅度（米）/ 频率（Hz）；`0` = 不浮 |
| `BG / BORDER / TEXT_COLOR` | 半透明深蓝底 / 冰蓝框 / 近白字 | 冰蓝是为了和「精英来袭」橙红、「飞毯血量」绿分开 |
| `LOG` | `false` | `true` = 每次换字打一条日志 |

### 4.2 教学关数据

| 键 | 缺省 | 说明 |
|---|---|---|

## 5. 踩坑

1. **提示板别在关卡开始时才建**。`_loadLevel` 的 `_sceneBefore` 快照会把新 `add` 的物件算成「本关新物体」
   并让它从 0 淡入 —— 板子必须**构造期**建好、默认隐藏。这是「造好但不显示」与「显示时才造好」的区别。
2. **`wrapBannerText` 的退化契约要写清**。200 字塞进 2 行本就无解（`maxW 200`、每字 22px ⇒ 每行 9 字），
   所以退化时**允许行数超标，但不许超宽、不许丢字、不许死循环缩字号**。
   `tests/danger-alarm.test.mjs` 里那条极端用例的判据据此改成「不超宽 + 不丢字」。
3. **`_skillCasts` 只在真的放出技能时 +1**。挂在「按了扳机键」上会让「能量不足没放出来」也解除冻结，
   教学就失去意义（玩家以为用过了，其实没放）。
4. **这 500 只属于教学关**。其它关通关不奖励，所以它不是「击杀能量入账」；别图省事改调
   `_addShopCoin`（那条路径带「以战养战」加成，500 会变成 550）。
5. **冻结只跳位置推进**。把整个 `update()` 早退会让朝向/血条/受击一起停 ⇒ 看上去像卡死的 bug。
6. **`dispose()` 要有场景桩**。单测里 `new TutorialHintBoard({ add })` 必须同时给 `remove`，
   否则 `dispose()` 报 `this.scene.remove is not a function`。

  4. 教学关收尾时日志出现一行 `教学关通关奖励：+500 商店币（现有 N）`，**只有教学关会有这一行**；
     第 2 关打完（进第 3 关商店之前）不会出现任何奖励行 —— 商店币只来自击杀能量入账。
- 部署口径：本轮改了 `src/**`（含 `src/content/tutorial.js`、`src/core/userConfig.js`）⇒
  内容包要重传、**APK 要重打**（游戏代码本体走 APK assets）；包名/版本号保持
  `com.DX.WeirdTurning` / `154` / `1.5.4` 不动。EXE 本轮不必重打。
