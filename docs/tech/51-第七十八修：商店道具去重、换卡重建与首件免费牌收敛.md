# 第七十八修：商店道具去重、换卡重建与「首件免费」牌收敛

## 现场反馈

> 还是不对，这个是拍的照片，还需要我提供什么吗

两张现场照片能直接读出三件事：

1. 左侧道具列出现两张一模一样的「以战养战」，卡面都写「Lv.0→1 / 免费」；
2. 第二张「以战养战」的气球是蓝色（`多才是王道` 的颜色），不是 `以战养战` 的黄色；
3. 道具列上方有一块巨大的绿色「任选一件免费」牌子，从侧面看会挡住整列卡。

第 2 条尤其关键：球色和卡面不同源。这说明不是「抽签抽重了」这么简单，而是
「槽位复用了旧 entry，但卡面/球色没有一起换」或者「场景里叠了两套商店」。
抽签函数本身（`pickShopItems`）在 6 个 id 里洗牌取前 3 个，结构上不可能重复。

## 根因（三条都堵）

### 1. 槽位复用只换 def，不保证卡面/球色同源

第七十三修为了消掉「购买后卡一下」，把 `_build()` 从「整店重建」改成
「按 `item:slot:N` 复用 entry，原位重绘贴图」。但复用条件只看了 key。
买走一个道具后，同一个槽位里的 `def` 已经换成另一个道具，entry 却还是旧对象。
只要 `repaintCardTexture` 因为任何原因没有真正刷新（旧缓存 / 纹理上传失败 / 旧的
`entry.faceSig` 已经等于新签名），就会留下旧卡面 + 新球色——正是照片里的样子。

修复：槽位里的 `def.id` 变了就 `_removeEntry` 并重新 `_createEntry`。
只重建换道具的那一个槽，其它槽位与预告卡仍然复用；一次购买最多重传 1 张贴图，
不会回到「整店 8 张全重传」的卡顿。

### 2. `_itemDisplay` 可能被外部污染成重复 id

`_itemDisplay` 是展示数组，刷新 / 补位 / 重进店都会改写它。只要有任意一条旧路径
（旧 APK 缓存、重复 open、内容包旧版本）写进 `['warFeed','warFeed',...]`，
`_itemEntries()` 就会老老实实建两张同款。

修复：新增 `_sanitizeItemDisplay()`，在每次 `_itemEntries()` 前做最后一道硬约束：

- 未知 id 丢掉；
- 重复 id 只保留第一次；
- 不足 3 个时从「未展示的道具」里补齐；
- 就地改写 `_itemDisplay`，保证补位 / 刷新 / 留痕拿到的是同一份干净数据。

这样即使上游再出错，画面上也永远是 3 个不同道具。

### 3. `_enterShop()` 可能叠两套商店

旧实现直接 `this.shopDraft = new ShopDraft(...)`。如果分帧任务 / 重进关把
`_enterShop()` 跑了两次，旧 group 还留在 scene 里，两套卡会在同一位置叠层——
表现就是「同一张卡出现两次 / 两张卡内容一样」。

修复：进店前先 `dispose()` 旧 `shopDraft`；同时留痕新增 `重复=是/否`，
下次现场一眼能看出是不是又叠层了。

## 「首件免费」牌：不再单独建大绿牌

第七十七修为了解释「三张都写免费」，在道具列上方又挂了一块 1.44×0.45m 的绿色牌子。
现场照片里它离玩家很近，透视放大后几乎挡住整列。

修复：

- 删除独立的 `freeBadge`；
- 把免费状态并进道具列原有的商店币牌子：
  - 有资格：`商店币 3250 · 首件免费`（绿色）
  - 买掉第一件：`商店币 3250`（金色）
- 牌子的位置 / 尺寸不变，不再多一块贴脸的绿牌。

三张道具卡仍然写「免费」——这是准确的（任选一件实扣 0）；「只能免一件」由
商店币牌子的「首件免费」表达。买掉第一件后三张自动恢复原价。

## 留痕

进店那一行改为：

```text
第 3 关 · 商店关：… 道具=[s0:candyString,s1:moreIsBetter,s2:warFeed] 重复=否 首件免费=1；…
```

`s0/s1/s2` 是槽位号；`重复=是` 出现时，直接按上面第 2/3 条排查。

## 测试

`npm test`：473 / 473 通过（新增 2 条，改写 1 条）：

- 「道具展示位强制去重」：手动把 `_itemDisplay` 改成 `['warFeed','warFeed','lifesteal']`，
  断言 `_build()` 后仍是 3 个不同 id；

## 现场验证

1. 安装 1.5.6，完全退出 PICO 浏览器再进游戏（清掉旧 ES Module 缓存）；
2. 第 3 关进店，看左侧是否 3 张不同道具卡；第二张的球色必须和卡面颜色一致；
3. 道具列上方只应有一块「商店币 … · 首件免费」，不应再有第二块大绿牌；
4. 打掉任意一个道具：实扣 0，牌子变成「商店币 …」，另外两张恢复原价；
5. 若仍出现重复，把 `page-forensics.log` 里「第 3 关 · 商店关」那一行发给开发——
   `重复=是` 说明是叠层/旧包，`重复=否` 说明是画面上看错或旧缓存。
