# 28 · 商店关（原机制关改造）—— 第五十五修

> 本文档面向「从零复现 / 移植」：把第 3 / 9 / 15 关从**激光机制关**改成**商店关**（打气球买强化），
> 并把商店币、道具、技能强化整套数值口径集中到一处。
> 结构：**目标 → 口径（用户拍板） → 原理 → 关键实现 → 参数表 → 踩坑 → 验证方法**。

---

## 1. 目标

- 机制关（3 / 9 / 15）不再需要**躲激光 / 踩格子 / 解密**：玩家只做一件事 —— 用枪**打气球**买单。
- 正前方是**技能区**（3 技能本体，或 3 技能强化 + 「购物完成」）；左手边是**道具区**（3 道具 + 「刷新道具」）。
- 商店币来自**击杀积分等额入账**；道具**跨关（1~18 关）全局有效**、可重复升级；技能本体 / 强化**每次进店每项限购 1 个**。
- 商店关**不发选项卡**（原机制关那套抽卡已由商店替代）。

## 2. 口径（第五十五修用户拍板）

| # | 项 | 口径 |
|---|---|---|
| 1 | 商店币 | = 击杀积分**等额**入账（精英 ×2 照算）；**无上限**；**一局（1→18 关走完）清零**；与技能积分 `score`（`SCORE_CAP=500`）**完全独立** |
| 2 | 价格 | 第 3 关三个技能本体各 **1000**；第 9 / 15 关三个技能强化各 **1500**；道具费用 = `1000 × 目标等级`（升到 Lv.n 花 `1000n`） |
| 3 | 限购 | 技能本体 / 技能强化**每项每次进店只买 1 个**；道具**可重复购买升级** |
| 4 | 道具抽取 | **6 选 3 不重复**；买走**补位**（从剩余 3 个里随机补一个，不重抽全排）；刷新 **200 起逐次翻倍**（进店重置），**重抽全部三个** |
| 5 | 血量 | **固定 100**（第五十五修删掉 `hp` 属性卡）；`selfRepair` 保留（+2%/s，上限 10% ⇒ 按 100 上限算即 +2/s ⇒ +10/s 封顶） |
| 6 | 商店关形态 | **只有魔术师开场动画**（`OPENING_MAGICIAN`）+ **无开场语音** + **不掉血** + **无激光**；倒计时 **60s**；另有「购物完成」气球可提前走 |
| 7 | 第 3 关奖励 | 「选完技能赠 **500 积分**」保留（`score`，非商店币） |
| 8 | 选项卡 | 商店关**不发**（`_enterCard` 遇 `shopMode` 直接进下一关） |
| 9 | 机制关几何 | 三份几何文件（`laserLevel.js` / `glassGrid.js` / 翻转阵）**保留在仓库**，只是商店关**不再创建**；第 9 关地面玻璃格子取消 ⇒ **飞毯恢复可见**（`laserMode` 概念随之删除） |

## 3. 原理

### 3.1 关卡分类：`kind: 'laser'` → `kind: 'shop'`

- `src/content/levels.js`：第 3 / 9 / 15 关的 `kind` 由 `laser` 改成 **`shop`**，同时**删掉 `laserMode`**；
  新增 `export function isShop(lv)`；`shouldShowLevelTitle` 的判据也纳入 `shop`（否则商店关看不到关卡名）。
- `game.js` 里原有的 `isLaser(lv)` 分支**全部保留**（`laserLevel` / `glassGrid` 等类还在），只是这三关不再命中。
- 好处：商店关与机制关**共用同一条「非普通关」通道**（无传送门、不拍快照、开场用 `MECHANIC_DELAY` 排关卡名），
  改动面收窄到「分岔点」，不牵动出怪 / 推流 / 平台链路。

### 3.2 商店场地 = `ShopDraft`（照抄 `CardDraft` 范式）

`src/game/shop.js` 的 `ShopDraft` 与 `cardDraft.js` 同源：`makeCardTexture()` 画卡面、`makeBalloon()` 做气球，
命中判定同样用**子弹线段 vs 气球球心的距离**（`pointSegmentDistanceSq`）。差别：

- **不是一次性三选一**：`_build()` 每次购买 / 刷新后**整排重建**（`_clear()` → 重新算坐标 → 重新 `_addEntry`），
  买掉的项目直接从架上消失、**后面的自动居中补位**（`x0 = -((n-1) × FRONT_SPACING)/2`），**不留空位**。
- **有两片场地**：正前方一排（`FRONT_*`：技能本体 / 技能强化 + 购物完成）与**左手边一列**（`ITEM_*`：3 道具 + 刷新）。
- **购买动画**：命中 → 气球爆炸 → `_spawnLightFx()` 光点飞散 → `_updateResolve()` 到 `SHOP.BUY_FLY` 秒后执行 `after()` 回调（改状态 / 补位 / 建下一排）。
- **买不起**：气球弹一下（`_denyT=0.4`）+ 中途横幅提示「商店币不足」，**不消费、气球留着**。
- **倒计时归零**：自动 `_finish()`（**不软锁**），与打「购物完成」同一条收尾路径。

### 3.3 数值口径单点化：`src/content/shopItems.js`

`SHOP_ITEMS`（6 道具）/ `SKILL_UPGRADES`（3 强化）两张表 + 一组**纯函数**：

| 纯函数 | 含义 |
|---|---|
| `shopItemPrice(id, levels)` | 道具升到下一级的价格 = `ITEM_BASE_PRICE × (当前等级+1)` |
| `warFeedMul(level)` | 「以战养战」商店币倍率：`1 + 0.10 × level` |
| `lifestealChance(level)` | 「吸血子弹」每发子弹击杀回血概率：`0.10 × level` |
| `strongHunterMul(level)` | 「专打强者」对精英 / Boss 最终伤害倍率：`1 + 0.2 × level` |
| `mibCooldown(level)` | 「多才是王道」第 level 级冷却秒数：`MIB_COOLDOWN - (level-1)`，**下限 = `MIB_DURATION`（2s）⇒ 可以不间断** |
| `pickShopItems(count, rand)` | 洗牌取前 count 个（**6 选 3 不重复**；`rand` 可注入便于单测） |
| `pickShopItemExcluding(ids)` | 从池里排除已在架 id，随机补 1 个（补位用） |

### 3.4 游戏侧接线（`game.js`）

- 状态：`shopMode` / `shopCoin` / `_itemLv{}`（道具等级）/ `_candyCount`（串糖葫芦全局累计）/ `_mibUntil` / `_mibNextAt` / `_shopLeft`。
  **一局清零**：`startGame()` 与 `toMenu()` 都把这些复位。
- `_loadLevel()`：`shopMode = isShop(lv)`；商店关**不建传送门、不建机制几何、不拍快照**（与 `isLaser` 同轨），
  分帧任务表里改推 `_enterShop()`；BGM 与机制关同档（`kind:'laser'` 走同一套程序化曲目）；`forceSingleShot = true`（点靶更准、避免多弹道误打相邻气球）。
- **击杀入账**：`_addShopCoin(n)` 是唯一入口（普通击杀 / 龙部件 / 聚宝盆积分四处都调它），内部乘「以战养战」倍率。
- **商店关不发选项卡**：`_enterCard()` 开头 `if (this.shopMode) { this._exitShop(); return; }`（放在所有抽卡逻辑之前，是真正的早退）。
- 每帧：`_updatePlaying` 里商店关走 `_updateShop(dt, pp)`（气球交互 + 倒计时 + HUD），并跑 `_tickShopItems()`。

### 3.5 六个道具的效果落点

| 道具 | 效果 | 代码落点 |
|---|---|---|
| 打狗还要看主人 | 子弹击杀时向 **5m 内最近的精英 / Boss** 发射 N 颗**追踪弹**（伤害 = 当前攻击力 × 2，紫色 `DOG_COLOR`）；场上无精英 ⇒ **不生成** | `_shopBulletKill` → `_spawnHomingBullets` |
| 以战养战 | 击杀商店币 **+10% / 级**（`warFeedMul`） | `_addShopCoin` |
| 串糖葫芦 | **全局累计**每满 10 发，额外补 1 颗**穿甲弹**（`pierce`，青色 `CANDY_COLOR`，可穿透多个敌人） | `_firePlayerShots` |
| 多才是王道 | 自动触发：**+2 临时弹道 / 2s**，冷却 `mibCooldown(level)`（买完立刻生效，冷却从买完算） | `_buyShopItem` / `_tickShopItems` |
| 吸血子弹 | 每发**子弹击杀**按 `lifestealChance` 概率回 1 血（满血不回） | `_shopBulletKill` |
| 专打强者 | 对精英 / Boss 最终伤害 ×`strongHunterMul(level)` | `_applyShopDamage`（`_collide` 命中时先过一遍） |

> 「打狗 / 吸血」只认**子弹击杀**（`_shopBulletKill`），技能击杀不触发 —— 与「吸血子弹」字面一致，也避免神掌 / 激光剑一次清场刷满收益。

### 3.6 技能强化（第 9 / 15 关）

玩家**已持有三选一技能**时，正前方自动从「技能本体」切换为三张强化：

- **技能威力+**：`skillDamageMul +1`（**上限 ×5**，复用原口径）；
- **技能消耗-**：`skillCost -100`（**下限 100**，复用原口径）；
- **技能冷却-**：`skillCdDown += SHOP.CD_DOWN(2s)`（`_skillCdTotal()` 里扣减；**另加下限 `CD_FLOOR = 1s`**，避免冷却被减成 0）。

> **第六十修补注**：`skillCost` / `skillDamage` 这两张属性卡已从**第 1~2 关的卡池里去掉了** —— 技能本体是第 3 关商店关才卖的，前两关抽到这两张等于**空卡**，只会把三选一浪费掉。口径落在 `cards.attrPoolForLevel(n <= 2)`（收成「射速 / 子弹 / 攻击」+ `strictPool`）与 `availableAttributes(player, ids, strict)` 的补位守卫，详见 [33-第六十修：第 1 关教学关与前两关卡池](./33-第六十修：第1关教学关与前两关卡池.md)。
> 本节（第 9 / 15 关的技能强化）**不受影响**。

> 「技能冷却-」的减冷**只在商店关（机制关）生效**（原机制关语境），因此实际只会被减两次（第 9、15 关各买 1 次）。

## 5. 踩坑（多次调试点）

1. **`_spawnLightFx()` 里 `_clearLightFx()` 的顺序**：若把 clear 放在建粒子**之后**，它会把刚设好的 `_lightStart / _lightDelay / _lightN` 清空 ⇒ 购买动画当场崩。clear 必须在函数**开头**。
2. **`_build()` 必须重建坐标**：买掉一项后如果只 `visible=false`，那排会**留一个空洞**；正确做法是整排重建、按剩余数量重新居中。
3. **商店关不发选项卡要用真正的早退**：`_enterCard()` 开头就 `if (this.shopMode) { this._exitShop(); return; }`；
   若只在分支末尾拦，前面已经 `state='card'`、清子弹、置 `forceSingleShot`，会留下半套抽卡状态。
4. **`hp` 属性卡删除后的池子要同步**：`_enterCard` 里第 9 关 `plan.guarantee` 与 Boss 关卡池若还写 `'hp'`，
   `availableAttributes()` 拿不到该卡会**静默少一张**（不是报错）⇒ 第五十五修把 `hp` 从池与 guarantee 里一起删掉。
5. **`laserMode` 一并删除**：`world.carpet?.setVisible(lv.laserMode !== 'drive')` 这类判断在商店关下必须退化成「恒显示」；
   第 9 关地面玻璃格（`GlassGrid`）不再创建 ⇒ 飞毯恢复可见。
6. **一局清零的时机**：`shopCoin` / `_itemLv` 必须在 `startGame()`（新一局）与 `toMenu()`（回菜单）**两处**都复位，否则回菜单再来一局会带着上一局的道具等级。
7. **「多才是王道」冷却从买完算**：`_mibNextAt = _gameTime + mibCooldown(lv)`；用 `_gameTime`（游戏内累计时间）而非 `performance.now()`，暂停 / 回菜单才不会「偷偷走表」。

## 6. 验证方法

- **单测**：`tests/shop.test.mjs`（21 项）锁关卡表 / 参数 / 纯函数 / 购买状态机 / game 侧道具数值；
  另有 `tests/collide-prune.test.mjs`（假 game 补 `_itemLevel` / `_applyShopDamage` / `_shopBulletKill`）、
  `tests/cards.test.mjs`（「生命卡已移除」断言）、`tests/level-title-label.test.mjs`（`isShop` 关卡名）、
  `tests/spawn-director.test.mjs`（商店关不出怪脚本）。全量 `npm test` 294 项全绿。
- **现场手测**：
  1. 第 3 关：正前方三张技能 + 购物完成；打中技能 → 扣 1000 → 正前方换成三张强化；打「购物完成」→ 进第 4 关并到账 +500 积分；
  2. 第 9 / 15 关：三张强化各 1500、每项买一次即下架；左手边道具买后**补位**、刷新价 200→400→800…、倒计时到点自动走；
  3. 道具数值：以战养战加币、串糖葫芦每 10 发补穿甲弹、多才是王道自动 +2 弹道 2s、吸血回血、专打强者加伤、打狗追踪弹（紫色，5m 内无精英则不出现）；
  4. 商店关**看不到关卡名以外的抽卡**、L3 魔术师动画在开场播放、无语音、不掉血、飞毯可见。
