## 0. 现场稿（原样存档）

用户口述稿，编号即稿里的「横幅提示 N」：

```
0- 关卡名字显示完之后，玩家的前方、左边（就是传送门方向）各出现一个小怪气球
1- 横幅提示1：敌人出现，扣动扳机击杀他们
2- 击杀完敌人（或横幅1 出现后超过 10 秒，敌人全部消失）→ 横幅提示2：很棒的枪法，打破前方气球获得奖励吧
3- 选项卡位置弹出一个选项卡：每射击杀敌 10 个射击速度加倍，持续 3 秒
4- 打破选项卡气球（或横幅2 出现后超过 12 秒，选项卡默认选择）→ 连杀数重置为 8
   → 前方出现五个小怪气球 → 横幅提示3：再杀两个试试加倍射速的威力吧
5- 击杀五个气球（或横幅3 出现后超过 15 秒）→ 末尾精英横幅 → 内圈出现一个精英怪
   → 横幅提示5：射击来不及了，快使用左手侧键的散射技能（精英阶段散射无消耗、无冷却，直到精英被杀死）
6- 精英被杀死 → 横幅提示6：敌人已清空，拿完奖励去下一个空域 → 正常选项卡再弹出
```

另外两条：
- **第 1 关做成教学关**（不是新增一关）：第 1 关的旧编排被教学流程整段接管。
- **选项卡系统：前两关不再出现技能相关的选项卡**。

## 1. 目标

第 1 关要在 60 秒内把四件事各教一遍，每一件都要**玩家自己动手做过一次**：

| 教学点 | 手段 | 判据 |
|---|---|---|
| 会开枪 | 前方 + 左（传送门方向）各 1 只杂鱼 + 横幅1 | 打完这 2 只 |
| 会拿卡 | 横幅2 → 选项卡位置弹出**单张**教学卡「连杀加速」 | 打破气球（或 12s 自动获得） |
| 看得见「加倍射速」 | 连杀数**种到 8** + 前方 5 只 → 再杀 2 只就触发一次加速 | 打完 5 只 |
| 会用散射技能 | 内圈一只铁甲兵（普通射击打不完）+ 散射**免费无冷却** | 打死精英 |

选项卡侧的第二件事：**第 1~2 关的卡池去掉「技能消耗 -100 / 技能伤害 +1 倍」**。
理由见 2.2 —— 这两张在前两关是**空卡**。

**不动**：第 2~18 关的编排、商店关（3/9/15）、末尾精英口径、Boss 关（6/12/18）、平台链路
（`/api/master/allow`、CMD 5/7/16、UDP 51124/51234、推流、门禁）一行未碰。

## 2. 原理

### 2.1 为什么单开一个模块，而不是往 `SPAWN_SCRIPT` 里加事件

`spawnDirector.SPAWN_SCRIPT[n]` 的事件表是**纯时间驱动**的（`{ t }` 定点 / `{ every }` 周期）：

```js
SPAWN_SCRIPT[1] = { trashMul: 1.5, trashMulUntil: 30, events: [ { t: 31, banner: ... }, { t: 33, merge: ... } ] }
```

教学关每一段都要等「怪被打完」这种**条件**推进，还要在**段与段之间改玩家状态**
（种连杀数 / 开一张单卡 / 开免费技能）。这两类驱动混在一张表里必然互相覆盖：
例如「33s 融合出铁甲兵」会跟「横幅3 之后才出精英」打架。

⇒ 拆成两层：

- **数据 + 纯函数** `src/content/tutorial.js`：段落表 / 文案 / 时长 / 出生方位 / 判据。**可单测**。
- **运行态** `src/game/tutorial.js` 的 `TutorialRunner`：一个每帧 `update(dt)` 的小状态机。
- 教学关开着时 `waves.startLevel()` **让位**：`this._script = null` + `this._dripStopped = true`
  （既掐掉 `SPAWN_SCRIPT[1]`，也掐掉 DPS 滴流），`_stopAt()` 返回 `Infinity`（没有倒计时，
  也没有「时间到 → 通关」这条判据）。waves 只保留既有管线：**光点飞入 + 落地生成**。

### 2.2 为什么前两关要去掉技能相关卡

「技能消耗 -100」「技能伤害 +1 倍」都作用在 `player.skillCost / skillDamageMul` 上，
而**技能本体是第 3 关商店关才卖的**（`SKILL_CARDS`：如来神掌 / 激光剑 / 散射强化）。
前两关玩家手里没有任何技能 ⇒ 抽到这两张等于**空卡**，白白把三选一浪费掉。

⇒ `cards.attrPoolForLevel(n)`：`n <= 2` 时池子收成三张必有用卡，并置 `strictPool = true`。

### 3.2 段落状态机（`TUTORIAL.STAGES`）

| 段 | 入口动作 | 推进判据 | 兜底超时 |
|---|---|---|---|
| `first` | 前方 + 左前各 1 只杂鱼，横幅1 | 这批清空 | 10s（超时 → 残兵原地消失，继续） |
| `card` | 横幅2 **收掉后**弹单张教学卡 | 卡被打破（或 12s 自动获得） | — |
| `seed` | 连杀数种到 8 + 前方 5 只，横幅3 | 这批清空 | 15s（同上） |
| `elite` | 散射免费 + 「前方精英来袭」 + 内圈 1 只铁甲兵；2.4s 后横幅5 | 精英消失（被打死或走到飞毯边自爆） | **无**（`0` = 只等条件） |
| `done` | 恢复收费 + 横幅6 | 横幅收掉 + `DONE.CARD_DELAY`(2.2s) | — |

`done` 之后再走一步 → `_finish()` → `game._finishTutorial()` → `_enterCard()` 走**正常三选一**（不推关卡号）。

开场前还有一道门：`index < 0` 时等 `game._levelTitleDone`（关卡名横幅播完，稿子第 0 条的前提），
最多等 `TITLE_WAIT = 8s` 兜底；名字横幅与后面的提示**共用一块 Sprite**，所以还要等它收掉才 `_enter(0)`。

### 3.3 横幅排队（全场只有一块 Sprite）

`warningBanner` 是场景里的**单例**（`game._showBanner` → `midWarning.show(text)`）。教学流程因此
**不直接 show**，而是：

```
_queueBanner(text) → this._queued = text
每帧 _flushBanner()  → 若 _queued 且 midWarning.showing === false → 真弹，清空 _queued
```

不排队的话，「横幅1」还没播完就被「横幅2」顶掉，稿子里的提示 1/2/3/5/6 会串成一条。
单卡段同理：**等横幅2 收掉再弹卡**，否则横幅压在卡面上。

### 3.4 「打完没打完」的判据：光点还在飞也算

```js
_aliveOf(wave) {
  let n = 0;
  for (const b of this.g.balloons.list) if (b.alive && b.tutorialWave === wave) n++;
  const mine = this._mineTypes();                       // 教学关自己会出的敌种
  for (const it of this.g.waves._pendingSpawns || []) if (it && mine.has(it.type)) n++;
  return n;
}
```

`tutorialWave` 是**光点落地那一刻**由 `_queueSpawn` 的 `onSpawn` 回调挂上的。
只数场上的气球就会踩一个必然的坑：**出怪那一帧**光点还在传送门往场上飞，
`alive === 0` → 同一帧被判「已清空」→ 横幅1 直接被横幅2 顶掉。

`_mineTypes()` 只认教学关会出的敌种（`basic` + `ELITE.TYPE`），别把别的系统丢进 `_pendingSpawns`
的光点误算成自己人；`_clearWave()` 清残兵时也复用它。

### 3.5 精英段的免费散射

`tutorial._freeSkill(true)` 只改**一个布尔** `game._tutorialFreeSkill`，三处读它：

| 读取点 | 免费时 |
|---|---|
| `game._skillCdTotal()` | 首行 `if (this._tutorialFreeSkill) return 0;` ⇒ 不进冷却 |
| `game._castScatter()` | 跳过扣分与余额校验（`if (!this._tutorialFreeSkill) { ...扣分... }`），日志改「教学免费」 |
| `vr/skillHint.js` | 消耗位显示「免费」，就绪文案改「技能就绪 · 教学免费 · 扣左手柄 Grip」 |

恢复收费有**两处**兜底：`done` 段入口 + `TutorialRunner._finish()`（正常路径不会漏）。
精英段**没有超时**：如果玩家就是不放技能，铁甲兵会自己飘到飞毯边自爆收场（`ELITE.SPEED = 0.5`）。

### 3.6 卡池 strict（前两关）

```js
attrPoolForLevel(n)  // n <= 2 → { pool: ['fireRate','multiShot','atk'], strictPool: true }
                     // n >= 3 → { pool: [...BASE, ...SKILL],      strictPool: false }
```

`availableAttributes(player, ids, strict = false)` 里的补位循环加了 `if (!strict)` 守卫：

```js
if (!strict) for (const card of ATTR_TYPES) if (pool.length < 3 && useful(card) && !pool.includes(card)) pool.push(card);
if (!pool.length) pool.push(RESUPPLY_CARD);   // 战场补给（回满血 + 3s 护盾）
```

不加这道守卫的话：玩家把射速 / 子弹 / 攻击三张吃满后，**补位又会把被排除的技能卡捡回来**
（`useful()` 只看玩家当前值，`skillCost` 未初始化 ⇒ 判「还能成长」）。第 3 关起 `strict = false`，
补位口径与改动前完全一致。

## 4. 参数表（`src/content/tutorial.js`）

| 键 | 值 | 说明 |
|---|---|---|
| `ENABLED` | `true` | **唯一回退开关** |
| `LEVEL` | `1` | 教学关 = 第 1 关 |
| `TITLE_WAIT` | `8` | 等关卡名横幅播完的兜底秒数 |
| `BANNER.KILL/CARD/RAPID/ELITE/SKILL/DONE` | 稿子提示 1/2/3/4/5/6 原文 | 全部有单测钉住 |
| `FIRST` | `COUNT 2`、`DIRS ['front','frontLeft']`、`DIST 15`、`SPREAD 6`、`TIMEOUT 10` | 开局两只 |
| `CARD` | `ID 'rapidFire'`、`LABEL '连杀加速'`、`DESC '…加倍 3 秒'`、`ICON 'fireRate'`、`COLOR '#2e86de'`、`TIMEOUT 12` | 单张教学卡 |
| `SEED` | `STREAK 8`、`COUNT 5`、`DIR 'front'`、`DIST 15`、`SPREAD 8`、`TIMEOUT 15` | 种连杀 + 前方五只 |
| `ELITE` | `TYPE 'eliteKnight'`、`HP 4000`、`SPEED 0.5`、`SIZE_MUL 3`、`DIST 9`、`SPREAD 3`、`SELF_DAMAGE 0`、`HINT_DELAY 2.4` | 内圈铁甲兵 |
| `DONE.CARD_DELAY` | `2.2` | 横幅6 之后多等一会儿再开卡（避免压住卡面） |
| `TUT_DIR_DEG` | `front 0 / frontLeft -45 / frontRight +45` | 与 `spawnDirector.DIR_TEXT` 同口径 |

**`ELITE.HP = 4000` 的由来**（教学关立得住的关键）：

- 基线射击 = `100 攻 × 2 发/秒 = 200 DPS` ⇒ 4000 血**20 秒打不完**（逼玩家想别的办法）；
- 一次**积分散射** = `SCATTER.COUNT 50 × 100 攻 = 5000` ⇒ **一击即杀**（技能教学才有说服力）；
- `SELF_DAMAGE = 0`：教学怪不扣血 ⇒ 教学关不会出现「玩家被打死重开」；
- `SPEED = 0.5 m/s`：9m 外飘向玩家 ≈ 10s 才进飞毯，留够「先自己开枪试试」的时间。

## 5. 踩坑（本轮真因）

1. **`seen` 判据是错的**（整轮唯一的功能性 bug）
   最初写的是「本段的怪出现过 **且** 场上 0 只」才推进：
   ```js
   if (alive > 0) this.seen = true;
   ... advance = (this.seen && alive === 0) || timedOut;
   ```
   光点从传送门飞到场上要一秒多，**出怪那一帧** `seen = false` 且 `alive = 0`
   ⇒ 同一帧被判「已打完」，横幅1 被横幅2 顶掉（单测里 `g.banners[1]` 直接变成 `undefined`）。
   修法：删掉 `seen`，判据改 `alive === 0 || timedOut`，并把 `_pendingSpawns` 里教学关的敌种
   也算进 `_aliveOf`（见 3.4）。
2. **`_clearWave` 里 `keep` 被 push 了两次**
   `_pendingSpawns.length = 0` 之后写成两个等价的 `for (const it of keep) push(it)`
   ⇒ 没被清掉的光点**翻倍**。删掉一行，并把 `mine` 集合抽成 `_mineTypes()`
   （原来 `_aliveOf` / `_clearWave` 各算一遍，两处口径会漂）。
3. **`_hintAt` 必须每段重置**：`_enter()` 里统一置 `-1`，只有 `elite` 段入口写 `2.4`。
   否则跨段累计的 `t` 会让后面的段误弹「用散射」提示。
4. **单测里的横幅是手动的**（改测试时才踩到）：fake game 的 `_showBanner` 只把 `_bannerBusy`
   置 `true`，**不会自己收掉**（真实 `warningBanner.update(dt)` 播完会自清）。
   所以断言必须自己排 `bannerOff()`，而且顺序要是「**先 `bannerOff` 再 `update`**」＝
   「上一块已经播完、这一帧轮到下一块」；写成 `update` 完再 `bannerOff` 会让
   `banners[3]` / `banners[4]` 整体错位一帧。
5. **`cardDraft` 的显式卡表要放在最前面判**
   `_buildCards()` 里 `state.cards` 分支必须排在 `state.fixedSkills` 之前（后者改成 `else if`），
   否则单张教学卡会被「第 3 关固定三张技能卡」那条分支抢走。
6. **`strict` 的补位守卫不能只加在 `pool` 上**：`useful()` 是「还能成长」判据，
   `skillCost` 这类**未初始化**字段一律判「可成长」，所以守卫必须加在**补位循环**里，
   而不是过滤 `ids`。

## 6. 验证

**单测**（`tests/tutorial.test.mjs`，18 项；`npm test` 全场 356 项）：

```bash
node --import ./tests/register.mjs --test tests/tutorial.test.mjs   # 18/18
npm test                                                            # 356/356
```

覆盖：开关与段落顺序 / 六条横幅原文 / 超时 10·12·15 与「精英段不超时」/ 出生计划与方位角口径 /
`SEED.STREAK=8` 与 `RAPID_FIRE.KILLS=10` 的关系 / 精英血量口径（打不完 vs 一击秒）/
前两关卡池与 `strict` 补位 / 免费技能三态（不冷却、不扣分、非免费照旧拦）/ `_stopAt → Infinity` /
整条链走一遍（含横幅排队与 ⑤b 技能提示）/ 超时分支 / 「光点还在飞不算打完」/ 精英段只等击杀。

**现场手测口径**：第 1 关开局 → 两只 → 横幅1 → 打完 → 横幅2 → 单张卡 → 打卡 →
前方五只（连杀种到 8，再杀 2 只触发一次加速）→ 打完 → 「前方精英来袭」+ 内圈铁甲兵（散射免费，
2.4s 后弹「用散射」提示）→ 打死 → 横幅6 → 三选一 → 第 2 关；
第 2 关的三选一里**不该**出现「技能消耗 -100 / 技能伤害 +1 倍」。

**回退**：`TUTORIAL.ENABLED = false` ⇒ 第 1 关完整回到旧编排（无需改其它任何文件）。

## 7. 设计取舍（可被否决）

| 取舍 | 现状 | 想改的话 |
|---|---|---|
| 教学关是不是每次开局都跑 | **是**（展会每换一个玩家都要教一遍） | 想「只跑一次」：加一个 `localStorage` 标记，`isTutorialLevel()` 顺带读它 |
| 精英 4000 血 | 口径是「必须用散射才打得动」 | 现场觉得太硬 ⇒ 调 `TUTORIAL.ELITE.HP`（`SCATTER` 一击 = 5000，别超过它太多） |
| 「用散射」提示晚 2.4s | 同一块 Sprite 不能重叠，必须等「前方精英来袭」播完 | 调 `ELITE.HINT_DELAY`（需 ≥ 横幅时长 2s） |
| 教学卡不给数值 | `apply: () => {}`，连杀数由 `_seedStreak` 种到 8 | 想给数值 ⇒ 改 `_enterTutorialCard` 的 `cards[0].apply` |
| 前两关卡池只剩三张 | 射速 / 子弹 / 攻击 | 想加回自我修复（`selfRepair`）⇒ 加进 `ATTR_POOL_BASE` |
