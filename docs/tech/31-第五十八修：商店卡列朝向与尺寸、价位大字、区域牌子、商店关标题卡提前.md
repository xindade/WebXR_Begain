## 2. 「卡面倾斜」的真因：`lookAt(场地原点)` 不等于「平行于地面的 Z 线」

原先两列卡（左手道具列、右手精英预告列）都是这么定向的：

```js
mesh.lookAt(0, holder.position.y, 0);   // 朝「场地原点」
```

`lookAt` 的目标是**场地原点**，而两列卡分别在 X = -3.0 与 +3.0 上 —— 于是每张卡都绕 Y 轴**歪了一个和它
到中线距离相关的角度**（左列 +atan(3/depth)、右列反向），而且**同一列里前排与后排的歪角还不一样**
（Z 越靠后角度越小）。现场感受就是「卡片都在斜着看人」。

**修法**：两列改成绕 Y 轴固定 ±90°，让卡面**平行于地面的 Z 线**（法线指向场地中线）：

```js
if (faceX) card.rotation.y = faceX * Math.PI / 2;   // 左列 +90°（法线 +X）/ 右列 -90°（法线 -X）
else card.lookAt(0, pos.y, 0);                      // 正前方一排保持旧行为（本来就大致朝玩家）
```

保留 `SHOP.SIDE_CARDS_PARALLEL_Z` 开关，置 `false` 退回旧行为（旧行为留着的理由是：万一现场觉得
「正对玩家」更好读，改配置即可，不用改代码）。

> **记一条**：`lookAt(固定点)` 对**成列摆放**的物体是错的选择 —— 它给每张卡一个不同的朝向。成列就该用
> 固定欧拉角；只有「单个像 Billboard 一样追着相机」才用 `lookAt`/`quaternion`。

## 3. 放大 2 倍：必须缩放**整组**，不能只缩放卡面

卡 = 「卡面平面 + 气球球体 + 细绳圆柱」三件的 `Group`。只放大卡面，气球和细绳会留在原地 ⇒ 视觉脱节。
所以缩放加在 `holder` 上（`holder.scale.setScalar(scale)`），代价是**所有「本地坐标 → 世界坐标」的手算
都要乘上 scale**，否则「看着多大」和「打得中多大」不一致：

| 位置 | 旧写法 | 新写法 |
|---|---|---|
| 悬浮幅度 | `CARD.BALLOON_BOB * sin(...)` | `e.bob * sin(...)`，`bob = CARD.BALLOON_BOB * scale` |
| 气球世界高度 | `holder.y + CARD.BALLOON_HEIGHT` | `holder.y + e.balloonY`，`balloonY = CARD.BALLOON_HEIGHT * scale` |
| 命中半径 | `(CARD.BALLOON_R + 0.12)` | `e.balloonHit`，`(CARD.BALLOON_R + 0.12) * scale` |
| 购买光点起点 | `from.y + CARD.BALLOON_HEIGHT` | `from.y + e.balloonY` |

**踩坑**：`tests/shop.test.mjs` 的 `hitEntry()` 辅助函数当年也是手写 `p.y += CARD.BALLOON_HEIGHT` 造子弹
—— 缩放一上线，它造的子弹就**打不到道具列了**（只有默认 1 倍的正前方那排还能中）。修法：helper 改读
`e.balloonY`（生产与测试同源）。这也是 `npm test` 里唯一一条被本轮改红的用例，报的正是
「刷新道具扣 200」失败（打不中 ⇒ 没扣钱）。

## 4. 价位：从「说明文字里夹一个括号数字」搬成卡面底部大字

现场口径两条：**换个容易区分的颜色** + **放大一倍**。做法是给卡面加一个「带价位版式」：

- `makeCardTexture(title, sub, color, icon, { price, priceColor })` —— 给了 `price` 就整体上移一档
  （标题 302→288、说明 348→320、立绘槽高 236→224），把最底一行让给价位；
- `drawPriceText()`：`bold 44px`（＝说明文字 22px 的**两倍**）、画在 y=430、居中、颜色 = `priceColor`；
- 文案侧：**价格从 `sub` 里拿掉**（`sub: '装备后按左手柄释放'`），改由 `priceText` 承载。

| 卡 | priceText | priceColor |
|---|---|---|
| 技能本体 / 强化 / 刷新 | 数字字符串 | `SHOP.PRICE_COLOR`（金 `#ffd43b`） |
| 道具（本店首个免费） | `'免费'` | `SHOP.PRICE_FREE_COLOR`（绿 `#51cf66`） |
| 购物完成 | 不传 ⇒ 不画（保持原版式） | — |

**为什么不用改画布分辨率**：卡面物理尺寸放大 2 倍后，同一张 256×456 的画布被铺到 2 倍大的平面上，
**文字随之等比变大且不会糊**（贴图本身分辨率没变，只是被放大显示）。想更锐再单开一档画布即可。

**踩坑**：`entries` 是 `_addEntry` 里**手写字段投影**的（不是 `{ ...e }`），第一版忘了把 `priceText` /
`priceColor` 带进去 ⇒ 卡面永远不画价位。这也是第五十七修 `free` 字段那个同类 bug 的重演
（见 `docs/tech/30` §6）。**投影对象加字段时，务必同步改投影列表。**

## 5. 区域牌子：`makeBadge()` + 只在文字变了才重绘

现场要「道具区与技能区的气球上方都显示当前商店币」，另外「购物完成」气球上要有倒计时。

**实现**：`cardDraft.makeBadge(text, color)` 返回 `{ mesh, set(text, color?), text, dispose() }` ——
一块 canvas 贴图的平面（画布 512×160，圆角底衬 + 亮色描边 + `bold 84px` 字）。物理尺寸当时是 `SHOP.BADGE_W × BADGE_H` = 0.96 × 0.30 m，
**第五十九修已放大到 1.44 × 0.45 m**（现场「再做大一点」；画布不变 ⇒ 必须严格保持 512:160 同比例，否则文字被拉伸）。

| 牌子 | 挂点 | 位置 | 朝向 |
|---|---|---|---|
| 技能区商店币 | `badgeGroup`（独立子组） |
| 道具区商店币 | 同上 | `(ITEM_X, ITEM_Y + BALLOON_HEIGHT*CARD_SCALE_ITEM + BADGE_DY, ITEM_ZC)` | `π/2`（法线 +X，与道具列同向） |
| 「购物完成」倒计时 |

**文案刻意短**：两块牌子都只写「商店币 N」——`makeBadge` 的字号是自适应的（见下），文案每长一截字号就掉一档：
「技能区 · 商店币 3250」要缩到 ~48px，而「商店币 3250」能吃满 84px 大字。**牌子挂在哪已经表达了它属于哪个区**，
没必要把区域名写进字里再牺牲一半字号。

**两个关键取舍**：

1. **`set()` 去重**：`_updateBadges()` 每帧都调，而 canvas 重绘 + `tex.needsUpdate` 会**每帧上传贴图**。
   所以 `set()` 记 `cur/curtext`+颜色，**完全一样就直接 return false**。
2. **倒计时牌子挂 entry 的 holder，不挂 badgeGroup**：`_build()` 每次购买都会重建可买的卡，若牌子是场景级
   单例，重建后就会指着已经 `_clear()` 掉的气球 ⇒ 悬挂在空处。挂 holder 则**天然随重建走**，
   代价是 `_clear()` 里要顺手 `e.badge.dispose()`（漏了就是每买一次漏一张贴图）。

`_clearBadges()` 只负责场景级两块（离店 / dispose / `_finish()` 三处调用）。

## 6. 商店关标题卡提前：把「等谁收场」抽成纯函数

原口径（第四十九修返工）：机制关(3/9/15) 与激光关一起走 `MECHANIC_DELAY = 12.0`（等魔术师动画收场
+ 兜底），语音正常结束才由 `_bindOpeningVoice` 改排到 `0.5s`。但第五十五修把商店关改成
**只留魔术师动画、去掉开场语音** ⇒ 商店关因此永远等不到「语音结束」，只能吃 12 秒兜底
——现场感受就是「商店关的关卡名来得特别晚」。

**修法**：判据从 `game._loadLevel` 里抽成 `levels.levelTitleDelay(lv, cfg, cover)`：

```js
export function levelTitleDelay(lv, cfg, cover) {
  if (lv && isLaser(lv)) return cfg.MECHANIC_DELAY;   // 激光关：动画 + 语音，先排兜底
  return cover ? cfg.INTRO_DELAY : cfg.DELAY;         // 商店关与普通关同口径
}
```

于是商店关和普通关一样：**有云雾就从「进关起雾」起 1.5s 弹**（卡片在雾里淡入）。抽成纯函数的意义
是这条口径有单测（`tests/level-title-label.test.mjs`），而不是埋在 300 行的 `_loadLevel` 里。

## 7. 关闭 EXE 报错：本轮只差重打包 + 一条加固

**先分清两件事**：第五十七修已经把「句柄被 `JSON.stringify`」从**源头**断掉了（见 `docs/tech/30` §2），
而现场那次报错用的是**修复前打的 EXE** —— 所以第 1 条的正解是**重新打包**，不是再改一遍代码。

本轮补的加固：`tools/cast-pc/main.js` 里**所有 `res.end(JSON.stringify(...))` 改走 `safeJson(...)`**
（共 10 处：`/api/info`、`/api/license/*`、`/api/launch/request`、`/api/master/allow`、`/api/config`、
`/api/round/*`、`/api/platform/*`）。原则写在 `safeJson` 的 doc 注释里：
**句柄（Timeout / Socket / Server）一律放模块级变量，状态对象只放纯数据；凡是要塞进响应体的状态对象都走 `safeJson`。**
这样任何一条响应出问题，代价只是那一条响应降级成 `{ok:false,why}`，**不会**变成挡住 `app.quit()` 的模态框。

- **单测**（全量 `npm test` 325 项全绿，本轮 +7）：

  | 用例 | 锁什么 |

  | `第五十八修 · 两列卡放大且平行于地面的 Z 线` | 缩放值 + `rotation.y = ±π/2`，正前方仍是 `lookAt` |
  | `第五十八修 · 气球高度 / 浮动 / 命中半径随整组缩放` | `balloonY / balloonHit / bob` 三条换算 + 放大后仍可命中 |
  | `第五十八修 · 价位搬出说明文字` | `priceText / priceColor`，且 `sub` 里不再夹价格 |
  | `第五十八修 · 区域牌子` | 两块牌子挂 `badgeGroup` 且在气球上方、倒计时挂 `done.holder`、数值随消费刷新、离店拆干净 |
  | `第五十八修 · 牌子只在文字/颜色真变了才重绘` | `set()` 去重（每帧调用不上传贴图） |
  | `第五十八修 · 牌子字号自适应` | 短文案 84px、长文案自动缩且量宽放得下 |
  | `第五十八修 · 商店卡面价位`（canvas 记录型） | 底部 `bold 44px` 大字 + 金色 / 免费绿；不带价位的卡照旧不画 |

  1. 进第 3 关：关卡名在**雾里**就出来（不再是 12 秒后）；左手道具列与右手预告列**不再歪**、明显大一圈；
     每张卡底部有金色大字价位；技能区与道具区气球上方各挂一块「商店币」；「购物完成」气球上有倒计时；
