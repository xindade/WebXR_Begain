# 第六十六修：商店币小框改「枪右侧镜像 · 整体减半」 · 「冲冲冲」限定脸谱 Boss 第一阶段

> 现场口径（原文，两条）：
> ① 「枪商店商店币显示现在挪到枪的右侧，和技能显示框位置对称，同时整体缩小一半。」
> ② 「冲冲冲的语音，只有第三关的脸谱Boss的第一阶段才会有，其它关卡中不要放，因为太吵了。之前说了几次你都理解错了」

> 方向是**反的** —— 现场要的是**位置门禁**：除脸谱 Boss 第一阶段外**完全静音**。本文口径以本轮为准。

## 一、商店币小框：改成技能信息框的**严格镜像**

两个面板共用同一套「按枪模型自动定位」（`vr/skillHint.js` 与 `vr/shopCoinBadge.js` 的 `placeOnGun`，
都走 `vr/streakCounter.js` 的 `barrelMount`）：

```
位置 = 轴上 ALONG 处  +  (up × 枪管轴) × (SIDE < 0 ? +1 : -1) × (radius + LATERAL_GAP)
        └─ 前后 ─┘       └────────── 左右（SIDE<0 取玩家左手边）──────────┘
```

（`up × 枪管轴 = 玩家左手边`；`SIDE < 0` 往左偏、`SIDE > 0` 往右偏。）

所以「对称」= 把三个量对齐即可：

| 量 | 技能信息框 | 商店币小框（第六十六修） | 含义 |
|---|---|---|---|
| `ALONG` | `0.5` | `0.5`（原 `0.68`） | 同在**枪身正中**那条横截面上 |
| `SIDE` | `-1` | `+1`（原 `-1`） | 一个在左、一个在右 ⇒ 分列两侧 |
| `LATERAL_GAP` | `0.07` | `0.07`（原 `0.005`） | 离枪身表面**等距** |

* 改 `ALONG` 就是「往前 / 往后」，改 `LATERAL_GAP` 就是「更贴枪身 / 更离枪身」，改 `SIDE` 就是「换边」；
  三者都在 `constants.SHOP_COIN.MOUNT`，`userConfig.SHOP_COIN` 已镜像（改完刷新页面即生效）。
* `SHOP_COIN.POSITION`（枪模型没加载出来时的兜底）同步改成 `SKILL_HINT.POSITION` 的镜像：`x` 取反（`-0.119` → `+0.119`）。
* ⚠ **两个面板必须共用同一条侧向公式**（`_left.normalize().multiplyScalar((M.SIDE < 0 ? 1 : -1) * gap);`），
  单测里直接拿这行源码文本对两边做断言 —— 以后只改一处就会失去对称，测试会先炸。

## 二、尺寸：整体减半，但比例锁死

`SHOP_COIN.W / H`：`0.24 × 0.075` → **`0.12 × 0.0375`**（各半）。

* 牌子画布是 `cardDraft.makeBadge()` 的 **512×160（宽高比 3.2）**，物理 `w/h` 必须同比例，
  否则文字会被拉伸 —— `tests/shop-coin.test.mjs` 把这条锁死（与商店里那块大区域牌子同一档口径）。
* ⚠ **物理尺寸减半 ⇒ 文字视觉也小一半**（画布是固定像素画好再等比缩放的）。
  若现场嫌字小：**不要**去动 `W/H`（会破比例），改 `cardDraft.makeBadge` 的字号上限（`FONT_MAX`，当前 `84`）放大源字号。
* 想整体关掉这个小框：`SHOP_COIN.ENABLED = false`（`rightGun` 根本不建它；商店里那两块区域牌子不受影响）。

## 三、「冲冲冲」：从「门槛题」改成「位置门禁」

前两轮的错误方向：把现场那句读成「门槛太高了 ⇒ 调低门槛，让普通关也能响」。
现场本轮已说明白：**不是**要它更容易响，而是**只允许在一个地方响**。

落地成一条独立判据（`src/game/game.js`）：

```js
/**
 * 「冲冲冲」放行判据（第六十六修 · 现场口径）：只有**在场且活着的脸谱 Boss 的相位 0（蓝 · 召唤阵冲锋）**才放。
 *   ⚠ 必须带 alive 判断：Boss 被打死后 waves.faceBoss 仍指向那个气球（见 waves._updateFaceBoss 的 cleared 分支）。
 */
_basicVoiceAllowed() {
  const w = this.waves;
  return !!w && !!w.faceBoss && w.faceBoss.alive === true && w.facePhase === 0;
}
```

* **为什么认「脸谱 Boss 的相位」而不是关卡号**：蓝阶段（相位 0）会在 2~4s 内把左右各 3×3（共 **18 只**，中心格骑士、
  其余基础怪）一次推过来 —— 这正是「冲冲冲」该响的地方；普通关按配额滴流（前期 6~10 只）声势完全不同。
  （另外 `_updateBasicVoice()` 只在「普通关」段被调用，`shopMode` / `laserMode` 那两个提前 `return` **之后**，
  所以商店关 / 激光段本来就不会走到这里。）
* **门禁排在数怪之前**（`_updateBasicVoice()` 第一行就 `return`）—— 普通关连怪都不数。
  这条很重要：如果把门禁放在计数后面，留痕里仍会写「基础怪 N 只」，
  现场核对「到底响没响」时会被这行日志骗过去。单测用源码位置断言（门禁 indexOf < 计数 indexOf）。
* 第六十四修的门槛 `basicVoiceNeed(本关配额)`**保留**：它管「凑够多少只才算成群」，
  只在门禁放行后才参与判断（脸谱 Boss 关没有滴流配额 ⇒ 落到 `MIN`）。

## 验证方法

1. **进第 1 关**：枪上那块「商店币 N」小框在**枪身右侧**，与左侧的技能信息框**一左一右、等距、同一横截面**，
   且整体只有原来一半大（文字跟着小一半）。
2. **调位**：把 `userConfig.SHOP_COIN.MOUNT.LATERAL_GAP` 调大 → 两框同时往外挪（等距）；把 `SIDE` 改成 `-1` → 换回左边。
3. **「冲冲冲」**：整局只在**脸谱 Boss 蓝阶段**（一次涌出 18 只那一段）能听到；普通关、其它 Boss、红 / 黑相位都**听不到**。
4. **留痕**：普通关搜 `[冲冲冲]` **应当一行都没有**（本轮新增的门禁就是为了这个）；
   脸谱 Boss 蓝阶段才有 `[冲冲冲] 基础怪 N 只 ≥ 门槛 M（本关配额 Q）`。

单测：`node --import ./tests/register.mjs --test tests/shop-coin.test.mjs tests/basic-voice.test.mjs`
（镜面对称 2 + 减半 / 比例 3 + 接线 3；门槛 5 + 门禁真值表 1 + 门禁位置 1 + 接线 1）。全量 `npm test` 431 项全绿。
