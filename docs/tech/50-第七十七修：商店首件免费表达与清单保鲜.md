# 第七十七修：商店「首件免费」表达与清单保鲜

## 现场反馈

> 再仔细分析一下商店逻辑，刚刚测试发现还是不对。

上一修（第七十六修）已确认：第 3 关商店在**当前源码 / 服务器内容 / APK 1.5.4** 三处构建出来都是

```text
左侧：3 个道具槽 + 刷新道具
右侧：铁甲兵 / 盾甲兵 / 治疗术士 / 脸谱 Boss
```

因此本轮不再重复猜「名单」，而是把整条链路逐层拆开：**代码怎么算 → 头显实际加载哪一份 → 玩家看到的文案是否和规则一致**。

## 二、真正的问题

### 1. 三张道具卡同时写「免费」→ 被读成「三件都免费」

旧实现：

```js
const free = !!this._freeItem;
priceText: free ? '免费' : String(price)
```

三张卡各写一次「免费」。这个写法本身是**准确**的（任选一件都免），但没有说明「只能免一件」，
玩家会理解成「三个都能免费拿」，买第二个突然扣 500，就像规则坏了。

同时，购买成功提示走的是 `onDenied` —— 那条通道本来是「商店币不足」的红色提示，成功消息走进去也像报错。

**修复：**

- 三张卡继续写「免费」（实扣确实是 0；标原价反而会让商店币不够的玩家误以为买不起）；
- 道具列上方新增一块独立牌子：`任选一件免费` → 买掉第一件立刻翻成 `免费名额已用`；
- 进店横幅补一句 `首件道具免费（任选一件）`；
- 买掉第一件后，三张卡立刻恢复原价（第 3 关 500、第 9/15 关 1000×等级）；
- 成功提示改走独立的 `onNotice`，不再复用 `onDenied`。

### 2. 服务器内容更新了，PC EXE 却在整场沿用旧清单

头显的配置来自两条**完全独立**的链路：

```text
游戏逻辑 src/game/shop.js      ← APK 内置（要重打 APK）
配置内容 src/content/*          ← PC EXE 从服务器清单下载后下发给头显
         src/core/userConfig.js
```

`eliteBrief.js`（预告名单）与 `userConfig.js`（商店布局）都属于第二条。旧版 `manifestEnsure` 是：

```js
if (MANIFEST.ok) return true;   // 启动拉到一次后，整场不再刷新
```

于是**服务器上新传了内容，只要 EXE 没重启 / 没走完一局，头显拿到的仍是旧覆盖层**。现场典型现象就是：

- 治疗术士缺失（旧 `eliteBrief.js` 白名单没有 `heart`）；
- 右侧两列位置不对（旧 `userConfig.js` 的 `ITEM_X / PREVIEW_X / DZ`）；
- 源码、服务器、测试三处都对，实机就是不对。

**修复：**

- 清单加 60 秒保鲜期：超过 `MANIFEST_TTL_MS` 就在下一次「配置下发」时重拉；
- 刷新失败**沿用旧缓存**（宁可旧一分钟，也不让头显开局直接失败）；
- 替换清单目录改成「旧目录改名留底 → 新目录就位 → 删留底」，rename 失败可回滚；
- `/api/info` 继续给出 `manifest.ver / count / bytes / builtAt / fetchedAt / fp`，现场一眼对账。

## 三、关于「商店逻辑能不能不重打 APK」

本轮**没有**把 `src/game/shop.js` 加进清单，原因是兼容顺序：

- 现有 EXE 的 `CONFIG_MANIFEST` 只有 `src/content/` + `src/core/userConfig.js`；
- `manifestPathOk` 对未知路径是**整份拒绝**（安全设计，防止清单往任意路径写文件）；
- 如果服务器先发一个含 `shop.js` 的 12 文件包，旧 EXE 会直接判定「清单含越界路径」→ 头显拿不到任何配置。

所以顺序必须是：**先换带新清单的 EXE → 再发含 `shop.js` 的内容包**。本轮先保证现场可上线；下一轮可以按这个顺序打开「商店逻辑热更新」。

## 六、现场操作（这一轮必须按顺序）

1. **重打 PC EXE**（`tools/cast-pc`）—— 本轮改了 `main.js`，旧 EXE 没有保鲜逻辑。
2. 跑部署脚本上传内容包：
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\deploy-content.ps1
   ```
3. 头显安装 **1.5.4 或更新**的 APK（`tools/cast-apk/dist/WeirdTurning-1.5.4.apk`）。
4. 完全退出头显浏览器 / 平台客户端，**重启 EXE**，再开一局。
5. 进第 3 关前，在 PC 上打开 `http://<PC地址>:8443/api/info`，确认：
   ```json
   "manifest": { "ok": true, "ver": "1.0.0", "count": 11, "bytes": 146030 }
   ```
   `fetchedAt` 应接近当前时间（保鲜期会重拉）。若还是很久以前的时间，说明 EXE 仍是旧包。
6. 进店后看留痕那一行：应为「道具=[…3 个…] 首件免费=1；精英预告 4 张：铁甲兵 / 盾甲兵 / 治疗术士 / 脸谱 Boss」。
