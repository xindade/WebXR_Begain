# 第八十七修：浮游炮跟随枪支、爆炮手火箭筒与专属道具

## 目标

处理现场 4 条反馈：

1. 浮游炮整体后移，正视前方只看到身侧枪头；整体转向跟随玩家**枪支**而非头显；
2. 浮游炮恢复默认自动索敌，删除「自动开火」；「集中火力」改为每级浮游炮攻击 +10%，满级 6；
3. 爆炮手爆炸范围 ×3，新增专属卡「再大一点」（爆炸范围翻倍）；
4. 把火箭筒 FBX 压缩为游戏可用的 GLB，并在 PC EXE 增加武器位置/旋转/缩放参数框。

## 浮游炮

参数仍在 `CHARACTERS.swarm.satellite`：

- `ARCH_FRONT_DIST = -0.12`：拱门中心略在头显后方；枪身沿前向伸出，因此正视前方时只在左右余光看到枪头；
- `ARCH_HALF_WIDTH = 1.20` / `ARCH_BASE_OFFSET = -0.22` / `ARCH_HEIGHT = 0.40`：左右展开、略微压低；
- 排布仍由 `archSlotOrder(10)` 保证「两侧先出现、最后补中间」。

整体朝向：

- `RightGun.root` 的本地 `+X` 就是枪模枪口轴；
- 每帧取该轴的世界方向、投影到水平面，作为浮游炮拱门的前向；
- 因此转头不会甩动浮游炮，只有转枪才会整体转向。

射击：

- 删除 `autoFire` 道具、`_autoTick()`、自动射速参数；
- 玩家扣扳机时，浮游炮默认在前方 60° 锥形内索敌；
- 若「集中火力」命中准星 12° 内的精英/Boss/龙部件，则全员集火该目标；
- `focusFire` 每级使浮游炮基础攻击 +10%（1 级即 +10%，满级 6 = +60%）。

## 商店道具

`src/content/shopItems.js`：

| id | 名称 | 角色 | 上限 | 效果 |
|---|---|---|---:|---|
| `focusFire` | 集中火力 | 蜂群 | 6 | 浮游炮攻击 +10%/级；瞄准精英时集火 |
| `blastPlus` | 再大一点 | 爆炮手 | 1 | 爆炮手爆炸范围 ×2 |

- `SHOP_ITEMS` 仍是 8 项：6 个通用 + 2 个角色专属；
- `pickShopItems` / `pickShopItemExcluding` 新增 `levels` 参数；
- 达到 `maxLevel` 的道具不再上架，`_sanitizeItemDisplay()` 也会把它从当前三格剔除并补位；
- 删除「自动开火」图标，新增「再大一点」的扩张冲击波图标。

## 爆炮手爆炸

- 主炮 `MAIN_RADIUS: 2.5 → 7.5`；
- 微型火箭 `EXTRA_RADIUS: 1.2 → 3.6`；
- `BombardRig.fire()` 读取 `_itemLevel('blastPlus')`，买过专属卡后半径再 ×2；
- 爆炸视觉使用子弹携带的最终 `blastRadius`，因此球壳会同步变大。

## PC EXE 武器调参

新增 `tools/cast-pc/lib/weapon-config.cjs`：

- 只在 `src/core/userConfig.js` 的 `BOMBARD_WEAPON` 块中原位替换数字；
- 支持 `POSITION.x/y/z`、`ROTATION.x/y/z`、`SCALE`；
- 脏输入、负缩放、非数字全部在落盘前过滤。

`main.js`：

- `WEAPON_OVERRIDE` 持久化到 `cast-pc-config.json`；
- `applyConfigOverrides()` 在 `/api/config/dump` 与 `/src/core/userConfig.js` 两条下发路径上套用；
- 新增 IPC `weapon:get` / `weapon:set`；
- 保存后 `rotateSession()`，头显下次问配置时整包重下。

`renderer` 新增「爆炮手火箭筒」栏：位置 x/y/z、旋转 x/y/z、缩放、保存按钮。留空 = 不改该轴。
