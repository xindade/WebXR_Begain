# 第九十修：脸谱宝箱攻速化与爆炮手基础攻击 200

## 目标

处理现场 2 条反馈：

1. 脸谱 Boss 宝箱不再给「额外子弹」，改为给「攻速」——因为爆炮手的输出是爆炸 AoE，额外弹道对它是空奖励；
2. 爆炮手基础攻击从 120 提高到 200。

## 脸谱宝箱：额外弹道 → 攻速

### 交互保持不变

- 第 6 关脸谱 Boss 打完后，仍先弹 2 秒「宝箱出现，快攻击」；
- 宝箱仍持续 4 秒，玩家子弹命中一次 +0.1，显示值 0.1 → 2.0；
- 结算档位仍是三段：`<0.5 → 0`、`0.5~<2.0 → 1`、`满 2.0 → 2`。

### 奖励改为攻速

- `MASK_CHEST.KIND` 从 `bullets` 改为 `fireRate`；
- 宝箱上方实时文案从「+0.7 子弹」改为「+0.7 攻速」；
- 每一档 = 一次「射速 +50%」成长（按角色基线计算，上限 20 发/秒）：
  - 疾风 4 → 6 → 8；
  - 蜂群 2 → 3 → 4；
  - 爆炮手 0.8 → 1.2 → 1.6；
- 结算时调用 `applyFireRateSteps(player, bonus)`，并同步 `input.setFireRate()`，确保真实节流源立即生效；
- 0 档时明确记录「不足 0.5 → 无攻速加成」。

### 龙族宝箱不变

第 12 关龙族宝箱仍是「窗口内打出的弹数 → 攻击力加成」，线性封顶 +150。

## 爆炮手基础攻击 200

- `CHARACTERS.bombard.atkMul` 从 `1.2` 改为 `2.0`，基础攻击 100 × 2.0 = 200；
- 角色选择卡文案同步改为「攻击 200」；
- 主炮伤害 = 200，微型火箭 = 200 × 50% = 100；
- 掌风窗口按倍率继承：主炮 200 × 1.5 = 300，微型火箭 100 × 1.5 = 150；
- 精英 / Boss 血量缩放读取玩家实时 DPS，因此会自动按新攻击力重算，不需要另改血量表。

## 验证

- `npm test`：519 项全部通过；
- 覆盖点：
  - 脸谱箱 `KIND === 'fireRate'`，上方文案单位为「攻速」；
  - `applyFireRateSteps`：爆炮手 0.8 → 1.6（两档），疾风 4 → 8；
  - 爆炮手初始攻击 200；
  - 主炮 200 / 微型火箭 100；
  - 掌风窗口主炮 300 / 微型火箭 150。
