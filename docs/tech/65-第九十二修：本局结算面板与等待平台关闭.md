# 第九十二修：本局结算面板与等待平台关闭

## 目标

第 18 关魔术师 Boss 击杀后，不再自动退出 VR / 回菜单 / 关闭浏览器，而是在头显里显示一块本局结算面板，并把“本局已结束”上报给 PC 主控端，让平台弹出自己的结算。之后游戏保持结算态，等待平台下发关闭指令。

## 结算面板内容

面板是场景内 Sprite（DOM HUD 在沉浸态不可见），固定在玩家视线前方，不主动消失、不跟随菜单状态重建。

| 区域 | 内容 |
|---|---|
| 战斗统计 | 角色名 / 角色称号、当前关卡、总杀敌、普通 / 精英 / Boss 分类、最高连击、飞毯血量、能量、商店币 |
| 强化选择 | 本局抽到的属性强化及次数（射速、额外子弹、攻击力、技能消耗、技能伤害、自我修复、多重爆炸等） |
| 技能构筑 | 当前技能、技能威力倍率、技能消耗、冷却缩减、本局成功释放次数 |
| 商店道具 | 本局购买过的商店道具及等级（打狗还要看主人、以战养战、吸血子弹等） |
| 底部 | `本局已结束 · 等待平台关闭游戏` |

面板只弹一次；重复进入收尾路径会被 `_runResultShown` 拦住。

## 状态与协议

- 自然结束：`_onFinalBossClear()` → `_showRunSummary()` → `state = 'result'`。
- 结算态冻结战斗：清空怪物、子弹、投射物、伤害数字、特效、金点、治疗线、宝箱与待出怪队列；玩家不能继续射击，但 VR 会话、相机和手柄追踪保持。
- 结算时调用 `_tellMasterRoundEnd()` → `POST /api/round/end`。PC 主控端在 `ROUND.armed` 时转成平台 **CMD 7**，平台据此弹出本局结算；这条路径**不关闭游戏**。
- 结算时**不发送**带 `roundOver:true` 的 `game-end`。否则 APK 的 `GameServer.notifyGameEndIfAny` / `MainActivity.restoreClientAndCloseBrowser` 会执行退出策略，违背“等平台关闭”的现场要求。
- 真正关闭：平台下发游戏通道 `0x10 closeGame`（`cmd 16`）→ `_onPlatformCloseRequest()` → `_finishRound()` → `toMenu()` → `_reportGameEnd(roundOver:true)`。此时 APK 才关闭浏览器 / 唤醒平台客户端。
- 旧平台 `cmd 5/6` 仍然走回菜单并结束 XR 会话，作为兼容路径保留。
- `_tellMasterRoundEnd()` 增加 `_masterRoundEndSent` 去重，避免“结算时发一次、平台关闭时又发一次”的重复 CMD 7。

## 防串局与防叠界面

- `start()` 重置 `_runStats`、`_maxCombo`、`_runSkillCasts`、`_runResultShown` 和 `_collectedCards`；其中 `_collectedCards` 之前漏清，会把上一局的强化带进新一局结算。
- 结算前清理金点，避免金点在 `GOLD_ORB.HOLD` 结束后调用 `_enterMidCard()`，把选项卡叠到结算面板上。
- 通关横幅到期后才进入结算；若结算发生在横幅仍存在时，会先 dispose 横幅，避免两个 3D 界面重叠。
- 面板沿用 1600×1000 画布；强化区上移到 `y=520`，保证 7 条强化全部落在面板内。

## 涉及文件

- `src/game/runSummaryPanel.js`（新）：Canvas + Sprite 结算面板；
- `src/game/game.js`：本局统计字段、击杀分类、连击记录、技能释放计数、结算态、清理与上报入口；
- `tests/run-summary.test.mjs`（新）：结算数据、冻结态、去重与不自动退出。

## 验证

- `node --check src/game/game.js`、`node --check src/game/runSummaryPanel.js` 通过；
- 专项：`node --import ./tests/register.mjs --test ./tests/run-summary.test.mjs`，5/5 通过；
- 全量：`npm test`，535/535 通过。

## 测试口径

1. 最终 Boss 击杀并看完通关横幅 → 出现结算面板，杀敌分类、技能、道具、强化均有数据；
2. 面板停留超过任意时长不自动退出，玩家仍停留在 VR；
3. 平台点“关闭游戏” → 结算面板被清理，页面进入既有收尾流程（关浏览器 / 待机）；
4. 平台侧在自然结束时应收到 CMD 7 并弹结算，但游戏不被这条报文关闭；
5. 新开一局时上一局的强化、杀敌数、技能释放数不得串入本局。
