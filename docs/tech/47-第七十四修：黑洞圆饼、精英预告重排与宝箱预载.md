# 第七十四修：黑洞圆饼、精英预告重排与宝箱预载

## 现场反馈

1. 黑洞把小怪吸成了一圈圆环，想要的是中间也填满的「圆饼」。
2. 第 3 关只需要铁甲兵 / 盾甲兵 / 治疗术士三张精英图 + 脸谱 Boss，共 4 张；忍者放到第 9 关预告。
3. 宝箱出现前的棕色占位方块会先露一下，希望横幅期间先预载、保持隐身，横幅结束再显示；同时检查其它同类问题。

## 修复

### 1. 黑洞吸附改为竖直圆饼

- 新增纯函数 `blackHoleDiscSlot(index, count)`：用黄金角 + `sqrt(i/(n-1))` 半径铺满整个圆面。
- `index = 0` 落洞心，后续小怪由内向外填充；新怪加入或旧怪死亡时按当前存活数量重新紧凑编号。
- 仍使用黑洞平面的 `right / worldUp` 两轴，所以圆饼严格竖直、正对释放瞬间的玩家，不会躺到地面。
- 精英行为不变：2 秒到位后继续做径向振荡，不参与普通小怪的圆饼槽位。
- `BLACK_HOLE.DISC_FILL = 0.94` 控制圆饼最外缘，避免贴到黑洞视觉边缘之外。

### 2. 精英预告卡重排

- 第 3 关：铁甲兵 / 盾甲兵 / 治疗术士 / 脸谱 Boss，共 4 张。
- 第 9 关：忍者队长 / 幽灵法师 / 章鱼将军 / 龙 Boss，共 4 张。
- 第 15 关：未知 Boss 阶段一 / 二 / 三，共 3 张。
- 第 8 关末尾的忍者属于客串，不再把第 3 关预告撑成 5 张；用 `PREVIEW_ELITE_BY_SHOP` 白名单固定现场口径。

### 3. 宝箱预载与占位遮挡

- 第 6 / 12 关的穿云窗预载队列加入 `Model/宝箱.glb`，并做 GPU `warm`。
- `_startBossChest()` 在 2 秒横幅开始时创建 `DragonChest`，构造即开始加载，但 group 保持隐身。
- `DragonChest.start()` 在模型未就位时进入 `loading`：不显示占位盒、不计时、不受击，但仍算 `running`，继续挡住通关抽卡，避免流程提前跑掉。
- GLB 到位后才真正显示宝箱并开始倒计时；加载失败才退回棕色盒兜底。
- 审计结果：传送门 / 开场魔术师 / 魔术师 Boss 都没有“先显示方块”的占位路径；龙头的红色线框只在加载失败时出现，且第 12 关已预载。小怪的「光点」是第三十四修确认保留的加载表现，不属于本次问题。
