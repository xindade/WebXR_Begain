# WebXR 稳定性与体验改进设计

用户已确认按 2026-09-21 项目审查建议依次实施。本设计保留静态 ES Module、Three.js r168 和现有 18 关玩法。

1. 玩法正确性：模型加载失败显示占位；攻击强化不降低死亡补偿后的攻击；选卡使用连续轨迹碰撞；开发快捷键与移动分离；满级强化不进入候选池，并展示前后数值。候选不足时提供补给，避免空卡池。
2. 资源：天空缓存默认最多三张，保护当前天空，切关/菜单使旧异步请求失效；共享 GLTF/Draco 加载器，失败请求可重试；真实启动进度、失败重试及简化模式。2K 天空档在解码后缩小上传尺寸，原图网络大小不变。
3. 性能：提供可下载诊断数据，记录帧间隔、更新/渲染 CPU 耗时、draw calls、三角形和纹理数；提供浏览器离线立绘导出工具与预生成图集入口。没有头显时不宣称通过真机验收。
4. 体验：暂停原因集合防止窗口恢复误清手动暂停；桌面与 XR 焦点变化暂停玩法、音视频，恢复需明确操作；VR 用手柄菜单操作恢复或退出。设置保存到 localStorage，包含移动速度、转向、桌面/坐姿高度偏移、惯用射击手、音量、天空质量。
5. 工程：新增独立碰撞、资源、设置、暂停和性能模块，避免继续扩大 Game；Node 内置测试，无第三方运行依赖；更新 README 和真机检查表，标记未接入的旧配置。

验收：回归检查覆盖伤害成长、低帧率选卡、资源失败/重试、天空竞态/淘汰、输入失焦、暂停多原因和设置校验；浏览器验证加载、开局、暂停恢复、切关及控制台。PICO/Quest 连续关卡、重开、72/90Hz 帧预算作为待真机验收项。
